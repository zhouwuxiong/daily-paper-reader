## 摘要
从原始像素导航大规模、照片级逼真的3D公寓，通常被认为对于普通的强化学习是不可行的。我们构建了一个代理，它仍然做到了这一点，仅从摄像头估计自己的姿态。该代理必须依次到达多个目标物体，并且它们的位置在每个回合之间变化，因此它必须探索以找到它们。它建立在我们早期的以对象为中心的拓扑控制器之上，该控制器仍然从模拟器中读取代理的真实姿态和对象检测。在这里，我们用自身的、以对象为中心的估计来替代真实姿态。对于每个对象，我们保留一组ORB特征，当再次看到该对象时，这些特征会产生粗略的姿态测量，一个最小的扩展卡尔曼滤波器（EKF）将其与运动模型融合。如同在真实机器人上一样，执行的运动是有噪声的。估计会漂移，但代理和附近的物体一起漂移，因此局部一致的姿态足以跟随每条短边，然后在视觉上锁定目标，这让我们可以用一个更小的模型取代完整的SLAM，更接近生物导航的工作方式。在照片级逼真的Habitat模拟器中，代理仅凭视觉就能到达目标物体，其姿态只需要局部一致。

## Abstract
Navigating large, photorealistic 3D apartments from raw pixels is widely considered infeasible for plain reinforcement learning. We build an agent that does it anyway, estimating its own pose from the camera alone. The agent has to reach several target objects in sequence, and their positions change between episodes, so it must explore to find them. It builds on our earlier object-centric topological controller, which still read the agent's true pose and its object detections from the simulator. Here we replace that true pose with an onboard, object-centric estimate. For each object we keep a bank of ORB features that, when the object is seen again, yield a rough pose measurement, which a minimal Extended Kalman Filter (EKF) fuses with a motion model. As on a real robot, the executed motions are noisy. The estimate drifts, but the agent and the nearby objects drift together, so a locally consistent pose is enough to follow each short edge and then home in visually on the target, which lets us replace full SLAM with a much smaller model, closer to how biological navigation appears to work. In the photorealistic Habitat simulator, the agent reaches its target objects from vision alone, with a pose that only needs to be locally consistent.

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将导航系统分为两层：
  - **决策层**：沿袭前作，使用基于宏动作的DQN（DRRN风格），从拓扑地图中选择下一个要访问的已知对象。
  - **导航与定位层**：将决策转化为实际运动，执行最短路径规划、底层控制（前进/转向），并新增一套基于视觉的轻量级定位栈，替代原有的真实位姿输入。

- **关键技术细节**：
  - **对象中心拓扑地图**：地图节点分为主干节点（机器人实际到达过的位姿）和对象节点（语义物体及其估计3D位置），只有对象节点作为宏动作提供给DQN。地图随探索动态增长。
  - **ORB特征库**：对每个对象，在语义掩码内提取ORB特征，首次出现时存储描述子和通过深度反投影得到的3D锚点；再次看到同一对象时进行特征匹配，得到当前观测与地图锚点之间的对应点对。
  - **Kabsch姿态测量**：利用加权最小二乘（Kabsch算法）在SE(2)上求解当前位姿测量值，权重与距离成反比以减少远处锚点的噪声影响。该测量作为EKF的观测值。
  - **扩展卡尔曼滤波器（EKF）**：状态为(x, z, ψ)，预测步基于已知的运动模型（前进、转向），并注入真实的执行噪声（转向1°、前进0.01m、侧滑0.005m）。EKF融合Kabsch测量，在无可匹配特征的帧（如靠近白墙）依靠运动模型航位推算，并对明显不一致的测量进行拒绝。
  - **地图写入门控**：当位姿估计不可靠时（如匹配特征太少、EKF协方差过大），暂缓将新对象写入地图，避免错误锚点污染后续规划。
  - **视觉归航**：接近目标时，直接根据图像中目标的方位转向并前进，当目标足够近时发出Found信号。这一过程不依赖于全局位姿，是容忍全局漂移的关键。

### 6. 论文的主要结论与发现

- **局部一致的姿态足以完成导航**：Full系统在位置估计漂移数米、航向误差十几到三十几度的情况下，仍能以较高的真实成功率到达目标，验证了“全局错误但局部一致”的拓扑地图可以支撑实际导航。
- **运动模型是定位栈的关键**：No-EKF（无运动模型）的航向误差增长到80–104度，导航明显失败；而Full系统航向误差保持在13–39度。说明EKF提供的运动预测和滤波是姿态估计可用的核心。
- **视觉测量纠正漂移**：Motion-Only（纯航位推算）在执行噪声下位置误差累积至3–4米，无法修正；Kabsch测量将位置误差控制在1.5–2.4米。两者结合才能维持可用估计。
- **与真实位姿相比仍有差距**：Full系统在各任务类型上的真实成功率低于GT-Pose，且差距随目标序列长度增大（1目标85% vs 97%，3目标即时27% vs 80%）。但Full是噪声条件中表现最好的。
- **随机宏动作也能到达部分目标**：说明手写控制器本身提供了较强的低层导航能力，但也表明高层策略的贡献相对有限。

### 7. 优点

- **方法论创新**：用轻量级ORB特征+Kabsch+EKF替代完整SLAM，显著降低系统复杂度，且更接近生物导航的“拓扑+局部度量”模式，具有仿生意义。
- **实验设计严谨**：通过两组消融（No-EKF、Motion-Only）精确分解了运动模型和视觉测量的各自作用；提出“真实成功率”以剥离偶然声明Found的噪声，使结果更可信。
- **现实考虑充分**：显式加入执行噪声（转向、前进、侧滑），更贴近真实机器人；地图写入门控防止错误位姿污染地图，提升了鲁棒性。
- **清晰的模块化架构**：决策层与导航定位层解耦，RL只负责高层语义选择，底层几何和运动学被显式建模，使问题可解。

### 8. 不足与局限

- **依赖模拟器简化**：对象语义掩码和类别ID仍由模拟器提供，未处理真实物体检测（如Mask R-CNN等）引入的噪声和误差，离真实部署尚有距离。
- **计算成本**：在每帧每个对象掩码内运行ORB特征提取和匹配是定位栈中最昂贵的部分，可能成为实时瓶颈。
- **手写控制器承担大量工作**：宏动作的执行依赖于手工设计的路径跟踪、视觉归航和恢复行为，其可靠性和步骤数主要取决于该控制器而非学习策略（表现为Random-Macro也能部分成功）。提升低层执行的可学习性是未来方向。
- **全局漂移限制**：虽然局部一致足够，但漂移会在长序列、大场景中累积，导致定位误差增大（如全系统位置误差在3目标时可超2米），最终影响长期任务成功率。
- **实验覆盖有限**：只在Habitat模拟器的同一类公寓环境中测试，未涉及多种场景类型、不同光照/纹理条件或真实机器人数据；缺乏对算法泛化能力的证明。
