## 摘要
前馈高斯重建最近已成为驾驶场景重建的一种高效方法。然而，现有的基于激光雷达的方法保留了观测点与高斯原语之间的初始对应关系，将初始化后的原语集合视为最终表示。与基于优化的3DGS不同，这些方法在训练期间无法累积梯度来确定场景表示应如何增密。同时，共享的稀疏骨干仅隐式地融合来自不同时间戳的观测，未能显式聚合跨时间的证据用于单个原语。在本文中，我们提出了学习高斯结构（LGS）框架，该框架同时增强了高斯结构和原语属性。我们的关键观察是，由剪枝或添加干预引起的局部梯度响应变化揭示了相应结构调整是否有利于重建。基于这一观察，我们的高斯增密策略（Gaussian Densify Policy）从受控干预中学习一个包含剪枝分数和添加分数的增密图（Densify Map），并在推理期间直接调整高斯结构。我们进一步开发了一种紧凑的跨时间点查询（Cross-Time Point Query），它能够显式检索并聚合来自其他时间戳的高斯原语的邻近特征，以实现可靠的属性预测。在Waymo开放数据集和PandaSet上的大量实验表明，LGS始终优于现有方法。

## Abstract
Feed-forward Gaussian reconstruction has recently emerged as an efficient approach for driving scene reconstruction. However, prevailing LiDAR-based methods preserve the initial correspondence between observed points and Gaussian primitives, treating the initialized primitive set as the final representation. Unlike optimization-based 3DGS, these methods cannot accumulate gradients during training to determine how the scenes representation should be densified. Meanwhile, the shared sparse backbone only fuses observations from different timestamps implicitly, without explicitly aggregating cross-time evidence for individual primitives. In this paper, we present Learning Gaussian Structure (LGS), a framework that enhances both Gaussian structure and primitive attributes. Our key observation is that changes in local gradient responses induced by a prune or add intervention reveal whether the corresponding structural adjustment benefits reconstruction. Based on this observation, our Gaussian Densify Policy learns a Densify Map comprising Prune and Addition Scores from controlled interventions, and directly adjusts the Gaussian structure during inference. We further develop a compact Cross-Time Point Query that explicitly retrieves and aggregates neighboring features from Gaussian primitives at other timestamps for reliable attribute prediction. Extensive experiments on the Waymo Open Dataset and PandaSet demonstrate that LGS consistently outperforms existing methods.

## 论文总结：Learning Gaussian Structure (LGS)

### 1. 核心问题与整体含义（研究动机和背景）

驾驶场景重建是自动驾驶、仿真和传感器合成的基础任务。近年前馈高斯重建方法（如 EVolSplat、Flux4D 等）相比逐场景优化的 NeRF/3DGS 方法，能够直接从传感器观测映射为动态高斯场景，效率更高。然而，现有基于 LiDAR 的前馈方法存在两个关键局限：

- **结构不可调整**：每个 LiDAR 点初始化一个高斯原语后，该集合在整个推理过程中保持不变，被视作最终表示。与优化型 3DGS 不同，这些前馈方法无法在训练中累积梯度来决定场景表示应如何增密或稀疏化。连续回归虽能更新已有原语的属性（位置、尺度等），却无法判断某个原语应被剪除或新增。导致的直接后果是：稀疏区域无法恢复精细场景结构，渲染结果模糊。
- **跨时间特征融合不足**：共享稀疏骨干虽然能将不同时间戳的 LiDAR 观测置于同一三维特征空间，但信息仅通过空间卷积隐式交互，未能针对单个高斯原语显式检索和聚合跨时间证据，限制了属性预测的可靠性。

本文提出的 LGS 框架同时解决上述两个问题：一方面通过干预引导的密度控制学习高斯集合的**离散结构**，另一方面通过跨时间点查询增强每个原语的**连续属性**预测。

### 2. 方法论

#### 2.1 整体架构

LGS 基于 EVolSplat/Flux4D 的前馈高斯重建框架。给定 T 个时间戳的 LiDAR 点和 C 个相机图像，每个高斯原语 `g_i = [x_i, q_i, s_i, α_i, c_i]`（位置、旋转、尺度、不透明度、颜色），保留采集时间戳 t_i。稀疏卷积骨干预测属性残差与初始速度，经三轮迭代优化渲染损失。LGS 在此框架上增加两个核心模块。

#### 2.2 Gaussian Densify Policy（高斯增密策略）

**核心观察**：对高斯集合执行剪枝（prune）或添加（add）干预后，局部梯度响应（local gradient response）的变化能反映该结构调整是否有利于重建。若某操作降低了周围原语的梯度响应，说明邻域表示能更好地解释观测，即该操作是有益的。

**干预构造**：
- 训练时按概率 ρ 采样原语子集，重复多轮以增加覆盖率。
- 从同一预测高斯集合构建三个分支：原始分支（B1）、剪枝分支（B2，移除采样原语）、添加分支（B3，为每个采样原语添加一个带微小扰动的副本）。
- 三个分支使用相同的目标视图和渲染损失，且表示网络被冻结，保证唯一差异是干预操作本身。

**局部梯度响应度量**：对分支 B 中的原语 j，计算渲染损失对高斯属性的归一化梯度幅度：

```
r_j^B = (1/D) Σ_{c=1}^{D} |(∇_{g_j} L^B)_c| / (max_l |(∇_{g_l} L^B)_c| + ε)
```

其中 D 为属性维度，按所有原语中最大绝对值归一化以消除属性间尺度差异。

**干预目标构造**：
- 剪枝目标：`Δ_i^prune = Σ_{j∈K(i)} (r_j^B2 - r_j^B1)`
- 添加目标：`Δ_i^add = Σ_{j∈K(i)} (r_j^B3 - r_j^B1)`

其中 K(i) 为原语 i 的 K 个空间邻居。负值表示干预降低了局部梯度响应，即有益。经符号对数变换、z-score 归一化和 sigmoid 映射后得到监督目标 `y_i^a ∈ [0,1]`。

**策略预测**：使用 Point Transformer V3 作为共享空间编码器，输入拼接了解码器特征 f'ᵢ、归一化位置、高斯属性和体素密度特征，两个预测头分别输出 Prune Score 和 Addition Score，构成 Densify Map。

**损失函数**：采用置信度加权回归损失：

```
L_density = Σ_{a∈{prune,add}} [ Σ_i w_i(p_i - y_i)² / Σ_i w_i ]
w_i = (2|y_i - 0.5|)^γ
```

γ=2 可使策略聚焦于高置信度的干预响应。

**推理时调整**：干预分支在训练后丢弃。推理时根据阈值 θ_p 和 θ_a（均设为 0.7）进行剪枝和添加：

```
G' = {g_i | p_i^prune ≤ θ_p} ∪ {Add(g_i) | p_i^add > θ_a, p_i^prune ≤ θ_p}
```

剪枝优先于添加，整个过程为前馈式，无需干预渲染。

#### 2.3 Cross-Time Point Query（跨时间点查询）

- 对每个高斯原语 i，在特征空间中检索 K 个**来自其他时间戳**（t_j ≠ t_i）的最近邻原语。
- 对检索到的特征做均值池化得到跨时间特征 f̄ᵢ。
- 与原始解码器特征拼接后经残差投影融合：`f'ᵢ = fᵢ + W_proj[fᵢ, f̄ᵢ]`。
- 融合特征既用于高斯残差预测，也输入到 Gaussian Densify Policy。

#### 2.4 三阶段训练策略

由于联合训练可能因干预目标随高斯状态预测变化而不稳定，采用三阶段：
1. **阶段一**：用渲染监督训练骨干和 Cross-Time Point Query（可选密度扰动以增强鲁棒性）。
2. **阶段二**：冻结上述模块，用干预目标优化 Gaussian Densify Policy。
3. **阶段三**：冻结策略模块，基于预测的剪枝和添加操作微调骨干。

### 6. 主要结论与发现

- **LGS 在两个数据集上全面超越现有方法**：Waymo 上全图 PSNR 达 28.04 dB（相比 UniSplat 26.28 dB），LPIPS 降至 0.113；PandaSet 上动态区域 PSNR 达 22.43 dB（相比 STORM 17.65 dB），DMAE 降至 2.06。
- **GDP 和 CTPQ 各自有效且互补**：单独加 GDP 提升 PSNR 1.13 dB（26.55→27.68），单独加 CTPQ 提升 0.76 dB，两者结合进一步提升至 28.04 dB。
- **干预引导的结构学习是可行的**：局部梯度响应变化能有效监督稠密化/剪枝决策，且学习到的策略可直接前馈应用于未见场景，无需推理时的干预渲染或逐场景优化。
- **Addition 和 Prune 分数呈现空间互补**：即使监督目标独立构造未加约束，高 Addition 区域通常低 Prune，说明策略学会了区分需要增密和需要删除的区域。
- **密度位置比密度规模更重要**：相同高斯数量下，学习策略较随机行为提升 0.52 dB，表明策略预测的干预位置是关键。
- **显式跨时间特征检索补充了空间骨干的隐式融合**：CTPQ 在不大幅增加参数（仅 0.02M）的情况下持续改善重建质量，尤其对动态物体形状的保持。

### 7. 优点

- **方法创新性强**：将可学习的稠密化机制引入前馈重建，是首个通过干预梯度响应进行结构学习的方法。干预目标不依赖人工标注，是一种自监督式的结构编辑信号。
- **原理清晰严谨**：梯度响应差异作为干预质量的度量，具有可解释性；三阶段训练将干预目标构造与表示学习解耦，设计合理。
- **推理效率高**：策略在训练后即可前馈预测 Densify Map，无需额外渲染迭代，保持了前馈方法的高效性。
- **消融设计客观**：随机对照 + 相同动作率的设置让"策略本身有效"这一结论更可信；阈值分析覆盖了实际部署需要关注的超参数敏感性。
- **可视化佐证充分**：Addition Score 高亮位置与渲染改善区域一致，直观展示了策略行为与收益的因果关系。

### 8. 不足与局限

- **密度阈值固定**：θ_p 和 θ_a 对所有场景统一设置，未必是最优。不同场景的光照、密度、目标尺度差异可能需要场景自适应阈值，文中也承认未来将探索场景相关的密度调节。
- **背景建模依赖外部输入**：背景仍依赖于 LiDAR 对齐的单目深度（Depth Anything 3）和采样的天空点，并非全可学习的统一建模方案。
- **跨时间检索可能混淆物理结构**：欧氏空间最近邻检索对快速移动的物体可能将不同物理结构的点混为一组，影响特征聚合的语义正确性；且检索有额外搜索开销。
- **算力信息不透明**：未报告 GPU 型号、批次大小和训练总时长，复现的算力门槛难以评估。
- **实验范围有限**：仅验证于 Waymo 和 PandaSet 两个数据集，均为美国城市驾驶场景，未覆盖极端天气、夜间等更具挑战性的情形。对低激光雷达密度或稀疏输入片段的鲁棒性也未测试。
- **效率仍有提升空间**：LGS 推理时间 1.92 秒/帧，相比同属前馈的 STORM（0.08 秒）差距明显；新增模块的检索和空间编码造成了时间开销，实时驾驶应用尚有距离。
