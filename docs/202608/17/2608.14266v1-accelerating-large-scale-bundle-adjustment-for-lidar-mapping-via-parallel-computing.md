## 摘要
激光雷达束调整广泛应用于建图，以构建全局一致的点云地图。本文提出了首个全并行计算框架，用于加速大规模建图中的激光雷达束调整，包含三项关键技术。首先，我们设计了一种自适应、异步的数据加载策略，以在内存受限的GPU上高效处理大规模点云数据集。其次，我们提出了一种新颖的自底向上体素化方法用于提取平面特征，从而实现全并行的预处理。第三，我们基于主化-最小化公式，通过并行计算加速优化中的计算密集型任务，包括残差、雅可比矩阵和海森矩阵的计算，以及并行增量求解器。为支持我们的设计，我们提供了方法时间复杂度的理论和实验分析。在多种计算平台上对大规模公开数据集的广泛基准测试验证了我们方法的鲁棒性和适应性，在保持与最先进方法相当的建图精度的同时，计算效率提升了最高十倍。为惠及未来研究，实现代码已在GitHub上公开。

## Abstract
LiDAR bundle adjustment is widely utilized in mapping to construct globally consistent point cloud maps. In this paper, we propose the first fully parallel computing framework to accelerate LiDAR bundle adjustment for large-scale mapping, incorporating three key techniques. First, we design an adaptive, asynchronous data loading strategy to efficiently process large-scale point cloud datasets on memory-constrained GPUs. Secondly, we present a novel bottom-up voxelization method for extracting planar features, enabling fully parallelized pre-processing. Thirdly, we build upon a majorization-minimization formulation to accelerate compute-intensive tasks in the optimization via parallel computation, including the computation of residuals, Jacobian and Hessian matrices, and a parallel increment solver. To support our design, we provide both theoretical and experimental analysis of the time complexity of our approach. Extensive benchmarking on large-scale public datasets across various computational platforms validates the robustness and adaptability of our approach, achieving up to a tenfold improvement in computational efficiency while preserving mapping accuracy comparable to state-of-the-art methods. To benefit future research, the implementation code is available on GitHub.

## 一、论文核心问题与整体含义（研究动机与背景）

- **核心问题**：大规模 LiDAR 束调整（Bundle Adjustment, BA）在构建全局一致点云地图时计算开销极大，传统方法依赖顺序计算，难以应对动辄包含数十亿点、数万个扫描位姿的大规模城市场景。
- **研究动机**：
  - LiDAR BA 是消除建图漂移、实现全局一致性的关键步骤，但预处理（特征提取）和优化（非线性迭代求解）两阶段的计算复杂度都随数据规模急剧增长，传统的 CPU 顺序计算成为性能瓶颈。
  - 虽然已有方法（如 BALM3）采用了 CPU 多线程或分布式处理，但并行程度有限，无法充分释放现代 GPU 的算力；而直接"从 CPU 迁移到 GPU"并非线性替换，需要针对内存分配、数据流和问题公式化进行专门设计。
- **整体含义**：本文提出了**首个全并行的 LiDAR 束调整框架**，在单一 GPU 上实现从数据加载、预处理到优化求解的完全并行化，旨在显著提升大规模建图的效率而不损失精度，为后续研究提供了开源实现。

## 二、方法论：核心思想、关键技术细节与算法流程

### 1. 核心思想
以 BALM3 的 majorization-minimization（MM）公式为基础，利用其将 LiDAR 位姿解耦的特性，将所有计算密集型任务映射到 GPU 上并行执行，并配套设计内存管理和数据流方案以突破 GPU 显存限制。

### 2. 三大关键技术

- **自适应异步数据加载（Adaptive Asynchronous Data Loader）**：
  - 针对大规模点云（可达数十 GB）超出 GPU 显存容量的现实约束，将 GPU 显存按比例 α 划分为两个区域：一个用于承载点云数据流，另一个作为簇存储和处理的缓冲区。
  - 利用点簇（point cluster）的紧凑表示，在 CPU 侧分批次将点云传入 GPU，并采用 CUDA Stream 实现**异步传输与点聚类的并发执行**，减少等待时间，缓解内存压力。

- **自底向上的体素化方法（Bottom-up Voxelization）**：
  - 区别于传统八叉树的"自顶向下"递归细分，该方法从最小分辨率 d 开始，逐步向上合并体素索引（`I_k = floor(I_{k-1}/2)`），通过 `sort by key` 和 `reduce by key` 等标准原语在各层级并行聚合点簇。
  - 优势：能捕捉到更多低层级体素中的平面特征，避免顶向下方法在高层级满足平面阈值后遗漏低层级特征的缺陷。

- **基于 MM 公式的全并行优化过程**：
  - **残差计算**：通过并行变换点簇到世界坐标系，`reduce by key` 聚合体素特征，并行计算平面法向量和残差，并行求和得到总残差。
  - **雅可比与海森矩阵计算**：利用 MM 公式的位姿解耦特性，为每个点簇独立计算其对相关位姿的雅可比和海森矩阵，再通过两个索引映射器（Mv、Ms）和 `reduce by key` 按位姿聚合。
  - **并行增量求解器**：因位姿已解耦，每个位姿的增量可通过 LDLT 分解独立并行求解，无需整体求解大规模线性系统。

### 3. 算法流程
1. **预处理**（Algorithm 1）：自底向上体素化 → 平面特征选择（阈值 τ）→ 构建索引映射器（Mv、Ms）。
2. **优化**（Algorithm 2）：LM 优化器迭代执行——并行残差评估 → 并行雅可比/海森计算 → 并行增量求解 → 更新位姿。

### 4. 时间复杂度分析
基于 Brent 定理，给出各阶段并行时间复杂度：
- 预处理：T_p = O(N_P log(N_P)/N_Th) + O(log²(N_P))
- 残差/雅可比/海森计算：T_p = O(N_C/N_Th) + O(log(N_C))
- 增量求解：T_p = O(N_T/N_Th) + O(1)

## 六、主要结论与发现

- **效率大幅提升**：在 HeLiPR 数据集上，相比 BALM3 最高加速 **9.97 倍**（如 Roundabout Avia03 序列），相比 HBA 加速更显著（最高约 30 倍以上）；在 MulRan 数据集上相对 BALM3 加速约 4.6 倍，相对 HBA 最高约 166 倍。
- **精度保持或略有提升**：在 33 个序列中，本文方法在 **17 个序列中取得最低 RMSE**，优于 HBA（13 个）和 BALM3（3 个），精度总体与 SOTA 相当或略优，并未以牺牲精度换取速度。
- **分离式耗时验证**：并行增量求解器平均耗时为 0.008 s，相比 BALM3 的 0.554 s 加速约 70 倍；预处理加速约 4.32 倍；残差/雅可比/海森计算加速约 8 倍。
- **消融结论**：多层（L=3）体素化能提升精度但增加耗时，且如果平面阈值选择不当，引入更多低质量平面特征可能反而损害优化结果。
- **理论分析得到验证**：实测运行时间随数据量近似线性增长，与理论分析一致，表明并行时间主要受限于顺序工作量而非并行深度，暗示多 GPU 扩展有进一步加速潜力。
