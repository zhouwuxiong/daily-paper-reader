## 摘要
我们为无GPS地图定位中的平滑方向点描述符建立了一个泛函分析框架。给定映射 \(\mathcal{M} \subset \mathbb{R}^d\) 中的查询点 \(\mathbf{p}\)，该描述符将环境信号与基于softmax核的单位分割权重族进行积分，从而产生硬角分箱的 \(\mathcal{C}^\infty\) 替代方案。我们的主要贡献包括：(i) 一个完全性定理，表明相关的线性泛函在 \(L^2(\mathbb{S}^{d-1})\) 中构成完全族，确立了描述符映射的渐近单射性；(ii) 由描述符诱导的半范数 \(|f|_{\mathcal{D},n} = \|P_n f\|_{L^2}\)，通过权重的Gram矩阵识别，并满足Parseval型恒等式 \(|f|_{\mathcal{D},n} \to \|f\|_{L^2(\mathbb{S}^{d-1})}\)（当 \(n \to \infty\)）。补充结果包括Fréchet可微性、遮挡下的下半连续性，以及依赖于核和温度的显式Lipschitz稳定性界。这些性质支撑了定位理论，其中描述符网格能够以可认证的静态误差界实现最近邻位置恢复，而机器人运动生成可观测性Gram矩阵，其最小特征值控制动态误差界，并在单观测匹配下普遍解决持续存在的对称性引起的模糊性。

## Abstract
We develop a functional-analytic framework for smooth directional point descriptors in GPS-free map-based localization. Given a query point $\mathbf{p}$ in a map $\mathcal{M} \subset \mathbb{R}^d$, the descriptor integrates an environment signal against a partition-of-unity weight family built from a softmax kernel, yielding a $\mathcal{C}^\infty$ alternative to hard angular binning. Our main contributions are: (i) a totality theorem showing that the associated linear functionals form a total family in $L^2(\mathbb{S}^{d-1})$, establishing asymptotic injectivity of the descriptor map; and (ii) a descriptor-induced seminorm $|f|_{\mathcal{D},n} = \|P_n f\|_{L^2}$, identified via the Gram matrix of the weights, which satisfies a Parseval-type identity $|f|_{\mathcal{D},n} \to \|f\|_{L^2(\mathbb{S}^{d-1})}$ as $n \to \infty$. Complementary results include Fréchet differentiability, lower semicontinuity under occlusion, and explicit Lipschitz stability bounds with constants depending on the kernel and temperature. These properties underpin a localization theory in which the descriptor grid enables nearest-neighbor position recovery with a certifiable static error bound, while robot motion generates an observability Gramian whose smallest eigenvalue controls a dynamic error bound and generically resolves symmetry-induced ambiguities that persist under single-observation matching.

## 2. 论文提出的方法论：核心思想、关键技术细节与公式

### 2.1 核心思想

描述符由三要素构成：**环境信号 \(f_p(\theta)\)**、**方向基 \(\{d_i\}_{i=1}^n\)** 和**单位分割权重族 \(\{w_i(\theta)\}\)**。特征分量定义为：

\[
\phi_i(p) = \int_{\mathbb{S}^{d-1}} f_p(\theta) w_i(\theta) \, d\sigma(\theta)
\]

**关键约束**：权重满足**单位分割（Partition of Unity, PoU）**：\(\sum_i w_i(\theta) = 1, \; w_i \ge 0\)，即：

\[
F(p) = \left[\phi_1(p), \ldots, \phi_n(p)\right]^\top \in \mathbb{R}^n
\]

### 2.2 权重构造：Softmax核（vMF型）

\[
w_i(\theta) = \frac{\exp(\theta^\top d_i / \varepsilon)}{\sum_{j=1}^n \exp(\theta^\top d_j / \varepsilon)}
\]

- **温度参数 \(\varepsilon\)**：控制权重集中度。当 \(\varepsilon \to 0\) 时，权重退化为硬分配的区域指示函数 \(w_i \to 1_{A_i}\)；当 \(\varepsilon \to +\infty\) 时，所有权重趋近 \(1/n\)（均匀平均）。
- **性质**：权重非负、归一化、\(\mathcal{C}^\infty\) 光滑，且对方向基的扰动具有（Lipschitz）连续性。

### 2.3 关键理论成果

| 理论结果 | 内容 |
|---------|------|
| **能量守恒** | \(\sum_i \phi_i(p) = \int f \, d\sigma\)，即描述符分解信号为无基的振幅分量与方向形状分量 |
| **渐近完全性/总量定理** | 当方向基网格间距 \(h_n \to 0\) 且 \(\varepsilon_n \to 0\) 时，线性泛函族 \(\{L_i^{(n)}\}\) 在 \(L^2(\mathbb{S}^{d-1})\) 中构成**总族**，描述符映射渐近单射 |
| **描述符诱导半范数** | \( |f|_{\mathcal{D},n} = \|P_n f\|_{L^2} \)，满足 **Parseval型恒等式** \(\lim_{n\to\infty} |f|_{\mathcal{D},n} = \|f\|_{L^2}\) |
| **Fréchet可微性** | Jacobian显式公式：\(J_F(p) = \int \nabla_p f_p(\theta) w(\theta)^\top d\sigma(\theta)\) |
| **遮挡下半连续性** | 在信号满足下半连续条件下，特征分量在 \(p\) 上也下半连续 |
| **Lipschitz稳定性** | 对不同方向基的扰动具有显式Lipschitz常数 \(\frac{(n+1)L_\psi}{Z_{\min}}\|f\|_{L^1}\delta\) |

### 2.4 定位框架

- **静态定位**：描述符网格上的最近邻搜索，误差界为 \(\|\hat{p} - p_*\| \le (Lh + \eta)/\mu(p_*)\)，其中 \(\mu(p_*) = \sigma_{\min}(J_F(p_*))\) 为局部单射半径。
- **动态定位**：沿轨迹定义**可观测性Gramian** \(W(0,T) = \int_0^T J_F^\top J_F \, dt\)，其最小特征值 \(\lambda_{\min}(W)\) 控制动态误差界，且随轨迹延伸单调增长。
- **对称性消解**：在对称环境（如走廊、圆形房间）中，单次观测无法定位（\(\mu = 0\)），但沿轨迹运动时，Gramian 在**generic**条件下严格正定，消除模糊性。
