## 摘要
使用轻量级拓扑地图的图像目标导航是室内机器人部署的一种实用范式：该地图仅需要地理标记图像，定位依赖于视觉匹配而非精确位姿估计。然而，学习型航点预测器可能产生违反几何约束或偏离全局路径的目标点。安全执行这些航点还需要具备避碰能力的局部规划器，但现有系统要么缺乏此类规划器，要么依赖无法适应狭窄空间的固定参数。为克服这些局限并保留学习预测器的导航直觉，我们提出EgoNav，一种层级系统，通过从语义分割的可通行区域生成候选航点，并将其与学习航点一起基于几何安全性、方向一致性和对学习先验的保真度进行评分来实现这一思想。随后，一个自适应局部路径规划器根据优化结果调整参数并执行细化后的航点。在Habitat-sim和物理人形机器人上的实验表明，EgoNav在成功率和路径效率方面均持续优于当代基线方法。

## Abstract
Image-goal navigation using lightweight topological maps is a practical paradigm for indoor robot deployment: the map requires only geotagged images, and localization relies on visual matching rather than precise pose estimation. However, learned waypoint predictors can produce targets that violate geometric constraints or deviate from the global path. Executing these waypoints safely further requires a local planner capable of collision avoidance, yet existing systems either lack one or rely on fixed parameters that cannot adapt to confined spaces. To address these limitations while retaining the navigational intuition of the learned predictor, we present EgoNav, a hierarchical system that implements this idea by generating candidates from semantically segmented traversable regions and scoring them alongside the learned waypoint for geometric safety, directional coherence, and fidelity to the learned prior. An adaptive local path planner then executes the refined waypoint with parameters modulated based on the refinement outcome. Experiments in Habitat-sim and on a physical humanoid robot show that EgoNav consistently outperforms contemporary baselines in both success rate and path efficiency.

## 论文核心问题与整体含义

- **研究背景**：室内机器人导航需要在全局路径感知与可靠局部控制之间取得平衡。传统依赖精确度量地图和全局定位的方法在定位漂移和环境变化下表现脆弱；无地图方法（如ObjectNav, VLN）则存在探索效率低、指令成本高等问题。
- **核心问题**：基于轻量拓扑地图的图像目标导航（ImageNav）虽然避免了精确位姿依赖，但学习型航点预测器（如GNM、ViNT）仅基于图像级特征进行预测，存在两个关键缺陷：
  1. **缺乏几何保证**：预测的航点可能落在障碍物上、违反可通行性约束，或偏离全局方向。
  2. **缺乏自适应局部规划**：现有系统要么没有局部碰撞避免规划器，要么使用固定参数控制器，无法适应狭窄空间。
- **整体意义**：论文提出EgoNav分层导航系统，在不丢弃学习先验的前提下，利用机载RGB-D传感器提供的局部深度和语义信息来验证与修正学习航点，并将修正结果直接用于调制下游局部规划器参数，实现"决策层耦合"的系统级创新。

## 方法论

### 核心思想
EgoNav采用三层分层策略：子目标检索 → 几何信息修正航点 → 自适应局部路径规划，其中修正模块的输出（修正幅度、航点离障碍物距离）直接反馈调制局部规划器的行为参数，形成显式信息流。这一决策层耦合是论文区别于既有ImageNav系统的核心贡献。

### 关键技术细节

**1. 地图引导的航点预测（Map-Guided Waypoint Prediction）**
- 使用序列式视觉位置识别（VPR，以MixVPR为特征骨干）将机器人定位到拓扑图中，并通过Dijkstra算法计算到目标的最短路径Γ。
- 沿Γ的滑动窗口持续匹配当前RGB图像，选择固定步数前方的节点作为子目标图像，与当前观测配对输入GNM，得到初始航点 ŵt。
- 设计了定位滤波与重定位机制：
  - **回溯抑制**：强制匹配索引单调不减（mt = max(frac{m_raw}{t}, m_{t−1})），防止视觉混叠导致索引倒退。
  - **跳变检测与重定位**：若索引单步前进超过阈值 jmax，判定匹配跳变，触发回溯（基于缓存的线速度命令回退），再通过短图像序列进行序列VPR重新定位，重规划Γ。

**2. 几何信息航点修正（Geometry-Informed Waypoint Refinement）**
- **可通行性引导的候选采样**：使用DFormerV2对RGB-D进行语义分割得到局部二值可通行地图，通过形态学细化提取骨架线，沿骨架以0.25m间隔采样候选航点，并与GNM初始预测共同构成候选集Wt。若深度与分割标签通过交叉模态一致性校验失败，则直接返回原始航点。
- **多准则能量评分**：对每个候选航点w计算加权能量函数：

  **E(w) = λs·Esafe(w) + λc·Ecoher(w) + λp·Eprior(w)**

  - **安全性 Esafe**：惩罚靠近障碍物的候选，使用sigmoid函数与局部窗口距离加权以抑制分割噪声；dsafe取自机器人足迹半径。
  - **方向一致性 Ecoher**：惩罚与全局导航方向（当前位姿到子目标的单位向量）的角度偏差，尤其修正转弯处GNM容易直行导致的过冲。
  - **先验保真度 Eprior**：惩罚偏离GNM预测超过阈值dprior的候选，由于ŵt本身在候选集中且Eprior=0，学习先验天然获得一个可被几何证据推翻的优先权。
- 能量项全部归一化到[0,1]，通过加权系数λ平衡。最终修正航点为 **wt\* = argmin E(w)**，并保留两个副产物：修正幅度δt和航点净空 d(wt\*)。

**3. 避碰路径生成（Collision-Free Path Generation）**
- 采用Falco作为基础局部规划器，利用深度点云计算碰撞检测，从运动学可行轨迹库中选取朝向修正航点wt*得分最高的轨迹组执行。
- **自适应规划器调制**：将修正模块的两个输出（航点净空d(wt\*)与修正幅度δt）分别转换为调制因子gc和gδ，通过线性插值动态调整四个规划器参数：
  - 轨迹尺度S（缩小以适配狭窄区域）
  - 碰撞容差N（提高以允许贴近边界）
  - 规划视距R（缩短以细化逐步规划）
  - 最大速度V（降低以匹配保守策略）
- 核心逻辑：环境越狭窄、修正幅度越大，规划器越趋于保守和精细化。

## 主要结论与发现

1. **整体优势**：EgoNav在仿真的短/中/长距任务中SR分别达96.7%/76.7%/60.0%，SPL达89.1%/64.9%/50.8%，全面碾压所有基线；真实世界相对仿真有明显下降，但优势格局不变。
2. **局部规划器的必要性**：PlaceNav+Falco（传感器公平基线）显著超越无局部规划器的所有方法，说明仅靠几何感知的局部规划就足以带来大幅提升。
3. **修正模块的独立价值**：EgoNav进一步全面超越PlaceNav+Falco，且差距随距离增加保持稳定，说明航点修正和修正感知调制解决了局部规划器无法单独解决的两类问题：转弯处的方向性错误和狭窄通道中过度保守的碰撞检查。
4. **消融顺序**：各模块对性能的贡献排序为：局部规划器（+10%）> 航点修正（+13.3%）≈ 定位滤波（+6.7%）> VPR检索（+10%）> 自适应调制（SPL提升0.4而无SR变化）。
5. **评分项重要性排序**：方向一致性（删除后SR下降20%）> 先验保真度（下降13.4%）> 安全性（SR不变、SPL下降，因为安全违规可被下游规划器碰撞检查兜底）。
