## 摘要
使用轻量级拓扑地图的图像目标导航是室内机器人部署的一种实用范式：地图仅需要地理标记图像，定位依赖于视觉匹配而非精确的姿态估计。然而，学习型航点预测器可能产生违反几何约束或偏离全局路径的目标。安全执行这些航点进一步需要一个能够避障的局部规划器，然而现有系统要么缺少局部规划器，要么依赖无法适应狭窄空间的固定参数。为了解决这些限制，同时保留学习预测器的导航直觉，我们提出了EgoNav，一个分层系统，它通过从语义分割的可通行区域生成候选，并将这些候选与学习航点一起评分，以评估几何安全性、方向一致性和对学习先验的忠实度。然后，自适应局部路径规划器根据优化结果调整参数，执行优化后的航点。在Habitat-sim仿真和实体人形机器人上的实验表明，EgoNav在成功率和路径效率方面均持续优于当代基线方法。

## Abstract
Image-goal navigation using lightweight topological maps is a practical paradigm for indoor robot deployment: the map requires only geotagged images, and localization relies on visual matching rather than precise pose estimation. However, learned waypoint predictors can produce targets that violate geometric constraints or deviate from the global path. Executing these waypoints safely further requires a local planner capable of collision avoidance, yet existing systems either lack one or rely on fixed parameters that cannot adapt to confined spaces. To address these limitations while retaining the navigational intuition of the learned predictor, we present EgoNav, a hierarchical system that implements this idea by generating candidates from semantically segmented traversable regions and scoring them alongside the learned waypoint for geometric safety, directional coherence, and fidelity to the learned prior. An adaptive local path planner then executes the refined waypoint with parameters modulated based on the refinement outcome. Experiments in Habitat-sim and on a physical humanoid robot show that EgoNav consistently outperforms contemporary baselines in both success rate and path efficiency.

## 1. 论文的核心问题与整体含义（研究动机和背景）

室内机器人的稳健导航需要同时具备全局路径感知和可靠的局部控制。传统基于精确度量地图和全局定位的方法在定位漂移、环境变化下易失效；无地图的替代方案（如目标目标导航、视觉语言导航）则存在探索效率低或依赖精细指令的问题。论文选择图像目标导航（Image-Goal Navigation）结合轻量拓扑图作为基础范式：地图仅由带地理标签的图像组成，定位通过视觉匹配而非精确位姿估计，构建和维护简单。

然而，现有系统存在两个关键缺陷：
- **学习型航点预测器（如 GNM、ViNT）** 仅从图像特征生成航点，缺乏几何保证，航点可能落在障碍物上、违反可通行性约束或偏离全局方向；
- **局部规划器缺失或参数固定**，无法适应狭小空间，导致避障失败或路径低效。

针对上述问题，论文提出 **EgoNav**：一个分层导航系统，在保留学习航点先验的同时，利用机载 RGB-D 传感器的深度和语义信息对航点进行几何校验与修正，并让局部规划器根据修正结果自适应调整行为，从而弥合“学习航点”与“几何安全控制”之间的鸿沟。

## 2. 论文提出的方法论（核心思想、关键技术细节）

EgoNav 采用三层级联结构：**子目标检索 → 航点预测与几何感知细化 → 自适应局部规划**，其核心在于决策层面的信息耦合。

### 2.1 地图引导的航点预测（Map-Guided Waypoint Prediction）
- 使用 MixVPR 作为视觉地点识别（VPR）特征主干，在预采集的拓扑图上进行序列式定位。
- 通过 Dijkstra 算法计算最短拓扑路径，并在导航过程中将当前观测与路径上的节点匹配，选取固定步长前方的节点作为子目标图像。
- 将当前图像与子目标图像输入预训练的 GNM 模型，得到初始航点 $\hat{w}_t = (x, y, \Delta\theta)_t$。

### 2.2 定位过滤与重定位
- 抑制 VPR 匹配的**回溯漂移**：强制匹配索引单调不减（$m_t = \max(m_t^{raw}, m_{t-1})$）。
- 检测**跳变式误匹配**（单次索引超过 $j_{max}$），触发回溯重定位：回放最近缓冲的速度指令，重新进行序列 VPR 定位并重规划路径。

### 2.3 几何信息航点细化（Geometry-Informed Waypoint Refinement）
- **可通行性引导的候选采样**：使用 DFormerV2 对 RGB-D 进行语义分割，得到二值可通行地图；通过形态学细化提取自由空间骨架，沿骨架每 0.25 m 采样候选航点，并将 GNM 预测也加入候选集。
- **跨模态一致性检查**：若可通行像素中深度低于安全距离的比例超过阈值 $\gamma$，则认为分割不可靠，直接返回原始预测。
- **多准则能量评分**：

$$
E(w) = \lambda_s E_{safe}(w) + \lambda_c E_{coher}(w) + \lambda_p E_{prior}(w)
$$

其中：
- **安全项** $E_{safe}$：对靠近障碍物的候选施加惩罚，使用逻辑斯蒂函数，安全阈值 $d_{safe}$ 由机器人足迹半径推导。
- **方向一致性项** $E_{coher}$：鼓励候选方向与从当前位置到子目标的全局方向对齐，使用夹角余弦距离衡量。
- **先验忠实度项** $E_{prior}$：鼓励候选不偏离 GNM 预测过远，$d_{prior}=2d_{safe}$，使得学习预测在无充分几何证据时天然占优。

最终选择能量最低的候选作为修正航点 $w_t^*$，并计算两个副产品：**修正幅度** $\delta_t = \|w_t^* - \hat{w}_t\|$ 和**航点安全裕度** $d(w_t^*)$，用于后续规划器参数调制。

### 2.4 无碰撞路径生成（Collision-Free Path Generation）
- 以 Falco 为基础局部规划器，利用深度点云对预计算轨迹库进行快速碰撞检测和评分。
- **自适应参数调制**：根据 $d(w_t^*)$ 和 $\delta_t$ 动态调整轨迹尺度、碰撞容忍度、规划视距和最大速度。例如，安全裕度小则缩小规划范围、提高碰撞容忍度；修正幅度大则缩短视距、降低速度。这样使规划器在开阔空间保持敏捷，在狭窄区域更加谨慎。

## 6. 论文的主要结论与发现

- **EgoNav 在仿真和真实环境中均优于全部基线**。仿真中，短、中、长距离的 SR 分别达到 96.7%、76.7%、60.0%，而最佳基线 PlaceNav+Falco 为 80.0%、56.7%、46.7%；SPL 也全面领先。
- **VPR 检索优于固定顺序子目标选择**：PlaceNav 在所有距离上优于原始 GNM，说明位置感知的子目标检索可显著提升导航性能。
- **仅添加深度局部规划器（PlaceNav+Falco）即可大幅提升成功率**，说明碰撞避免是前向预测方法的主要短板。
- **航点细化主要解决方向性错误**：移除方向一致性项 $E_{coher}$ 导致成功率下降最严重，证明在转弯处纠正学习航点的全局方向是关键。
- **先验项 $E_{prior}$ 防止过度“几何化”**：移除后候选偏向贴墙位置，降低了路径质量；安全项 $E_{safe}$ 虽不影响 SR 但影响 SPL。
- **自适应规划器调制提升路径效率而不牺牲成功率**：更宽松的碰撞容忍和精细搜索在狭窄区域产生更短更平滑的轨迹。
- **定位过滤与重定位对长距离导航贡献明显**：可恢复 VPR 跳变导致的定位失败，进一步提升 SR。
- **系统总延迟约 160 ms**，满足实际室内移动机器人 5 Hz 控制需求。

## 7. 优点（方法与实验亮点）

- **系统级贡献而非单一算法**：将学习航点预测、几何细化和自适应局部规划通过显式信息流耦合，细分模块之间共享修正幅度和安全裕度，具有清晰的决策级协同设计。
- **保留学习先验的同时纠正几何缺陷**：通过能量评分中的先验项，避免完全抛弃 GNM 的导航直觉，形成“软修正”而非硬替换。
- **骨架采样策略**：沿可通行区域中轴采样候选，相比均匀网格更利于走廊和门洞穿越，符合室内导航经验。
- **跨模态一致性检查**：以深度原始数据校验语义分割，防止分割错误导致细化失效，增强鲁棒性。
- **定位过滤与重定位机制**：针对 VPR 的已知痛点（回溯漂移、跳变误匹配）设计了简单有效的工程补救措施。
- **丰富且结构化的实验**：仿真与真实人形机器人对照、多个基线、逐步消融和单项评分消融，能够清晰归因各模块贡献；参数在留出集上固定，避免过拟合评测场景。

## 8. 不足与局限

- **学习航点的泛化边界未深究**：GNM 等预测器受训练分布限制，EgoNav 并未改进预测器本身，只是在其周围添加修正，遇到分布外场景时仍可能给出严重偏离的航点。
- **动态障碍物处理能力有限**：避障依赖 Falco 的反应式机制，只适用于低密度移动障碍；快速随机轨迹的障碍难以躲避，且躲避绕行可能脱离拓扑图覆盖范围，触发重定位而降低成功率。论文也承认缺乏速度级推理和轨迹预测。
- **依赖语义分割与 VPR 的可靠性**：分割错误虽有跨模态检查，但若深度同样不可靠（如玻璃、反光表面）则检查可能失效；VPR 在场景光照变化较大时匹配质量下降，导致真实环境整体性能相比仿真有明显下降。
- **局部规划器基于 Falco 轨迹库**：轨迹库的运动原语受限于预设模式，对非常规地形或非完整约束较强的机器人可能不够灵活；未与更先进的自适应规划方案（如优化法、变形法等）对比。
- **真实实验场景仅为单栋办公楼**，场景类型有限；动态障碍实验的真实 episode 数量较少（10 个），统计显著性可能不足。
