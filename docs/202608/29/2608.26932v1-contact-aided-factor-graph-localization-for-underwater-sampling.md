## 摘要
自主水下航行器在执行近底海底采样时的精确状态估计仍然具有挑战性。在低空作业中，俯视相机面对无特征平坦海底会产生尺度模糊、横向退化以及特征跟踪不一致的问题。同时，惯性-多普勒测速仪（DVL）融合单独无法提供结构漂移校正机制。我们提出了一种接触辅助的因子图定位框架，将物理交互视为平滑式定位公式中的信息性几何约束。该方法紧密融合了基于吸力的机械臂接触事件与自适应视觉里程计、学习型目标检测以及机载传感器。视觉里程计相对位姿因子和地标方位-距离因子根据内点统计进行不确定性缩放，以防止视觉较弱的帧破坏估计器稳定性，而接触事件被建模为高置信度因子，无需基于外观的位置识别即可诱导隐式闭环。此外，系统能够在运动过程中完全在线初始化。在实验水池、港口和仿真环境中的实验评估表明，与基于滤波的导航和无接触图公式相比，接触引起的约束显著降低了轨迹漂移并提高了目标重访精度。这些结果凸显了具身物理交互在感知退化水下环境中作为定位原语的作用。

## Abstract
Accurate state estimation for autonomous underwater vehicles performing close-range seafloor sampling remains challenging. In low-altitude operation, down-looking cameras over featureless planar seabeds produce scale ambiguity, lateral degeneracy, and inconsistent feature tracking. Meanwhile, inertial-Doppler Velocity Log (DVL) fusion alone provides no mechanism for structural drift correction. We propose a Contact-Aided Factor-Graph Localization framework that treats physical interaction as an informative geometric constraint within a smoothing-based localization formulation. The method tightly fuses suction-based manipulator contact events with adaptive visual odometry, learned object detections, and on-board sensors. Visual odometry relative-pose factors and landmark bearing-range factors are uncertainty-scaled according to inlier statistics to prevent visually weak frames from destabilizing the estimator, while contact events are modeled as high-confidence factors that induce implicit loop closures without appearance-based place recognition. Furthermore, the system can fully initialize online during motion. Experimental evaluation in tanks, harbor, and simulation environments demonstrates that contact-induced constraints significantly reduce trajectory drift and improve object revisit accuracy compared to filtering-based navigation and contact-free graph formulations. These results highlight the role of embodied physical interaction as a localization primitive in perception-degraded underwater environments

## 2. 论文提出的方法论

### 2.1 总体框架
- 基于 **GTSAM/iSAM2** 实现因子图平滑（smoothing）框架，联合估计车辆位姿、速度、IMU偏置和环境地标。
- 系统可**完全在线初始化**（无需静止或专用引导阶段），IMU、磁力计、压力计和DVL数据到达后即可构建初始状态。

### 2.2 惯性传感器融合
- **IMU预积分**：采用标准预积分理论，将加速度和角速度转换为相邻状态间的相对运动增量，构建IMU因子，并联合估计加速度计偏置 $b_a$ 和陀螺仪偏置 $b_\omega$。
- **DVL速度因子**：利用杆臂校正（lever-arm compensation）修正DVL体坐标系速度，再转换到IMU坐标系，形成速度因子。
- **压力深度因子**：通过温度补偿的密度模型将压力转换为深度，作为垂直位置的先验约束。
- **磁力计偏航因子**：提供绕重力轴的偏航角测量。
- 上述传感器共同构成"惯性骨干"，确保视觉结构弱或间歇时仍能保持稳定的姿态估计。

### 2.3 自适应视觉里程计（VO）
- **图像增强与特征提取**：CLAHE对比度增强，ORB特征+BRISK特征回退，Hamming距离+比值检验匹配。
- **尺度恢复**：单目本质矩阵分解得到相对旋转和归一化平移方向，度量尺度通过DVL/声呐高度或压力深度恢复，并统一转换到车体坐标系。
- **自适应不确定度缩放**：根据RANSAC内点比例 $\eta = N_{inliers}/N_{matches}$ 计算自适应协方差，经指数移动平均平滑并截断在合理边界内。以此**抑制视觉弱帧对估计器的负面影响**。

### 2.4 视觉地标检测
- 使用YOLOv8检测俯视相机中的海星目标，从边界框高度估计斜距，反投影像素中心获得归一化相机坐标方位。
- 每个检测贡献一个**方位-距离因子（bearing-range factor）**，低置信度或小边界框检测的不确定性会被放大。
- 地标同时在末端执行器坐标系中表达，便于与接触事件直接锚定，实现接触一致的建图。

### 2.5 混合局部束调整（Hybrid Local Bundle Adjustment）
- 滑动窗口（最近 $N$ 个位姿）内，若窗口位姿连接了视觉地标，则执行**地标增强的LBA**；否则退化为**纯位姿优化（pose-only fallback）**。
- 窗口外但与子图相连的位姿施加强先验以避免规范自由度（gauge freedom）问题，使用有界Levenberg-Marquardt迭代求解。

### 2.6 接触感知约束（核心创新）
- 机械臂采用加速度级逆运动学控制器，通过关节编码器正运动学得到末端执行器在世界系中的位姿：$T^{w}_{ee}(k) = T^{w}_{b}(k) \cdot T^{b}_{ee}(\theta_k)$。
- **接触事件建模**：当吸盘接通（rising-edge事件）时，当前末端位置 $p_{ee}$ 被视为环境中的点测量：
  - 若已存在距离小于阈值 $\epsilon$ 的地标 $l_j$，则在当前位姿与地标间添加**方位-距离接触因子**；
  - 否则在接触点初始化新地标，并添加零距离因子。
- 采用紧致各向同性噪声模型 $\Sigma_c$，提供高置信度的几何约束。
- **关键机制**：当末端执行器接触到一个先前已映射的物体时，该机制产生**隐式闭环**，完全无需外观识别——这是本文区别于传统SLAM的核心创新。

### 2.7 算法流程总结
```
数据输入(IMU/DVL/Pressure/Mag/Camera/机械臂编码器/吸盘状态) 
→ 在线初始化(非静止) 
→ 每帧处理：
   ├─ IMU预积分 + DVL速度 + 压力深度 + 磁力计偏航 → 因子添加
   ├─ 自适应VO → 相对位姿因子 + 速度因子（协方差按内点比缩放）
   ├─ YOLO检测 → 地标方位-距离因子
   ├─ 吸盘接触事件 → 高置信接触因子（隐式闭环）
   └─ 混合LBA（滑动窗口内按地标存在性切换优化模式）
→ iSAM2增量式后端优化 → 实时输出位姿估计
```

## 6. 论文的主要结论与发现

1. **平面旋转放大漂移**：在平坦、低纹理海床上执行重复180°偏航旋转会显著增加ATE（T2达0.2917 m），说明横向与偏航可观测性极弱。
2. **垂直激励改善可观测性**：加入深度变化后，ATE从0.2917 m降至0.1954 m（T4），结合地标进一步降至0.1651 m（T5），偏航RMSE从0.1232 rad降至0.0412 rad——垂直运动有助于恢复尺度与偏航可观测性。
3. **视觉地标主要稳定朝向，但无法完全消除漂移**：单靠海星视觉地标（T3）能改善偏航RMSE（0.0867 rad），但ATE反而上升（0.3514 m），说明单个视觉地标无法约束全局平面退化。
4. **接触约束持续改善任务级一致性**：在第二水池中，重访误差从无地标时的0.58 m降至有地标时的0.50 m，再降至加入泵激活后的0.45 m；港口实验中同样从1.23 m降至0.90 m。**单调递减趋势证明接触约束是独立于视觉地标的额外结构性信息**。
5. **消融研究一致性**：完整配置（FG-UCAL-Full）在所有配置中Pareto距离最优（0.6909），移除局部BA、相机更新或弱化传感器耦合均导致性能下降。
6. **物理接触可作为定位原语**：在感知退化的水下环境中，吸盘接触事件提供度量和锚定的几何约束，无需外观识别即可诱导隐式闭环，显著提升长期采样任务中的全局一致性。

## 7. 方法或实验设计的优点

1. **概念创新性强**：首次将物理接触建模为水下SLAM中的因子图约束，将"交互"从任务层提升到估计层，开辟了感知退化环境定位的新思路。
2. **不确定性建模精细**：基于内点统计的EMA平滑自适应协方差缩放，既保留了信息丰富的视觉约束，又有效压制退化帧的负面影响——工程上非常实用。
3. **混合优化策略务实**：滑动窗口内根据地标存在性自动切换地标增强LBA与纯位姿优化，兼顾精度与实时性，针对间歇性视觉结构问题给出了简洁解决方案。
4. **多模态耦合完整**：IMU/DVL/压力/磁力计/自适应VO/目标检测/接触因子在统一因子图中紧耦合，每个传感器的作用都有清晰的因子建模。
5. **实验验证链条完整**：仿真（地面真值）+两个受控水池（不同光照条件）+真实港口部署（浊度和扰动），从绝对精度到任务级指标全面评估。
6. **消融研究系统深入**：既有传感器级别的移除实验，也有超参数级别的窗口长度、IMU预积分采样数量变化，辅以Pareto多目标分析，方法论严谨。
7. **对退化环境有定量刻画**：通过关键点数量、跟踪比例、光流中值和梯度幅值等统计量，客观量化了环境退化程度，增强了问题论证的说服力。
