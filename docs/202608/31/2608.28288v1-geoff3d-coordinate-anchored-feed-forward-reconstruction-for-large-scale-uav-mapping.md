## 摘要
现有前馈3D重建方法通常处理有限数量的图像，并在局部或内部归一化坐标系中恢复相机位姿和几何结构。将其扩展到大规模无人机测绘需要可扩展的多块处理和可靠的聚合，而完整的Sim(3)对齐在近共线轨迹下可能变得不稳定。我们提出GeoFF3D，它结合了坐标锚定模型与空间大规模重建框架（SLRF）。该模型利用地理参考的相机平移和可选的几何先验，直接在重力对齐的Z向上度量坐标系中预测相机位姿和密集点图。SLRF将图像划分为空间重叠的块，传播共享视图先验，并分层聚合局部重建结果，同时适用于不同的有界视图模型。在九个航空测绘块上，GeoFF3D实现了最佳平均重建质量，将F@5从Pi3X + SLRF的0.829提升到0.877。在长序列UAVScenes上，它达到0.848，而Pi3X + SLRF为0.687，最强评估的SLAM/流式基线为0.451。GeoFF3D在大约五分钟内重建2000张图像，展示了可扩展且稳健的大规模无人机重建能力。代码可在https://github.com/yanxian-ll/GeoFF3D获取。

## Abstract
Existing feed-forward 3D reconstruction methods typically process a bounded number of images and recover cameras and geometry in local or internally normalized frames. Extending them to large-scale UAV mapping requires scalable multi-chunk processing and reliable aggregation, while full Sim(3) alignment can become unstable for near collinear trajectories. We present GeoFF3D, which combines a coordinate-anchored model with a spatial large-scale reconstruction framework (SLRF). The model uses georeferenced camera translations and optional geometric priors to predict camera poses and dense point maps directly in a gravity-aligned Z-up metric frame. SLRF partitions images into spatially overlapping chunks, propagates shared-view priors, and aggregates local reconstructions hierarchically, while remaining applicable to different bounded-view models. Across nine aerial mapping blocks, GeoFF3D achieves the best average reconstruction quality, improving F@5 from 0.829 for Pi3X + SLRF to 0.877. On long UAVScenes sequences, it reaches 0.848, compared with 0.687 for Pi3X + SLRF and 0.451 for the strongest evaluated SLAM/streaming baseline. GeoFF3D reconstructs 2,000 images in approximately five minutes, demonstrating scalable and robust large-scale UAV reconstruction.The code is available at https://github.com/yanxian-ll/GeoFF3D.

## 1. 核心问题与研究动机

- **背景**：无人机倾斜摄影测量广泛应用于城市建模、地形测绘、灾害评估等大规模三维场景采集。传统摄影测量系统依赖多阶段几何估计和迭代优化（如 SfM/MVS），虽然精度可靠但计算开销巨大。近年来，前馈重建模型（如 DUSt3R、Pi3、VGGT 等）可直接从多视图图像预测相机参数和稠密几何，效率更高。
- **现有方法的局限**：
  - 大多只能处理有界数量（bounded）的图像，无法直接扩展到包含数百至数千张影像的真实 UAV 航测任务。
  - 输出的相机位姿和点云通常在**参考相机坐标系**或**内部归一化坐标系**中，而实际测绘需要统一的地理参考、重力对齐的度量坐标系。
  - 将局部重建结果地理配准时，常用完整 Sim(3) 变换对齐，但对于**近共线（near-collinear）无人机轨迹**，滚转和俯仰角约束不足，可能导致重建结果被错误倾斜。
  - 大影像集合需分块处理，独立重建的块之间在共享视图上的深度、坐标帧存在不一致，造成表面重复、垂直偏移和接缝可见。
- **核心问题**：如何将前馈重建方法扩展到大规模无人机影像，并在无需全局优化的前提下获得统一、地理参考、重力对齐的高质量稠密重建？

## 2. 方法论：GeoFF3D 的核心思想与技术细节

### 核心思想
> 利用地理参考先验（尤其是相机平移）**直接定义预测坐标系**，而非在内部坐标系重建后再进行对齐；同时以重力方向约束稳定垂直方向，避免近共线轨迹下 Sim(3) 对齐的不稳定性。

### 整体框架
GeoFF3D 由两部分组成：
1. **坐标锚定前馈模型（Coordinate-Anchored Feed-Forward Model）**：负责有界视角数量的局部稠密重建。
2. **空间大规模重建框架（SLRF, Spatial Large-Scale Reconstruction Framework)**：负责将局部重建扩展到包含数百至数千张影像的大规模数据集。

### 坐标锚定模型的关键技术

- **坐标系**：在局部地理参考笛卡尔坐标系中预测相机位姿与几何，Z 轴与重力方向相反（Z-up），X-Y 平面平行于当地水平面。使用平移锚点计算平移中心 \(c_T\) 和场景尺度 \(s_T\) 进行归一化，推理后再恢复到地理参考度量帧。
- **先验编码**：
  - 图像编码器产生视觉 patch token。
  - 射线方向、深度观测作为 patch 级特征，与图像 token 空间对应。
  - 归一化的地理参考平移向量和可选的旋转矩阵作为**视图级嵌入**，广播到该视图的所有 patch token。
  - 融合表示 \(F_i = F^I_i + m^R_i F^R_i + m^D_i F^D_i + m^t_i e^t_i + m^r_i e^r_i\)，其中 mask 表示先验可用性；训练时随机丢弃先验，增强鲁棒性。
- **预测头**：
  - 相机头预测每个视图的相机到世界变换 \(^c W_{c\to w} \in SE(3)\)。
  - 稠密头预测像素级射线方向和 Z 深度，再通过变换和反归一化得到世界坐标点：\(\hat{X}^w_i(u) = s_T \pi_3(^c W_{c\to w} [\hat{d}_i(u)\hat{r}_i(u); 1]) + c_T\)。
  - 另有置信度头抑制不可靠几何。
- **训练**：初始化自预训练 Pi3X，在 UAVFF3D 和 BlendedMVS 上训练。损失函数：
  \[
  L = \lambda_{local}L_{local} + \lambda_{world}L_{world} + \lambda_{pose}L_{pose} + \lambda_{grav}L_{grav}
  \]
  其中 \(L_{world}\) 和 \(L_{pose}\) 监督地理参考帧中的绝对位姿与稠密点，使模型学习锚点定义的坐标系；\(L_{grav}\) 约束预测相机上与重力的对齐（主要约束 roll/pitch）。两阶段训练：80 epoch @224px + 10 epoch @518px。

### SLRF 的关键技术

- **足印引导的空间分块（Footprint-Guided Spatial Chunking）**：利用 GNSS/IMU 估计每张影像的地面足印，依据空间覆盖而非采集顺序构建自适应二叉树，将影像划分为空间上紧凑的叶子块。每块含核心视图（保留用于最终融合）和接缝视图（提供重叠、用于深度传播和对齐）。每块视图数不超过 M 且核心视图数 ≤ 0.7M。
- **从中心向外的推理与先验传播（Center-Outward Inference & Prior Propagation）**：构建空间邻接图，从场景中心块开始广度优先处理。维护按图像索引的深度缓存：推理前将共享视图的缓存深度作为输入先验；推理后过滤低置信度区域（分位数阈值 0.25），更新缓存，并优先保留核心视图的深度。若内参未知且相机相同，则用第一块预测的平均内参作为后续输入。
- **重力对齐的层级聚合（Gravity-Aligned Hierarchical Aggregation）**：
  - 叶子块先用**重力对齐相似变换（GA-Sim）**：\(T_{GA-Sim}(x) = sR_z(\theta)x + t\)，估计尺度、偏航角和三维平移，保持 roll/pitch。
  - 兄弟块之间用**重力对齐刚体变换（GA-Rigid）**：\(T_{GA-Rigid}(x) = R_z(\Delta\theta)x + \Delta t\)，仅估计残余偏航和平移。
  - 沿足印树从叶子到根自底向上累积变换，最终仅融合置信度过滤后的核心视图几何。整个过程不扰动 Z-up 方向。

## 6. 主要结论与发现

- 在 9 个航空测绘块上，GeoFF3D 获得最佳平均 Accuracy（2.72m）、Completeness（2.59m）、F@1（0.267）和 F@5（0.877）。相比 Pi3X+SLRF，Accuracy 降低 18.7%，Completeness 降低 15.8%，F@5 提升 0.048。
- 在长 UAVScenes 序列上优势更大：Accuracy 从 6.05m 降至 4.14m（降 31.5%），Completeness 从 4.40m 降至 2.28m（降 48.2%），F@1 从 0.181 提升至 0.319，F@5 从 0.687 提升至 0.848；显著优于最强 SLAM/流式基线 LingBot-Map（F@5=0.451）。
- 消融证明：世界坐标系损失建立了平移锚点定义的坐标系（去除后性能大幅下降）；重力监督持续降低 GDE；GA-Sim/GA-Rigid 相比完整 Sim(3) 在保持重力对齐几何方面更好；足印层级分块与先验传播显著优于时间顺序处理。
- GeoFF3D 对噪声位姿具有一定鲁棒性（2×噪声下性能稳定），但完全移除旋转先验会导致较大退化。
- 系统可扩展性良好：2,000 张图像约 5 分钟完成，显存约 16 GiB，运行时间近似线性增长。
- 核心结论：**坐标锚定**（用先验定义预测坐标系）和**重力约束**是提升大规模、近共线轨迹重建质量的关键；SLRF 提供了一种与具体有界视角模型解耦的大规模处理方案。

## 7. 优点

- **思想新颖**：将地理参考先验从“后处理配准”提升为“预测坐标系的定义依据”，规避了完整 Sim(3) 在退化轨迹下的不稳定性。
- **设计简洁且模块化**：SLRF 可包装任意有界视角前馈模型（仅当模型支持先验传播时才启用传播），具备通用性。
- **工程考虑周全**：包括足印引导分块、共享深度缓存、置信度过滤、重力保持变换等，针对 UAV 测绘的实际痛点（多航线、近共线、跨块接缝）逐一解决。
- **实验扎实**：主实验+消融+鲁棒性+可扩展性+定性泛化，覆盖全面；长序列提供逐序列数据，透明度高。
- **高效**：对比传统方法和流式方法，推理速度快、显存占用低，适合实际大规模任务。

## 8. 不足与局限

- **实验覆盖偏差**：未与传统全局 SfM 方法（如 COLMAP）或经典摄影测量软件进行定量对比，无法评估相对传统工作流的精度/效率权衡。
- **场景局限性**：UAVScenes 中部分山谷场景（Valley01/02）性能不佳，表明近共线+地形起伏同时存在时，仅靠平移锚点和重力可能仍不足以约束尺度/姿态。
- **对位姿先验的依赖**：虽然对噪声有一定鲁棒性，但完全去掉旋转先验时性能显著下降；在 GNSS/IMU 精度极差或缺失的场景（如室内、GNSS 拒止环境）适用性受限。
- **无在线重建**：当前是离线批次处理，未来需扩展至在线/流式模式。
- **评估指标局限**：使用 F@1/F@5 等阈值指标可能对均匀性不敏感；垂直方向误差与水平方向误差未单独拆分报告（仅消融中部分体现）。
- **定性数据集无量化**：NPU-DroneMap 仅定性展示，未提供任何度量指标，泛化结论缺乏定量支撑。
- **训练成本未充分披露**：未说明训练总时长、数据量、训练消耗的详细资源开销，对可复现性有一定影响。
