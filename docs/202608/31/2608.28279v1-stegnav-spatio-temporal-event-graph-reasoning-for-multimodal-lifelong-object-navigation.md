## 摘要
多模态终身导航要求智能体在自主探索未见环境的同时，按顺序完成由物体类别、语言描述或参考图像指定的导航任务。现有方法主要通过构建以状态为中心的语义场景图来完成任务。通过将场景图视为语义观测的持久存储库，这些方法难以区分相似实例、联合表示语义目标与探索前沿，并有效利用导航记忆与轨迹经验。为解决这些局限，我们提出了时空事件图导航（STEGNav），一种无需训练的框架，它沿互补的空间与时间轴将传统场景图扩展为时空事件图。空间轴执行基于查询条件的实例定位，并联合表示语义目标与具有可达性、路径成本和探索效用的占据感知探索前沿。时间轴采用轨迹感知的双窗口记忆，以保留最近的决策-轨迹事件和经过验证的跨子任务导航结果。基于VLM的导航代理对生成的时空事件图进行推理，并选择目标实例或探索前沿作为其下一个导航目标。STEGNav在GOAT-Bench上达到66.3%的SR和39.7的SPL，在HM3Dv1和HM3Dv2上分别获得64.0%和69.4%的SR分数。消融研究和错误分析验证了两个轴的互补效应，表明事件驱动的时空表示提高了导航可靠性和跨子任务经验复用。

## Abstract
Multimodal lifelong navigation requires an agent to autonomously explore unseen environments while sequentially completing navigation tasks specified by object categories, language descriptions, or reference images. Existing methods primarily accomplish these tasks by constructing state-centric semantic scene graphs. By treating scene graphs as persistent repositories of semantic observations, these methods struggle to distinguish similar instances, jointly represent semantic targets and exploration frontiers, and effectively exploit navigation memory and trajectory experience. To address these limitations, we propose Spatio-Temporal Event Graph Navigation (STEGNav), a training-free framework that extends conventional scene graphs into spatio-temporal event graphs along complementary spatial and temporal axes. The spatial axis performs query-conditioned instance grounding and jointly represents semantic targets and occupancy-aware exploration frontiers characterized by reachability, path cost, and exploration utility. The temporal axis employs trajectory-aware dual-window memory to retain recent decision--trajectory events and verified cross-subtask navigation outcomes. A VLM-based navigation agent reasons over the resulting spatio-temporal event graph and selects either a target instance or an exploration frontier as its next navigation goal. STEGNav achieves 66.3% SR and 39.7 SPL on GOAT-Bench, as well as SR scores of 64.0% and 69.4% on HM3Dv1 and HM3Dv2, respectively. Ablation studies and error analyses validate the complementary effects of the two axes, demonstrating that event-driven spatio-temporal representations improve navigation reliability and cross-subtask experience reuse.

## 1. 核心问题与研究动机

- **背景**：多模态终身导航要求智能体在完全未知的环境中，按顺序完成由**物体类别**、**语言描述**或**参考图像**指定的多个连续导航子任务。这不仅需要理解不同模态的查询，还需要在长时间、跨子任务的导航过程中持续探索环境并复用已获取的知识。
- **现有方法的不足**：主流方法依赖**以状态为中心的语义场景图**（state-centric semantic scene graphs），将场景图视为语义观测的静态存储库，导致三大局限：
  - **实例混淆**：无法区分同一语义类别下的不同物理实例，例如多个"沙发"、多个"桌子"；
  - **语义-空间分离**：语义目标节点与基于占据图生成的探索前沿（frontier）被割裂为独立输入，VLM 无法联合推理目标身份、可通行性和探索效用；
  - **时间维度缺失**：场景图只记录当前环境状态，不记录导航过程和历史决策，导致重复探索、记忆遗忘以及已验证经验难以复用。
- **核心主张**：多模态终身导航本质上是**事件驱动**的——每次导航决策都会同时改变智能体的空间知识与可供未来导航使用的历史经验。因此，应将静态场景图升级为**时空事件图**。

## 2. 方法论

### 2.1 核心思想
- 提出 **STEGNav（Spatio-Temporal Event Graph Navigation）**，一个**无需训练（training-free）** 的框架。
- 将传统场景图沿**空间轴**和**时间轴**两个互补维度扩展为时空事件图，由 VLM（ChatGPT-5.4-mini）统一推理并决策。

### 2.2 空间轴：多层语义-导航图（Spatial Axis）
- **查询条件实例定位（Query-Conditioned Instance Grounding）**：
  - 先用类别预过滤器 P 保留语义相关节点；
  - 再用 VLM 实例定位模块 Φ_inst 评估每个保留节点，输出查询-实例相关性 r(i) 和查询条件化语言描述 d(i)；
  - 对图像查询，比较参考图像与存储实例外观；对语言查询，将目标属性与实例外观、房间、空间上下文对应；类别查询不做实例级剪枝。
- **占据感知前沿定位（Occupancy-Aware Frontier Grounding）**：
  - 将前沿栅格聚类为前沿节点，每个节点记录空间中心、可达路径距离、探索增益、最近访问状态；
  - 前沿节点与附近语义节点建立前沿-语义边，描述前沿通向的局部语义环境；
  - 占据图建立智能体节点到物体/前沿节点的导航边，统一记录可达性和测地路径代价；
  - 最终将候选物体与探索前沿置于同一图结构，使 VLM 可在同一表示中直接权衡目标相关性与探索效用。

### 2.3 时间轴：轨迹感知双窗口记忆（Temporal Axis）
- **短期决策-轨迹窗口**：保留最近 Wst=20 次高层决策及其轨迹段，记录所选节点、轨迹端点、穿越语义区域、路径长度和执行结果；连续事件通过时间边连接，并投影到当前空间图以更新前沿访问状态。该窗口允许 VLM 识别重复导航模式，但**不施加硬性探索约束**；子任务结束时清空。
- **长期任务事件窗口**：仅保留经过阳性 VLM 验证的跨子任务结果（Wlt=8 个），验证条件为
  - w_k = 1 ⟺ iterm_k = i*_k ∧ o_k = + ∧ d_k ≤ δ（δ=0.8m，严于基准成功阈值）；
  - 存储为事件锚点（实例标识、目标类别、查询模态、历史查询、终端外观特征、房间标签），无固定坐标；
  - 通过持久标识符或 CLIP 外观相似度（接受阈值 γ_hi=0.92，拒绝阈值 γ_lo=0.70）重新关联实时场景图，歧义情况由 VLM 验证器裁决。
- **重要约束**：类别级查询产生的锚点不能验证后续图像或描述查询，避免类别级证据误用于实例级任务。

### 2.4 整体流程
- 每个决策步骤：构建查询事件 u_k → 时间窗口关联（TemporalLink）→ 实例定位 → 前沿提取 → 构建空间图 → 组装事件图 → VLM 选择物体节点或前沿节点 → 执行导航/探索 → 更新场景图和占据图 → 验证并更新长期记忆。
- 序列化图暴露给 VLM 的信息包括：查询条件化实例描述、相关性分数、当前可达性、前沿探索效用、近期决策轨迹、已验证历史结果。

## 6. 主要结论与发现

- **GOAT-Bench**：SR 66.3%、SPL 39.7；相比最强 SR 基线 MSGNav 提升 3.9 个百分点；相比同协议最强 SPL 基线 EvoMemNav，SR/SPL 分别提升 6.7%/0.8。
- **HM3D**：SR 64.0%（HM3Dv1）与 69.4%（HM3Dv2），均为最高 SR，较前最好结果分别提升 3.8% 和 5.6%；但 SPL 不是最优（29.8/28.2），说明成功率优势尚未完全转化为路径效率优势。
- **消融结论**：
  - 3D 场景图本身带来显著提升（45.7→55.8 SR）；
  - 查询条件实例定位（QIG）对语言和图像查询增益明显；
  - 占据感知前沿定位（OFG）是增量最大的组件，尤其提升图像查询 SR/SPL（+10.2/+5.8）；
  - 双窗口记忆（DWM）进一步提升图像查询 SR（68.2→73.9），验证跨子任务经验复用的价值。
- **错误分析**：总失败数从 123 降至 81（减少 34.1%）；其中实例混淆减少 53.8%（13→6），低效探索减少 40.0%（45→27），记忆召回失败 25→18，目标定位失败 22→16；执行/停止失败仅从 18→14，表明低层控制问题仍有待解决。

## 7. 优点

- **无需训练**：完全基于预训练模型与在线推理，无需针对导航任务进行任何参数训练。
- **多模态统一推理**：将物体类别、语言描述、参考图像三种查询模态纳入同一事件图框架，由单一 VLM 决策。
- **时空双轴互补设计**：空间轴解决"什么目标、怎么到达"，时间轴解决"去过哪里、学到什么"，二者协同提升导航可靠性与跨子任务经验复用。
- **保持长期记忆的鲁棒性**：长期锚点不存固定坐标，而是通过持久标识符+外观相似度+房间一致性+轻量 VLM 验证重新关联实时图，避免因坐标系漂移或图节点合并导致的失效。
- **硬约束与软提示平衡**：短期轨迹不作为硬性禁止访问约束，而是作为证据提示暴露给 VLM，保留决策灵活性。
- **验证过程自包含**：内部验证不使用模拟器 ground truth，而依赖 VLM 对观测的判断，更贴近真实部署场景。
- **严格的验证门槛**：内部验证距离 δ=0.8m 严于基准的 1.0m，保证长期记忆质量。

## 8. 不足与局限

- **SPL 短板**：在 HM3D 上 SR 最高但 SPL 非最优，表明高成功率未充分转化为路径效率，导航路径存在冗余；GOAT-Bench 上 SPL 增益也较小（+0.8）。
- **低层控制未触及**：错误分析显示执行/停止失败改进有限（18→14），方法只作用于高层目标选择，低层运动规划与终止决策仍有明显提升空间。
- **消融范围有限**：消融仅在固定子集（每场景 1 episode）上进行，样本量有限；未报告完整拆分上的消融结果，也未提供随机性分析或多次运行方差。
- **依赖 VLM 质量**：整个框架的实例定位、目标选择、验证、歧义裁决均依赖同一个 VLM 后端（gpt-5.4-mini），VLM 的错误会传导至导航决策；文中未分析不同 VLM 的鲁棒性。
- **计算开销未报告**：未报告推理时延、token 消耗、内存占用等实际部署成本；VLM 串行推理在高频决策场景下的实时性存疑。
- **长期记忆容量有限**：Wlt=8 的固定上限可能不足以支持超长 episode 或大规模环境中的知识积累。
- **类别级到实例级的迁移限制**：类别级锚点不能验证实例级查询，且实例关联依赖 CLIP 外观阈值，对视角变化大、外观相似度高的场景可能产生误关联。
- **仅验证模拟环境**：实验限于 Habitat 模拟器，未在真实机器人平台上部署验证。
