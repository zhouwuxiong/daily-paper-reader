## 摘要
地标测量与地标变量之间的数据关联一直是SLAM中的核心挑战，因为估计精度关键取决于将测量与正确的地标变量相关联。深度学习的近期进展为该问题创造了新的机遇；数据关联现在不仅可以利用位置测量，还可以利用关于对象地标的语义信息，例如来自神经对象检测器的类别标签和来自视觉基础模型的特征向量。在本文中，我们提出了一种广义的免数据关联SLAM框架，该框架从里程计以及地标的位置和语义测量中联合估计数据关联、机器人位姿、地标位置和地标语义。所提出的框架(i)实现了数据关联与地标语义估计之间的协同作用；(ii)采用半增量式估计方案以提高精度和计算效率；(iii)为地标数量估计提供了原则性的论证、指南和启发式方法，提高了框架的可解释性和实际可用性。所提出的框架和算法在合成和真实世界数据集上，使用类别标签和实值特征向量两种类型的语义信息进行了评估，并展示了优于强基线的性能。

## Abstract
Data association between landmark measurements and landmark variables has long been a central challenge in SLAM, as estimation accuracy depends critically on associating measurements with the correct landmark variables. Recent advances in deep learning have created new opportunities for the problem; data association can now leverage not only positional measurements but also semantic information about object landmarks, such as class labels from neural object detectors and feature vectors from visual foundation models. In this paper, we present a generalized data-association-free SLAM framework that jointly estimates data associations, robot poses, landmark positions, and landmark semantics from odometry, and positional and semantic measurements of landmarks. The proposed framework (i) creates a synergy between data association and landmark semantics estimation; (ii) adopts a semi-incremental estimation scheme for improved accuracy and computational efficiency; and (iii) provides a principled justification, guidelines, and heuristics for landmark-number estimation, improving the interpretability and practical usability of the framework. The proposed framework and algorithms are evaluated on synthetic and real-world datasets with two types of semantic information, class labels and real-valued feature vectors, and demonstrate superior performance compared to strong baselines.

## 2. 论文提出的方法论

### 2.1 核心思想
- 在统一的最大似然/最大后验框架中，把**数据关联、机器人位姿、地标位置和地标语义**作为联合变量处理，不对数据关联做硬性前置决定。
- 将语义信息显式建模为地标语义变量的带噪测量（高斯噪声模型），支持**one-hot 类别向量**与**实值特征向量**两种形式。
- 采用**分而治之（divide-and-conquer）**的半增量式（block-incremental）处理策略，先处理轨迹分段，再做全局优化，从而抑制里程计漂移并降低计算量。
- 对地标数量估计的外层问题，基于局部最优性条件给出 β 参数的启发式设置原则，提高可解释性。

### 2.2 关键技术细节
- **内层问题（含语义项）**：将 DAF-SLAM 的内层目标函数扩展为
  \[
  \min_{x,y,y_s} f_{\text{odom}}(x)+\sum_{k=1}^{M}\min_{j_k\in[K]}\left(\|R_{i_k}^T(y_{j_k}-t_{i_k})-\bar{z}_k\|^2_{\Sigma}+w_s^2\|y_{s,j_k}-\bar{z}_{s,k}\|^2_{\Sigma_s}\right)
  \]
  其中空间残差与语义残差通过权重 \(w_s\) 归一化后叠加。
- **联合 K-means 关联步骤**：将空间坐标与加权语义特征拼接，形成 \(d+s\) 维的增广特征空间，再用 k-means++ 一次完成聚类，聚类中心同时给出地标位置与地标语义的估计。数据关联即聚类分配。
- **交替优化**：关联步骤（k-means）与估计步骤（SLAM 求解位姿和位置、对语义取均值）交替迭代；语义估计在给定关联后独立求解，平均即最优点；one-hot 向量取平均后取 argmax 等价于多数投票。
- **外层地标数估计**：保留原 DAF-SLAM 的外层形式 \(\min_K f^*_{\text{slam}}(K)+\beta K\)，但新增了 **β 局部最优性条件的推导**，给出 \(\beta_{\text{ub}}\ge \beta\ge\beta_{\text{lb}}\) 的形式，并基于卡方分布提出 β 的启发式设置：
  - 在地标间距大、噪声小的场景，用 \(\chi^{-2}(0.999, d|\hat M(j)|)\) 设置 β；
  - 在地标密集、间距接近噪声量级时，采用经验起始值 \(\frac{2|\hat M(j)|}{\pi}\)，并给出相应的建模依据（高斯样本分裂模型）。
- **半增量式算法**：
  - `skid-SLAM`：先顺序或并行处理各轨迹分段（每段独立运行带语义的 kSLAM），再用里程计连接各段并对整条轨迹做全局优化；外层问题搜索空间从 \(\{1,\dots,M\}\) 缩减为 \(\{1,\dots,\sum_n \hat K_n\}\)，显著降低计算复杂度。
  - `skill-SLAM`：并行版本，在更多分段就绪时提前用另一线程做全局优化，并将结果作为分段继续与后续分段联合，进一步抑制漂移。
- **实践考量**：算法对 one-hot 向量可直接使用无需改动（仅需将 \(\frac{\sigma}{\sigma_s}w_s\) 视为超参数）；讨论了并行全局优化、目标检测器误检、漏检、错标等情况下的处理方式（漏检可在后处理中用估计目标渲染补偿，错标可主要依据空间关联并用投票纠正）。

## 6. 论文的主要结论与发现

- 将语义信息纳入联合估计框架后，**数据关联精度和轨迹精度都显著提升**，尤其在语义噪声可接受、里程计噪声较高时，性能提升更明显。
- 半增量式处理（先分段、后全局）相较批次处理**有效抑制里程计漂移**，同时通过缩小外层地标数搜索空间获得计算优势；`skill-SLAM` 略优于 `skid-SLAM`。
- 地标语义估计精度大幅优于原始测量噪声水平（例如错标率明显下降、特征向量误差更低），证明语义-关联联合估计具有自我纠错能力。
- 论文给出的 β 启发式在"地标间距远大于测量噪声"时有效；在复杂密集场景（厨房数据）下，经验起始值 \(2|M(j)|/\pi\) 也能工作，且最终地标标签始终正确。
- 对真实水下数据，`skill-SLAM` 比 kSLAM 更准确地合并循环回绕的测量，纠正了 kSLAM 将笼子与海草错误合并的关联问题。
- 现有方法对偶发误检等异常测量鲁棒性不足，是未来工作方向。

## 7. 优点

- **理论贡献清晰**：给出了外层地标数估计的局部最优性条件，将 β 与卡方分布联系起来，并借助高斯样本分裂模型推导出合理起始值，增强可解释性。
- **框架通用性强**：同时支持 one-hot 类别向量与连续实值特征向量，兼容 Mask R-CNN 和 DINO 等主流模型，不需要针对传感器类型重新设计关联前端。
- **算法设计巧妙**：将空间与语义残差拼接成增广空间后用一次 k-means 完成关联与语义估计，简单有效；分段+并行全局优化的方案兼顾精度与效率，逻辑上与 ORB-SLAM 中的局部/全局 BA 呼应。
- **实验设计系统**：在多类噪声、多种语义信息、不同真实场景下与多个较强基线（含 Oracle）全面比较，并给出消融。
- **实用细节充分**：讨论了漏检、误检、错标对系统的影响与处理建议，便于实际部署。

## 8. 不足与局限

- **异常值处理不完善**：对假阳性检测和空间离群测量缺乏显式鲁棒建模，只能"合并"进近邻地标；对检测器系统性错标或其他对抗性噪声的鲁棒性未验证。
- **β 启发式适用条件受限**：当地标间距很小、测量噪声大时，β 的理论推导假设不再成立，只能凭经验选取；附录也展示了该场景下卡方启发式会低估地标数。
- **依赖近似真值**：厨房数据以 AprilTag 为伪地标，位置与真实物体有偏移，无法直接量化物体位置误差；泳池数据无真实轨迹，评价主观。
- **仅支持点地标模型**：未涉及形状估计或更丰富的地标几何表示，距离完整"对象级"理解尚有差距。
- **真实场景验证范围有限**：仅覆盖室内厨房和小型泳池，未在自动驾驶、大规模室外或剧烈运动场景下测试；语义噪声实验为主要在合成数据上验证。
