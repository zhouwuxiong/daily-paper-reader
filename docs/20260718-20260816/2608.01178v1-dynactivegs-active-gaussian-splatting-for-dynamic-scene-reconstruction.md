## 摘要
我们提出了DynActiveGS，一种基于3D高斯溅射（3DGS）的动态感知主动重建框架，用于动态环境中的自主探索。该框架通过在线不确定性预测和不确定性加权高斯优化，增量式地重建3D高斯场景表示，同时抑制受运动影响的观测。DynActiveGS的一个关键组成部分是将不确定性明确分解为结构不确定性和运动诱导不确定性，这使系统能够区分重建不足的静态区域和动态不可靠区域。基于这些不确定性场，DynActiveGS执行动态感知的视点选择和动态约束的路径规划，以在探索过程中偏好信息丰富且稳定的观测。由此形成的系统为动态场景中的鲁棒主动重建提供了一个统一的闭环流程。在具有挑战性的动态基准上的大量实验表明，在重建精度、完整性、渲染质量和探索效率方面，DynActiveGS持续优于现有的主动重建基线。

## Abstract
We present DynActiveGS, a dynamic-aware active reconstruction framework based on 3D Gaussian Splatting (3DGS) for autonomous exploration in dynamic environments. The framework incrementally reconstructs a 3D Gaussian scene representation while suppressing motion-corrupted observations through online uncertainty prediction and uncertainty-weighted Gaussian optimization. A key component of DynActiveGS is the explicit decomposition of uncertainty into structural uncertainty and motion-induced uncertainty, which enables the system to distinguish under-reconstructed static regions from dynamically unreliable areas. Based on these uncertainty fields, DynActiveGS performs dynamic-aware viewpoint selection and dynamic-constrained path planning to favor informative yet stable observations during exploration. The resulting system forms a unified closed-loop pipeline for robust active reconstruction in dynamic scenes. Extensive experiments on challenging dynamic benchmarks demonstrate consistent improvements over existing active reconstruction baselines in reconstruction accuracy, completeness, rendering quality, and exploration efficiency.

- **研究动机**：主动3D重建（Active 3D Reconstruction）是让智能体自主决定“去哪里看、看什么”，以高效获取信息并构建高保真场景表示的关键技术。近年来，3D高斯溅射（3DGS）凭借显式、可微、高效渲染和增量优化的优势，催生了一批基于3DGS的主动重建方法。

## 2. 论文提出的方法论

### 核心思想
提出一种**显式不确定性分解**策略——将重建过程中的不确定性分为：
- **结构不确定性（U_s）**：反映区域因观测不足或重建不匹配导致的“知识缺失”；
- **运动不确定性（U_m）**：反映区域因动态物体干扰而导致的“观测不可靠”。

基于这两种不确定性场，系统在**建图、选视点、规划路径**三个层面都引入“动态感知”能力，形成闭环。

### 关键技术细节与流程

1. **动态感知高斯重建（Dynamic-aware Gaussian Reconstruction）**
   - 帧级不确定性预测：使用预训练的DINOv3特征提取器提取密集视觉特征，再经轻量级不确定性预测网络P生成逐像素不确定性图 β_t，动态/遮挡像素具有较高不确定性。
   - 不确定性加权建图：渲染RGB-D后，利用 β_t 对渲染损失进行像素级加权：
     - L_render = λ₁L_color + λ₂L_depth/β_t² + λ₃L_iso
     - 动态污染像素贡献降低，优化器聚焦静态结构。
   - 地图级不确定性构建：
     - **U_s(x)** 由有效观测次数 n_t(x)（倒数平方根项）和累计渲染残差 ē_t(x)（clip项）共同决定，突出“未看够”或“没建好”的区域。
     - **U_m(x)** 通过将帧级不确定性 β_t 反投影到3D并随时间指数移动平均累积（U_m ← (1−α)U_m + α·1_t(x)·β_t(u_t)），标识持续受动态干扰的区域。

2. **动态感知视点选择（Dynamic-aware Viewpoint Selection）**
   - 在Voronoi图 G=(V,E) 上构建拓扑表示，通过聚合聚类将图划分为子区域，聚类距离同时考虑欧氏距离、图距离和路径累积运动风险。
   - **局部-全局两级评分**：
     - 局部评分 S_local(n) = I_s(n;U_s) − λ_r·R_m(n;U_m) − λ_c·C(n)，其中结构增益 I_s 和运动风险 R_m 均通过软可见性权重累计；
     - 当局部区域充分探索或运动风险过高时，切换到全局评分 S_global(R_k)，综合考虑区域总增益、运动风险、跨区旅行成本和重复访问惩罚。
   - 核心思想：**“信息量”和“稳定性”同时纳入决策**，避免被高增益但动态干扰严重的区域吸引。

3. **动态约束路径规划（Dynamic-constrained Path Planning）**
   - 每条图边的通行代价定义为 c(e) = ℓ(e) + λ_m·Ū_m(e)，即几何长度 + 平均运动不确定性。
   - 运动不确定性采用指数移动平均更新时间累计，避免瞬时扰动主导规划，持续动态区域被稳定降权。
   - 最终形成“感知→重建→选点→规划→执行”的统一闭环系统，直到探索步数预算 S 耗尽。
