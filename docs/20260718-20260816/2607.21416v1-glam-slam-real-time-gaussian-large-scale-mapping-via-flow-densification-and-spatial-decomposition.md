## 摘要
现有的基于高斯溅射的单目同时定位与建图（SLAM）系统要么针对短序列设计，要么不是实时的，要么面临高昂的GPU内存需求，从而限制了它们在现实长时程场景中的适用性。为了解决这一问题，我们提出了GLAM-SLAM，一个专为大规模室外场景设计的实时解耦高斯溅射SLAM系统。我们通过基于特征的鲁棒SLAM前端实现轻量级跟踪，同时在建图方面采用结构化稀疏锚点网格表示，确保可扩展操作并在长序列中保持场景一致性。为满足3D高斯溅射（3DGS）的密集初始化要求，我们提出了一种基于几何的流密化锚定策略，利用对极约束。此外，通过将建图视为多场景问题，我们提出了一种场景划分策略，通过MLP初始化引入强空间归纳偏置，以生成局部高斯。我们在具有挑战性的长序列KITTI里程计、Oxford RobotCar和马拉加数据集上评估了我们的系统。大量的消融实验和比较表明，与第二名相比，我们的重建质量提高了15%，同时保持实时性能和扩展到更长时间序列的能力。代码已公开，以供社区使用。

## Abstract
Existing Gaussian-splatting-based monocular Simultaneous Localization and Mapping (SLAM) systems are either tailored to short sequences, are not real-time, or suffer from prohibitive GPU memory requirements, limiting their applicability in realistic, long-horizon scenarios. To address this, we present GLAM-SLAM, a real-time, decoupled Gaussian-splatting SLAM system designed for large-scale outdoor scenes. We ensure lightweight tracking using a robust, feature-based SLAM frontend, while for mapping, we adopt a structured, sparse anchor grid representation that ensures scalable operation and maintains scene coherence across long-term sequences. To satisfy the dense initialization requirements of 3D Gaussian Splatting (3DGS), we introduce a geometry-based flow-densification anchoring strategy using epipolar constraints. Furthermore, by treating mapping as a multi-scene problem, we propose a scene-partitioning strategy that introduces a strong spatial inductive bias via MLP initializations to generate localized Gaussians. We evaluate our system on the challenging, long-sequence KITTI Odometry, Oxford RobotCar, and M'alaga datasets. Extensive ablations and comparisons demonstrate a 15% improvement in reconstruction quality over the second-best performer, while maintaining real-time performance and the ability to scale to longer sequences. Code is publicly available for the benefit of the community.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 总体框架：解耦式架构

- 系统采用**解耦设计**，分为两个独立并行运行的模块：
  - **前端**：基于CPU运行的ORB-SLAM2多线程框架（跟踪、局部建图、回环检测），负责鲁棒的实时位姿估计，提供稀疏特征点作为几何地基。
  - **后端**：基于GPU运行的Gaussian Mapper线程，异步执行3DGS建图优化，基于结构化锚点网格（Scaffold-GS）进行稠密场景重建，不干扰前端跟踪。
- 这种解耦保证了跟踪鲁棒性，防止建图误差反向污染定位精度，同时增强了系统的模块化和灵活性。

### 2.2 结构化稀疏锚点网格表示

- 采用Scaffold-GS的稀疏锚点网格方案，每个锚点存储：
  - 可学习特征描述符 $f_a \in \mathbb{R}^8$
  - 缩放参数 $l_y$
  - $k$ 个可训练的偏移向量
- 所有高斯属性（位置、颜色、不透明度、球谐系数等）由轻量级MLP隐式预测，以锚点特征、锚点到相机距离 $\delta_{ac}$ 和视角方向向量 $d_{ac}$ 为条件：
  $$\delta_{ac} = \|x_a - x_c\|_2, \quad d_{ac} = \frac{x_a - x_c}{\|x_a - x_c\|_2}$$
- 这种表示大幅降低内存占用，保持几何完整性。

### 2.3 流致密化模块（Flow Densification）

- **问题**：ORB-SLAM2提供的高质量特征点分布不均匀，某些区域过密、某些区域覆盖不足，导致3DGS在这些稀疏区域无法收敛。
- **方案**：
  1. 使用**LiteFlowNet3**（轻量级光流网络）在连续关键帧之间建立稠密对应关系 $x \leftrightarrow x'$；
  2. 通过**极线约束**进行几何一致性过滤，采样N对对应点并计算残差：
     $$\text{residual} = x'^\top F x < \tau$$
     其中基本矩阵 $F = [e_2]_\times P_2P_1^+$，仅保留满足阈值的鲁棒匹配；
  3. 将保留的匹配点通过已知相机位姿进行三角化，生成补充的几何锚点。
- **关键技术决策**：
  - 光流仅在**建图线程**中稀疏使用（每7个关键帧运行一次），与跟踪完全解耦，避免深度网络领域偏差（domain bias）对跟踪准确性的负面影响；
  - 光流提取的噪声不会损害跟踪，但可以显著改善建图稀疏区域的初始化。

### 2.4 局部化MLP初始化（Localized MLP Initialization）

- **问题**：在光照变化大、物体尺度差异大、表面属性多样的大规模户外场景中，单一的全局MLP集难以捕捉全部空间和光度变异，导致细节丢失。
- **方案**：
  - 将环境动态划分为M个不同区域 $R = \{R_1, R_2, \dots, R_M\}$，每个区域配备独立的MLP参数集 $\Theta = \{\theta_1, \theta_2, \dots, \theta_M\}$；
  - 高斯属性解码由激活的局部MLP决定：
    $$\mathcal{G} = \sum_{m=1}^{M} \mathbb{1}(C \in R_m) \cdot \Phi_{\theta_m}(f_a, \delta_{ac}, d_{ac})$$
  - 采用**转向检测（turn detection）** 作为高效启发式触发条件，无需任何先验知识（区别于Block-NeRF需预定义区域、DeRF需预知区域总数）。
- **优势**：有效缓解灾难性遗忘，每个MLP只负责局部区域，无需覆盖整个长期轨迹的全部环境条件变化。

### 2.5 回环闭合处理

- 当ORB-SLAM2检测到回环时，对受影响关键帧位姿计算相对变换：
$$\Delta T_i = (T_{new,i}^{cw})^{-1} T_{old,i}^{cw}$$
- 将每个变换应用到该关键帧局部视锥内的所有锚点上，实现网格的非刚性变形，保持重建一致性并约束长期漂移。

### 2.6 渲染与训练

- 渲染遵循标准3DGS alpha合成：
  $$C(p) = \sum_{i=1}^{n} c_i \alpha_i(p) \prod_{j=1}^{i-1} (1-\alpha_j(p))$$
- 训练目标为L1损失与SSIM损失的加权组合：
  $$\mathcal{L} = \lambda L_1 + (1-\lambda) L_{SSIM}$$
- 每次训练迭代从最近k=25个关键帧中按0.7概率采样新关键帧、0.3概率采样旧关键帧，以减轻遗忘。

## 7. 优点

- **架构设计巧妙**：解耦式设计将鲁棒跟踪（CPU）和高保真建图（GPU）彻底分离，兼顾了系统的实时性和鲁棒性，模块化程度高，便于独立替换和升级。
- **针对性解决真实痛点**：准确识别并解决了3DGS SLAM在户外长序列中的三大瓶颈——稀疏初始化不足、全局MLP表达能力受限、内存不可扩展。
- **光流与极线几何结合的初始化策略新颖**：相较PhotoSLAM中使用邻居深度平均的反投影噪声初始化，本文基于稠密光流+极线约束的三角化提供更可靠的几何先验，加速收敛且提升稀疏区域重建质量。
- **空间分解方案灵活且无先验依赖**：通过转向检测自适应划分场景，不依赖预设区域数目或边界，适用于完全未知的大规模环境。
- **实验体系较为完整**：包含多数据集、多指标、多方法对比及双组件消融，验证充分。
- **开源提供**：代码公开，便于复现和社区使用。

## 8. 不足与局限

- **跟踪精度并非最优**：在ATE指标上，GLAM-SLAM（平均约10.8m，排除Seq.01）不如GigaSLAM（约3.4m），因其前端本质仍基于ORB-SLAM2，较重型但精密的深度/特征方法精度有限。论文承认此点，但牺牲了部分定位精度以换取实时性和轻量性。
- **对ORB-SLAM2前端失效的脆弱性**：在某些复杂序列（如KITTI Seq. 02的一部分）中，ORB-SLAM2会丢失跟踪导致建图失败，缺乏针对跟踪丢失的恢复机制。
- **光流模型固定占用显存**：即使仅在必要时使用，LiteFlowNet3仍常驻显存（约3 GiB），在低显存硬件上可能成为部署瓶颈。
- **跨区域一致性缺乏显式约束**：局部化MLP之间的空间边界处未做明确的几何/光度一致性约束，虽然论文声称不造成可感知降质，但在复杂场景中可能导致边界伪影。
- **对比方法受内存限制导致不公平比较**：PhotoSLAM和GigaSLAM因OOM被迫截断序列评估，缺失了长序列端到端的直接对比，削弱了"可扩展性"这一核心主张的充分验证。
- **缺少语义/动态对象处理**：未讨论动态物体（如行驶车辆、行人）对重建的影响，而户外驾驶场景中动态物体普遍存在，可能引入伪影。
- **Parking Sequence实验受限于单场景、无轨迹精度参考**：仅验证了重建质量，且该场景光照变化小，难以充分体现局部化MLP的优势（实验数据也显示仅带来微弱提升）。
