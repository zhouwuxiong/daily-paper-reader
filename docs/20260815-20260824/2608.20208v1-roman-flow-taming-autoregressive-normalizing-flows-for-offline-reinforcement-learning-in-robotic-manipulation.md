## 摘要
离线强化学习利用先前收集的数据改进机器人策略，而无需进一步的环境交互。然而，流行的扩散和流匹配机器人策略缺乏可处理的似然，限制了它们在基于似然的离线强化学习后训练中的使用。自回归归一化流（AR-NFs）既提供了表达力强的动作建模，又提供了精确的似然评估，但其顺序采样在策略优化和部署期间会产生大量的采样开销。我们提出了RoMAN-Flow（基于自回归归一化流的机器人操作），一个离线强化学习框架，通过解决这两个阶段的采样瓶颈，使AR-NF策略在机器人操作中变得实用。在策略优化期间，RoMAN-Flow采用无采样的、优势加权的似然目标，无需从自回归策略中采样即可为离线数据集中高优势的动作分配更高的似然。为了实现高效部署，它将优化后的自回归策略蒸馏为一步动作生成器，从而实现低延迟的动作预测。在多个模拟操作基准和真实机器人平台上的实验表明，RoMAN-Flow在显著降低推理延迟的同时实现了具有竞争力的策略性能。代码可在https://github.com/konnyaku28/RoMAN-Flow获取。

## Abstract
Offline reinforcement learning improves robotic policies using previously collected data without further environment interaction. Yet prevalent diffusion- and flow-matching robot policies lack tractable likelihoods, limiting their use in likelihood-based offline RL post-training. AR-NFs offer both expressive action modeling and exact likelihood evaluation, but their sequential sampling incurs substantial sampling overhead during policy optimization and deployment. We present RoMAN-Flow (Robotic Manipulation with Autoregressive Normalizing Flows), an offline reinforcement learning framework that makes AR-NF policies practical for robotic manipulation by addressing this sampling bottleneck in both stages. During policy optimization, RoMAN-Flow employs a sampling-free, advantage-weighted likelihood objective that assigns higher likelihood to high-advantage actions from the offline dataset without sampling from the autoregressive policy. For efficient deployment, it distills the optimized autoregressive policy into a one-step action generator, enabling low-latency action prediction. Experiments across multiple simulated manipulation benchmarks and real-world robotic platforms demonstrate that RoMAN-Flow achieves competitive policy performance while substantially reducing inference latency. Code is available at https://github.com/konnyaku28/RoMAN-Flow.

## 一、核心问题与研究动机

- **背景**：离线强化学习（Offline RL）允许利用先前收集的带奖励标签数据改进机器人策略，而无需与环境进一步交互，是机器人策略后训练（post-training）的实用途径。在大语言模型领域，基于似然的离线策略优化已取得显著成功，因为自回归模型可以提供可处理的精确对数似然。
- **核心矛盾**：机器人操作领域，主流的扩散策略（Diffusion Policy）和流匹配策略（Flow Matching，如 π0）虽然能建模复杂多峰动作分布，但缺乏低成本、精确的动作条件似然；自回归策略虽然提供可处理似然，但通常将连续动作离散化为 token 序列，引入量化误差，损害精细控制。
- **出发动机**：近年来，基于 Transformer 的自回归归一化流（AR-NFs）在图像生成中显示强生成能力，兼具表达力与精确似然评估。但 AR-NF 的自回归逆变换导致动作生成是顺序的，在**策略优化**和**部署推理**两个阶段都引入显著采样开销。
- **论文目标**：提出 RoMAN-Flow，解决 AR-NF 策略在离线 RL 后训练和部署两阶段的采样瓶颈，使其成为实用的机器人策略表达，弥合似然型离线 RL 与连续动作操控之间的缺口。

## 二、方法论

### 2.1 总体框架
- 采用“模仿学习（IL）→ 离线 RL 后训练（NF-IQL）→ 单步蒸馏（One-Step Distillation）”三阶段流水线。
- 以 AR-NF 为基础策略：前向变换可并行计算精确似然用于训练；逆变换（自回归顺序）用于动作生成，随后被蒸馏为并行单步模型。

### 2.2 AR-NF 策略构建
- **多模态上下文编码**：使用预训练视觉-语言模型（SmolVLM-500M-Instruct）对视觉、语言指令和本体感觉编码为上下文 token Ct。
- **AR-NF 骨干**：采用 SimFlow 作为条件 AR-NF，由 L 个条件可逆流块组成，每个流块使用前缀因果注意力掩码的 Transformer，基于上下文 Ct 和前置动作位置预测仿射变换参数（均值 μ 和对数尺度 s）。
- **关键公式**：
  - 前向变换：h(l)t,j = (h(l−1)t,j − μ(l)t,j) ⊙ exp(−s(l)t,j)
  - 精确对数似然：log πθ(at|ct) = log p0(zt) − Σl Σj s(l)t,j
  - 训练时的并行性来源：完整动作块在训练中可观察，仿射参数可通过一次掩码 Transformer 前向并行计算。

### 2.3 NF-IQL 离线后训练
- **核心思想**：基于 IQL，但完全避免从当前策略采样动作（因为 AR-NF 逆变换是顺序的），只对离线数据集中的动作块做优势加权最大似然。
- **Chunk 级 Q 学习**：使用 M 个 Chunk Transformer critic 集成 {Qωm}，通过因果掩码单次前向输出所有动作前缀的 Q 值；TD 目标为前缀内累积折扣奖励 + 后续状态值的折扣引导；训练损失为回归所有前缀 Q 值到对应 TD 目标。
- **状态值学习**：Vϕ 通过 expectile 回归（τ > 0.5 得上分位数基线）学习状态值，作为 critic 的 bootstrap 目标和优势计算基线。
- **优势加权似然优化**：
  - 优势：At = Q̄ω̄(ct, at) − Vϕ(ct)
  - 权重：wt = exp(βAt)
  - 损失：Lπ = −E[sg[wt] log πθ(at|ct)]
  - 该过程将策略向高价值行为偏移，全部基于离线数据，避免自回归采样。

### 2.4 单步策略蒸馏
- **动机**：NF-IQL 优化阶段避免了自回归采样，但部署时逆变换仍是顺序的（LIBERO-Long 上约 697ms）。
- **数据诱导路径**：对离线动作块加小高斯扰动，冻结 teacher 前向得潜在码 z 和中间流状态 {h(l)}，训练双向 student gψ 同时预测中间状态和最终动作块，损失包括中间状态对齐（L2）和动作重构（L2）。
- **先验采样路径**：从高斯先验采样 z，冻结 teacher 逆变换生成动作和中间状态，再训练 student 对齐，扩大 student 对 teacher 分布的覆盖。
- **总目标**：Ldistill = Ldata + λpLprior。

## 六、主要结论与发现

1. **NF-IQL 有效提升策略**：MetaWorld 平均成功率从 IL 的 72.8% 升至 81.1%（主要受益于 Medium/Hard/Very Hard 组）；LIBERO 从 93.5% 升至 95.3%（Long suite 提升 6.6pt 为主要来源）；真实机器人从 57.3% 大幅提升至 81.5%（+24.2pt），其中 Pick Beaker +64pt、Balance +20pt。
2. **超越/匹敌强基线**：MetaWorld 上 NF-IQL（81.1%）超越 π0+Flow-SDE（78.1%）3.0pt，且后者使用了在线交互；LIBERO 平均 95.3% 为所有对比方法中最高；真实机器人超越 π0.5 9.7pt。
3. **单步蒸馏保留性能**：MetaWorld One-Step 78.5%（保留 teacher 约 97%），LIBERO 93.7%、LIBERO-Long 上甚至超过 teacher（93.0% vs 92.2%），RoboMimic 上几乎无损；同时显著降低推理延迟（8.55×）。
4. **AR-NF + 似然型离线 RL 的实用性得到确立**：AR-NF 可以作为扩散/流匹配策略的可行替代，兼顾可处理似然与表达力。
5. **容量效应非线性**：AR-NF actor 容量需要达到特定阈值（~685M 参数）才能在精细操控任务（Square-MH）上有显著改善。

## 七、方法亮点与优点

- **双瓶颈的系统性解决**：分别在策略优化（无采样 NF-IQL）和部署（单步蒸馏）两个阶段消除 AR-NF 顺序采样开销，思路清晰完整。
- **似然型 RL 的创新结合**：将 AR-NF 可处理似然与 IQL 的优势加权机制结合，避免了对扩散策略所需的专门去噪代理目标、价值引导等复杂替代方案。
- **训练-推理效率设计的巧妙对称**：利用 AR-NF 前向可并行、逆向顺序的特性——训练时全部用前向（IL 和 RL 均无需策略采样），部署时用蒸馏将逆向变为并行。
- **Chunk Transformer critic 设计**：单次因果掩码前向产生所有动作前缀 Q 值，支持 chunk-level 精细时序信用分配。
- **蒸馏中的双重路径**（数据诱发 + 先验采样）保证 student 既拟合训练数据分布又覆盖 teacher 的完整潜在分布。
- **多基准验证全面**：从模拟（跨任务泛化、长期、精细操纵）到真实机器人均有覆盖，并与强 VLA 基线对比。
- **实用性落实**：给出开源代码、模型参数与超参表格，利于复现。
