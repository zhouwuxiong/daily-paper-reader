## 摘要
复杂户外地形中的自主导航对无人地面车辆（UGV）提出了严峻挑战，这源于全局地图构建与实时传感器反馈之间的固有脱节。本研究提出了一种混合框架，将低分辨率数字高程模型（DEM）数据与基于激光雷达的实时障碍物检测及地形分析相集成，以实现高效路径规划。首先，利用基于DEM预处理后的A*算法计算全局路径。随后，局部传感器数据驱动自适应路径修正，使UGV能够在保持安全性和效率的同时应对突发环境变化。在Gazebo中的仿真结果表明，该方法相较于基线方法有显著改进，在自定义地形中实现了95%的避障率，并将平均遭遇坡度从8°降低至2.7°。这种集成提高了路径效率和地形可通过性，并支持鲁棒的实时自适应，为动态户外环境中更可靠的自主导航铺平了道路。

## Abstract
Autonomous navigation in complex outdoor terrains presents critical challenges for unmanned ground vehicles (UGVs) due to the inherent disconnect between global mapping and real-time sensor feedback. This work proposes a hybrid framework that integrates low-resolution Digital Elevation Model (DEM) data with real-time LiDAR-based obstacle detection and terrain analysis for efficient path planning. A global path is initially computed using a preprocessed DEM-based A* algorithm. Subsequently, local sensor data drives adaptive path correction, enabling the UGV to negotiate sudden environmental changes while maintaining safety and efficiency. Simulation results in Gazebo demonstrate significant improvements over a baseline approach, achieving a 95\% obstacle avoidance rate and reducing the average encountered slope from $8^\circ$ to $2.7^\circ$ in custom terrain. This integration enhances path efficiency and terrain traversability and supports robust real-time adaptation, paving the way for more reliable autonomous navigation in dynamic outdoor environments.

## 2. 方法论

### 2.1 核心思想

提出一个**混合路径规划框架**，分两级协同：
- **全局规划**：低分辨率DEM数据 → 成本图 → A*算法生成全局最优轨迹；
- **局部修正**：实时LiDAR数据 → 地面分割、坡度估计、障碍检测 → 动态轨迹调整。

### 2.2 全局路径规划

**DEM预处理**：
- 使用SRTM 1弧秒（~30m分辨率）全球DEM数据（GeoTIFF格式）；
- 区域中心：圣约翰斯（ϕc=47.4870°N, λc=−52.8629°W），半径rm=1000m；
- 经度/纬度度量转换系数：mϕ=111320 m/deg，mλ=111320·cos(ϕc) m/deg；
- 对DEM数据进行裁剪、插值（细化到更高分辨率）、归一化，生成三维地形表面z(x,y)。

**成本函数设计**：

局部坡度幅度：
\[
s(x,y) = \sqrt{\left(\frac{\partial z}{\partial x}\right)^2 + \left(\frac{\partial z}{\partial y}\right)^2}
\]

成本函数：
\[
C(x,y) = w_s \cdot s(x,y) + w_z \cdot z(x,y)
\]
其中权重经验设定为 \(w_s=1.0\)（坡度）、\(w_z=0.5\)（高程）。对极端低海拔区域施加惩罚 P=10，以规避潜在的洪水区或不安全区域，最终将成本归一化到 [0,1]。

**路径生成**：使用A*算法在成本图上搜索累计成本最小的路径，优先避开陡坡和高程危险区域。

### 2.3 局部路径修正与规划

**① LiDAR数据分割**（混合GPF + 迭代RANSAC）：
- 初始地面种子提取：取最低的250个点作为低点参考（LPR），LPR上方0.8m内的点作为初始地面种子；
- 迭代平面拟合：对种子点拟合平面（n·x + d = 0），计算所有点到平面的距离，距离 < 0.1m 的点被分类为地面，重复3轮迭代；
- 最终将点云分为地面点与障碍物（非地面）点。

**② 坡度估计与自适应可通过性分析**：
- 当前坡度由地面法向量与竖直轴的夹角计算：
  \[
  \theta_{current} = \arccos\left(\frac{\vec{n} \cdot \vec{z}}{\|\vec{n}\| \|\vec{z}\|}\right)
  \]
- 维护滑动窗口（N=40）记录最近坡度，计算均值 μθ 与标准差 σθ；
- **动态阈值**：
  - 警告阈值：τwarn = μθ + σθ（坡度超过一标准差，启动避障）；
  - 临界阈值：τcrit = μθ + 3σθ（极其陡峭，触发紧急操作——停车+转向或后退）。

**③ 障碍物规避与自适应转向**：
- 将非地面点建模为“凸包分布”，定义障碍宽度 Wpit = ymax − ymin，最近距离 Dpit = min{x}；
- 高度分布h(x)的统计特征（均值、中位数、标准差）用于计算**Pearson偏度系数**：
  \[
  S = \frac{3(\mu_h - \text{median}(h))}{\sigma_h}
  \]
- **转向决策**（阈值τ=0.2）：
  - 若偏态（|S| ≥ τ）：S > 0 左转，S < 0 右转；
  - 若近正态：比较左右两侧障碍高度中位数，转向较低一侧；
- 转向角：θturn = arctan(Wpit / Dpit)；
- 角速度命令：ω = sign(S) · min(ωmax, ωbase · θturn)；
- 紧急逃逸：若 Dpit < 0.5m，则 v = vmax，ω = 5ωbase。

**④ 动态路径校正**：
- 监控相对目标路径的横向偏差 yerror，采用比例控制：
  \[
  \omega_{corr} = k_p \cdot \tan^{-1}(y_{error})
  \]
- 角速度限制在 [−ωmax, ωmax] 内以防止振荡；
- 设有**覆盖机制**：当高优先级命令（如避障）存在时，暂时禁用路径校正。

1. **系统集成度高**：将全局优化（A*）与局部感知（LiDAR）有机融合，弥补了“全局地图—实时反馈”的断裂；
