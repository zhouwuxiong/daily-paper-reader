## 摘要
尽管大型视觉-语言模型（VLMs）显著推进了具身导航，但其直接部署仍具挑战性，因为现有方法往往迫使VLM进入与其二维预训练先验不一致的非自然动作空间，加之僵化的推理调度和低效的记忆管理。为克服这些局限，我们提出TAMP-Nav，一个用于高效具身导航的统一框架。首先，我们引入像素到3D动作形式化（Point），将导航重新构建为2D视觉提示。具体而言，VLM仅需选择2D像素，随后将其投影为3D坐标以供底层SLAM控制器使用。这一设计自然地将具身执行与VLM固有的2D视觉能力对齐。其次，我们提出集成选择性推理与锚点轨迹记忆机制（Think and Memorize），该机制动态触发思维链，并仅在关键节点保留高保真记忆，将冗余轨迹压缩为轻量级时空指示器，从而保留关键历史信息并增强时空感知。最后，我们通过组相对策略优化（GRPO）设计了一种高效的两级对齐范式（Align）。通过将全局结果奖励与细粒度过程奖励叠加，这种密集监督将智能体的认知规划与物理环境反馈紧密对齐，赋予模型自适应推理能力。实验表明，TAMP-Nav在R2R-CE上实现了最先进的性能（如66.2%的SR），且具有高运行时和样本效率（仅需90k条训练轨迹）。

## Abstract
Although Large Vision-Language Models (VLMs) have significantly advanced embodied navigation, their direct deployment remains challenging, as existing methods often force VLMs into unnatural action spaces that misalign with their 2D pre-training priors, compounded by rigid reasoning schedules and inefficient memory management. To overcome these limitations, we propose TAMP-Nav, a unified framework for efficient embodied navigation. First, we introduce a Pixel-to-3D Action Formulation (Point) that reformulates navigation into 2D visual prompting. Specifically, the VLM merely selects 2D pixels, which are then projected into 3D coordinates for a low-level SLAM controller. This design naturally aligns embodied execution with the VLM's inherent 2D visual capabilities. Second, we propose an integrated Selective Reasoning and Anchor-Trajectory Memory mechanism (Think and Memorize), which dynamically triggers Chain-of-Thought and retains high-fidelity memory only at critical nodes, compressing redundant trajectories into lightweight Space-Time Indicators, thereby preserving critical historical information and enhancing spatio-temporal perception. Finally, we design an efficient Two-Level Alignment Paradigm (Align) via Group Relative Policy Optimization (GRPO). By superimposing global outcome rewards with fine-grained process rewards, this dense supervision tightly aligns the agent's cognitive planning with physical environmental feedback, endowing the model with adaptive reasoning capabilities. Experiments demonstrate that TAMP-Nav achieves state-of-the-art performance (e.g., 66.2% SR on R2R-CE) with high runtime and sample efficiency (requiring only 90k training trajectories).

## 1. 核心问题与整体含义（研究动机和背景）

- 具身导航要求智能体理解自然语言指令并在复杂环境中行动，大型视觉-语言模型（VLM）虽提升了多模态理解能力，但直接部署面临三大瓶颈：
  - **几何间隙**：现有方法迫使 VLM 输出低层原子动作（如“左转 30°”）或回归 3D 坐标，而 VLM 主要在 2D 图像-文本对上预训练，强制其隐式学习 3D 几何变换会导致空间幻觉和低样本效率。
  - **推理与效率的矛盾**：现有方法通常固定地在每一步或预设间隔触发 Chain-of-Thought（CoT），虽然提高规划质量，但带来严重推理延迟，无法平衡运行效率与导航性能。
  - **长程记忆信息丢失**：保留全部历史视觉特征会导致注意力稀释和记忆溢出；而随意丢弃过去观测又会丢失关键信息；同时缺少显式时空坐标来组织历史，智能体难以保持对过去轨迹的清晰理解。
- 针对上述问题，论文提出 **TAMP-Nav**（Think, Align, Memorize, and Point）统一框架，将 2D 视觉能力自然延伸至 3D 执行，并动态管理记忆与推理，实现高效具身导航。

## 2. 论文提出的方法论

- **整体架构**：连续交互循环——智能体整合当前视觉观测与 Anchor-Trajectory Memory → 自主决定是否触发选择性推理 → 通过 Pixel-to-3D 动作公式化预测像素路点 → 转换为 3D 坐标交给低层 SLAM 执行 → 通过 Two-Level GRPO 优化。

- **Point：Pixel-to-3D 动作形式化**
  - 智能体作为“视觉指针”，在每一步接收四张第一视角图像（覆盖 360°），VLM 先选择最优视图，再输出指示目标路点的 2D 像素坐标 (u, v)。
  - 该像素通过深度图投影为局部 3D 点：`Pt = D(u,v) · K⁻¹[u,v,1]ᵀ`，再转换到世界坐标系并交给低层 SLAM 控制器执行。
  - 这样做避免了让 VLM 学习复杂几何变换，使其专注于视觉语义定位；仿真中直接使用真值深度，真实部署时使用深度相机。

- **Think & Memorize：选择性推理与锚点轨迹记忆**
  - **MultiNav-CoT 数据集构建**：从 VLN-CE 过滤得到 90k 轨迹，通过关键节点挖掘与结构化 CoT 生成构建选择性思维链标注。
  - **关键节点挖掘**：重要性得分 `S(t) = S_sem(t) + S_vis(t)`，其中语义得分用 CLIP 相似度，视觉得分用帧间特征差异；经距离贪心过滤和时序填充，选出约 30% 的轨迹节点作为推理锚点。
  - **结构化 CoT 生成**：采用多阶段提示（任务阶段定位、当前观测分析、未来动作推理）降低单次查询认知负荷，减少幻觉，保证推理质量。
  - **Anchor-Trajectory Memory**：
    - 显式锚点（Explicit Anchors）：存储关键决策节点的 STI、高保真视觉特征和规划信标（CoT），支持像素级闭环检测。
    - 时空指示器（STI）：将目标节点间的冗余区间压缩为轻量级时空 token，编码 (x, y, yaw, t)，使用 2D/1D RoPE 和 MLP 融合，保留轨迹拓扑信息且严格限制记忆预算。

- **Align：两级 GRPO 对齐**
  - 先以 Qwen2.5-VL-7B 为基础在 MultiNav-CoT 上做 SFT 冷启动，再进行 GRPO 强化学习。
  - **本地步骤奖励**：包含目标接近奖励、碰撞避免奖励、停止动作奖励、推理价值奖励（衡量 CoT 是否提升决策质量）、格式遵循奖励。
  - **全局轨迹奖励**：包含任务成功奖励（放宽到 oracle 边界）、轨迹效率奖励（SPL）、推理密度奖励（防止过度思考）。
  - **两级策略优化**：生成 G=8 条完整轨迹，每一步通过温度采样产生 M=4 个候选动作；早期采用退火引导采样加重高质量候选的选择概率，训练后期退化为均匀采样。全局优势与步骤级优势分别 Z-score 标准化后叠加，提供密集监督并促进自主探索。

## 6. 论文的主要结论与发现

- TAMP-Nav 在 R2R-CE Val-Unseen 达到 **66.2% SR**，在 RxR-CE Val-Unseen 达到 **65.7% SR**，刷新 SOTA。
- 仅使用 **90k 训练轨迹**（约 70 万交互）即达到竞争性结果，远少于 DualVLN（76.3 万轨迹）和 NavFoM（337 万交互），说明样本效率高。
- SFT 到 RL 将成功率从 55.7% 提升到 66.2%，证明两级 GRPO 比纯监督学习更能有效内化复杂逻辑。

- 深度噪声实验表明：在相对噪声 16% 时 SR 仅下降 2.8 点，具备一定鲁棒性。
- 真实世界零样本部署中，TAMP-Nav 达到 60.0% SR，优于 StreamVLN（49.0%）和 DualVLN（53.0%）。

## 7. 优点

- **动作空间设计巧妙**：Pixel-to-3D 将 VLM 的输出从 3D 坐标或原子动作转化为 2D 像素选择，自然契合 VLM 的 2D 预训练先验，降低几何推理负担。
- **推理与记忆兼顾**：选择性 CoT 触发机制显著降低推理延迟，同时 Anchor-Trajectory Memory 通过 STI 轻量保留完整时空路径，解决了长程信息丢失与注意力稀释问题。
- **两级 GRPO 设计创新**：叠加全局结果奖励和过程奖励，配合退火引导采样，缓解了稀疏奖励导致的信用分配困难，并加速早期探索。
- **样本效率突出**：仅用 90k 轨迹达到 SOTA，远超需要更大数据量的已有方法。
- **实验体系完整**：涵盖仿真标准 Benchmark、长程任务、深度噪声、消融、推理触发分析、真实世界部署，证据链充分。
- **从数据到训练闭环可控**：自建 MultiNav-CoT 数据集，结构化生成高质量 CoT，并系统性验证了 CoT 监督质量对下游性能的影响。

## 8. 不足与局限

- **对深度信息与 SLAM 的依赖**：Pixel-to-3D 投影和 STI 依赖深度质量与 SLAM 稳定性；尽管噪声实验显示一定鲁棒性，但严重深度误差、里程计漂移或 SLAM 定位失败可能导致较大性能退化。
- **无法在线强化学习**：GRPO 依赖仿真特权信号（进度、碰撞、SPL 等），当前策略只能零样本迁移到真机，不能根据真实反馈微调。
- **关键节点挖掘的启发式局限**：基于 CLIP 语义相似度和视觉差异的启发式可能在小而关键的决策点（语义或视觉不显著）低估重要性，在指令风格差异大时可能失效。
- **STI 编码不包含高度**：只能表示平面位置与朝向，无法区分楼层，多楼层或不平坦环境需要扩展为完整 3D 位姿表示。
- **推理密度阈值固定**：rden 中的 0.4/0.6 阈值可能在其他任务或指令分布下不再适用。
- **数据集来源单一**：仅基于 VLN-CE 训练，泛化到更广泛具身任务和动态真实环境仍需验证；真实世界的 100 次实验样本量与场景覆盖仍有限。
- **对比实验中的隐性差异**：不同方法可能使用不同的低级控制器或深度输入，硬件实跑对比范围有限（只比较了 StreamVLN 和 DualVLN）。
