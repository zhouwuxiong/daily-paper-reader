## 摘要
尽管有腿动物能够在穿越狭窄空间时执行爆发性动作，但在四足机器人上复制这种行为一直是一个长期挑战。在此，我们提出了一种分层强化学习流程，使机器人能够通过受限障碍物——一个狭窄的门——执行激进的运动。模仿学习技术用于训练低级策略，该策略模仿真实动物的行为并形成一组多样化的技能。高级控制器能够感知低级技能的能力，并通过基于视觉的检测获取门的信息，确定合适的机动动作，并规划无碰撞轨迹以动态穿越狭窄空间。值得注意的是，我们还验证了该框架可以扩展到其他高动态任务。这是首批在地面行走机器人上执行自主和敏捷的空中门穿越任务的工作之一，将腿式机器人的逼真敏捷性扩展到与其生物对应物相匹配的程度。

## Abstract
Although legged animals are capable of performing explosive motions while traversing confined spaces, replicating this behavior in quadrupedal robots has been a longstanding challenge. Here, we propose a hierarchical reinforcement learning pipeline that empowers the robots to perform aggressive locomotion through constrained obstacles--a narrow gate. The imitation learning technique is used to train the low-level policy, which mimics the behaviors of real animals and forms a set of diverse skills. The high-level controller, having an awareness of the capability of low-level skills and acquiring the gate information via vision-based detection, determines the suitable maneuvers with collision-free trajectories to traverse it dynamically. Notably, we also verify that this framework can be extended to other highly dynamic tasks. This is one of the first works that perform autonomous and agile aerial gate traversal tasks on ground-walking robots, extending the lifelike agility of legged robots to match that of their biological counterparts.

## 2. 方法论

### 2.1 总体架构：分层强化学习（Hierarchical RL）

整体流程为两阶段训练：

- **第一层（低层策略 πᴸ）**：基于对抗性模仿学习（GAN 风格），训练一个统一的运动控制器，使其既能跟踪速度指令，又能模仿动物多种运动技能；
- **第二层（高层策略 πᴴ）**：固定低层策略，训练一个决策控制器，根据视觉感知的门洞信息，输出低频率的速度指令（线速度 + 偏航角速度），引导机器人完成任务。

### 2.2 低层控制器

| 组件 | 内容 |
|---|---|
| **状态空间** | 本体感觉（42维）：基座角速度、投影重力、12个关节角、12个关节速度、上一时刻动作。基座线速度作为特权状态仅输入 Critic 网络。 |
| **动作空间** | 12维关节角偏移量，作用于 PD 控制器；采用基于真实机器人数据训练的驱动器网络以缩小 Sim2Real gap。 |
| **奖励函数** | 总奖励 = α_T·任务奖励 + α_S·风格奖励 + α_R·正则化奖励。任务奖励鼓励速度跟踪与腾空期脚部高度；风格奖励由判别器提供（最大化与参考动作的相似度）；正则化奖励约束力矩、动作平滑度与加速度。 |
| **参考运动数据集** | 选取多段速度范围由低到高的动物动作（慢速踱步、跑步、跳跃、转向），经逆运动学重定向到机器人形态。跳跃数据采样权重为低速数据的6倍，以强化高难度动作学习。 |

### 2.3 高层控制器

| 组件 | 内容 |
|---|---|
| **状态空间** | 复用低层本体感觉 + 上一时刻高层动作 + 门洞相对方向向量（式2）+ 偏航角误差 Δφ_z（式3）+ 门洞内外边长几何信息。 |
| **动作空间** | 2维：前进线速度命令 v_cmd_x 与偏航角速度命令 ω_cmd_z，由低层策略执行。 |
| **运行频率** | 高层10 Hz，低层50 Hz（高层每5步低层步发送一次动作）。 |
| **奖励函数** | 中心跟踪（基座速度在门洞方向上的投影）、偏航校正、能量耗散惩罚、速度指令超限惩罚。 |
| **感知模块** | RGB-D 相机 → 二值化 + 形态学处理 + Canny 边缘 → 凸包检测 → 深度图计算顶点世界坐标 → 取中心与边长 → 三阶低通滤波平滑输出。 |

## 6. 主要结论与发现

1. **成功实现自主窄门穿越**：机器人通过机载视觉感知门洞位置和尺寸，自主决定合适的运动技能与切换时机，以**最高约2.5 m/s**的速度穿越与自身尺寸相当的窄门，**腾空时间约0.44 s**。
2. **自然的行为转换**：整个过程中，控制器呈现“低速踱步→蓄力→加速→起跳→腾空→落地缓冲”的连续行为序列，且无任何预设的运动或接触顺序。
3. **电机能力被充分利用**：起跳时后腿电机力矩接近饱和，后小腿关节偏转超过140°以避让门边，验证了系统对硬件能力的挖掘。
4. **层级架构的优势**：高层策略只需在二维速度命令空间中决策，相比端到端从原始关节空间探索，训练效率显著提高，性能优于所有对比方法。
5. **强适应性**：系统可应对变高度、变位置、动态移动的门洞，亦可在楼梯、缝隙、斜坡等复杂地形上完成穿越。
6. **可扩展性**：仅需重新配置高层模块即可迁移到跨栏、跳跃缝隙、板条间隙等新任务，无需重新训练低层运动策略。

## 7. 方法优点

- **首次实现**：为首批在真实地面行走机器人上完成自主、敏捷的空中门洞穿越的工作；

- **实验证据丰富**：多地形、多门洞位置、动态扰动、任务扩展等验证，并附带真实硬件轨迹可视化。

## 8. 不足与局限

- **速度抽象限制关节级精细控制**：高层仅能通过速度命令间接影响低层技能，无法显式选择具有相同速度分布但不同关节构型的行为（如不同的收腿策略），在需要非生物动作模式的任务中可能受限；
- **依赖外部定位系统**：训练中基座线速度作为特权状态，真实部署依赖 VICON 提供全局位姿——在实际室外环境中缺乏自包含性；
- **硬件验证范围有限**：仅在单一机器人（Unitree Aliengo）和较小的6.0 m × 3.0 m场地内验证，未测试更大尺度、更多地形类型或更具挑战性的运动性能；
- **对比实验公平性风险**：Baseline 方法的奖励调优、架构超参数等细节未完全披露，无法完全排除实现上对本文方法更有利的偏差；
- **感知模块局限**：门洞检测基于黑色方形框的视觉特征，在复杂视觉背景或光照变化下鲁棒性尚待验证（论文未提供感知性能的定量评估）；
- **训练成本**：虽然远低于端到端方法，但两阶段训练 + 大量并行环境的配置仍需要特定 GPU 资源和较长时间，在低成本研究场景下或构成门槛。
- **个别表述待加强**：论文未报告真实硬件上多次重复实验的统计成功率、失败案例分析等，对系统稳定性的定量刻画略显不足。
