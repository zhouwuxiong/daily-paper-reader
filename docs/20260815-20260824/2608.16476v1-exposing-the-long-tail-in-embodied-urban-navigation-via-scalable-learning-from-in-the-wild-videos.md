## 摘要
从现实世界数据中学习具身城市导航策略受到任务特定数据采集成本以及稀有但安全关键场景覆盖有限的制约。为应对这些挑战，我们提出一个可扩展框架，从网络规模的野外自我中心视频中学习点目标城市导航，同时系统性地揭示其长尾分布。该框架自动为未策划的网络视频标注度量轨迹和结构化导航语义，进而用于训练视觉-语言-动作策略，以实现可解释的导航规划。我们基于模型性能以及感知-运动模式的分布来刻画长尾，并采用基于反思的分析来诊断反复出现的失败模式。在网页视频数据和真实世界城市导航任务上的实验表明，从无约束视频中能够有效迁移知识，并揭示出超越总体导航性能的连贯长尾结构。

## Abstract
Learning embodied urban navigation policies from real-world data is constrained by the cost of task-specific data collection and the limited coverage of rare yet safety-critical scenarios. To address these challenges, we present a scalable framework for learning point-goal urban navigation from web-scale in-the-wild egocentric videos while systematically exposing its long tail. The framework automatically annotates uncurated web videos with metric trajectories and structured navigation semantics, which are then used to train a vision-language-action policy for interpretable navigation planning. We characterize the long tail based on model performance and the distribution of perception-motion patterns, and employ reflection-based analysis to diagnose recurring failure modes. Experiments on web-video data and real-world urban navigation tasks demonstrate effective knowledge transfer from unconstrained videos and reveal coherent long-tail structures beyond aggregate navigation performance.

## 2. 论文提出的方法论

### 2.1 总体框架

方法分为两个阶段：

- **阶段一（Step ①）——自动化网页视频数据标注**：将无约束网络视频转化为带结构化导航推理标注的导航片段。
- **阶段二（Step ②）——长尾发现与失败归因**：基于分布稀有性和模型难度联合挖掘长尾样本，并使用特权反思进行结构化失败归因。

### 2.2 核心流程与关键技术细节

**数据构建流程：**

- **视频收集**：从互联网收集30个城市、15个国家的街走第一视角视频，统一分辨率并切分为5分钟片段。
- **数据过滤**：使用视觉-语言模型识别视频切换、主体聚焦片段以及门口、楼梯、电梯等特殊事件，过滤掉不符合通用地平面导航设定的片段。
- **轨迹重建**：使用 **LoGeR**（长上下文几何重建框架）配合 **Pi3X** 模型作为视觉几何骨干，估计无参考帧的相机姿态和度量深度，重建5分钟连续行走轨迹。轨迹按1Hz采样，切成10帧导航片段（5帧历史+5帧未来），并按时间块分组以防止数据泄漏。
- **元动作语义标签**：基于速度、横向进展和运动方向，通过确定性几何规则将每个有效未来轨迹映射为**20种元动作**之一。
- **结构化导航推理注释**：使用 **GroundingDINO** 检测导航相关物体，将检测坐标和重建深度映射为标准化的物体类别、图像平面位置和深度标签；使用 **Qwen3.6VL-27B** 作为标注教师VLM，遵循**感知-分析-规划（perception-analysis-planning）** 三层Schema生成导航推理链（CoT）。教师模型同时接收未来观测和规则推导的元动作作为**特权验证证据**，但被明确要求将推理依据限定在历史和当前可观测线索上，防止未来信息泄漏。

**WILD-Nav 模型架构：**

- 基于 **Qwen3.5VL-4B** 骨干，视觉编码器冻结，五个时序自我中心观测与任务提示、历史轨迹和点目标文本表示交错输入。
- 引入特殊标记 `<PLAN_QUERY>` 作为动作专家的接口，其隐藏状态聚合前文CoT推理。
- **动作专家**由两个轻量输出头组成：
  - **元动作头**：线性分类器，`â_t = softmax(W_a h_q + b_a)`
  - **轨迹头**：四层MLP（3个512维隐藏层，GELU激活），`τ̂_plan_t = f_mlp(h_q)`
- 推理配置有两种：
  - **WILD-Nav-think**：先自回归生成结构化推理，再追加 `<PLAN_QUERY>` 进行一次前向传播生成动作和轨迹（推理条件配置）。
  - **WILD-Nav-inst**：将 `<PLAN_QUERY>` 放在推理前，利用因果注意力实现单次前向直接规划（高效变体）。

**多任务监督学习：**

- 三个互补目标函数：
  - **语言建模损失** `L_cot`：监督结构化分析和规划推理的令牌生成。
  - **交叉熵损失** `L_act`：监督元动作分类。
  - **MSE损失** `L_traj_mlp`：监督5个未来路点的欧氏距离误差。
- 总目标：`L = λ_cot L_cot + λ_act L_act + λ_traj L_traj`。

### 2.3 长尾发现方法

- **感知-运动模式表示**：将开放词汇物体描述映射到规范化词表，结合物体类别、图像平面位置、深度位置和运动配置形成联合特征 `z = ϕ(x, y)`。
- **导航条件稀有度**：使用平滑逆文档频率（IDF）计算联合特征的稀有度分数：
  - `IDF(a) = log((N+1)/(DF(a)+1))`
  - `s_rare_i = Σ_{a∈F_i} IDF(a) / √|F_i|`
  - 分数越高表示包含越多的稀有感知-运动组合。
- **难度度量**：使用 **ADE**（平均位移误差）和 **FDE**（最终位移误差）评估模型依赖的规划难度，分别取前3%的并集作为困难集。
- **特权反思归因**：仅对困难集使用教师VLM进行反思分析。教师模型接收未来观测和参考轨迹进行追溯验证，检查场景分析是否由观测历史支撑、规划推理是否与目标一致、轨迹是否与元动作一致。ADE/FDE/稀有度分数和困难样本排名被排除在反思提示之外，以保证归因独立性。

## 6. 论文的主要结论与发现

- **知识迁移有效**：WILD-Nav在视频测试集上显著优于两种基线。即使与更强的SocialNav变体相比，WILD-Nav-inst在三个轨迹指标上至少降低53.4%误差；相比UrbanNav，FDE降低47.8%。
- **结构化推理有增益**：WILD-Nav-think较WILD-Nav-inst进一步降低ADE和FDE（分别减少8.5%和4.2%），表明结构化CoT推理为连续路点生成提供了有效上下文。
- **真实世界存在域差距但可微调弥补**：直接迁移误差较高（域差距来自视点和运动约束差异），微调后WILD-Nav-inst取得最优轨迹性能，FDE和MAOE相比次优UrbanNav分别降低55.6%和45.8%，但差距未完全闭合。
- **长尾结构是场景依赖的**：稀有与困难重叠有限（24.18%的困难样本是稀有的，14.48%的稀有样本是困难的），说明**数据覆盖缺口与模型弱点不应混淆**。不同场景聚类的失败模式显著不同：密集行人停车场景以规划和轨迹形状错误为主；滑板车-标志场景表现出规则和动作错误；交通标志场景放大规则违反；滑板车或骑行者交互主要暴露预测和碰撞风险失败。
- **困难样本微调+随机回放最佳**：Hard+Random策略在保持整体性能的同时实现最低尾部误差（尾部ADE 0.217、FDE 0.160），证明困难样本提供针对性监督，而回放数据帮助保持更广泛的导航分布。
