## 摘要
语义映射在机器人与物体交互、操作和导航复杂环境的能力中起着关键作用。最常见的语义映射流程包括几何映射与定位（SLAM）、感知、语义融合和语义表示。然而，近期的研究也在其应用中整合了某种形式的先验知识，最显著的是知识图谱或语义场景图，以增强对环境上下文的语义理解。在本文中，我们提出了一种混合语义映射流程。我们的系统利用外部标定相机通过单应性投影进行几何映射与定位，并结合目标检测、持续目标跟踪和本体驱动的语义更新来构建动态语义世界模型。同时，采用线性回归模型对真实世界坐标的估计值进行校正。系统基于实时传感数据持续更新目标实例、空间属性和语义关系。由于本体具有层级结构、语义表达性强且支持动态世界建模，我们选择本体作为知识表示的形式。

## Abstract
Semantic mapping plays a crucial role in the ability of a robot to interact with objects, operate and navigate a complex environment. The most common pipeline for semantic mapping consists of geometric mapping and localization (SLAM), perception, semantic fusion and semantic representation. However, more recent works also integrate a form of prior knowledge in their application, most notably knowledge graphs or semantic scene graphs, to improve contextual understanding of the environment. In this paper, we present a hybrid pipeline for semantic mapping. Our system incorporates an external calibrated camera using homography projection for geometric mapping and localization, combined with object detection, persistent object tracking and ontology driven semantic updates to build a dynamic semantic world model. Linear regression models are also used for correction of the estimated values of real world coordinates. The system continuously updates object instances, spatial properties and semantic relations based on real time sensory data. Ontologies are selected as form of knowledge representation due to their hierarchical structure, semantic expressiveness and support for dynamic world modelling.

## 2. 方法论与关键技术

- **总体架构**：外部 PoE 校准相机（Tapo C501GW，安装在 3–3.5m 高处）→ 实时 RTSP 视频流 → 去畸变 → 单应性投影几何定位 + ArUco 标记机器人位姿估计 + YOLOv11s 目标检测 → 真实世界坐标修正 → 本体观察创建与动态更新。

- **模块一：相机标定与去畸变**
  - 采用棋盘格（9x6）标定计算相机内参矩阵 K 与畸变系数（k₁,k₂,k₃,p₁,p₂）。
  - 通过 OpenCV 的 `getOptimalNewCameraMatrix()` 获得新投影矩阵 K′，再用 `undistort()` 对每帧进行去畸变，确保图像几何正确。

- **模块二：单应性投影几何映射**
  - 测试区域约 180×240 cm，通过选取图像四点对应真实世界 [0,0]、[180,0]、[180,240]、[0,240]，计算单应性矩阵 H。
  - 映射关系：λ\[x,y,1\]ᵀ = H\[u,v,1\]ᵀ，将图像像素坐标 (u,v) 变换为真实世界坐标 (x,y)（单位 cm）。

- **模块三：机器人定位**
  - 不使用 YOLO 直接检测机器人，原因是位姿（含朝向）估计不稳定。
  - 在 NAO 机器人头部水平放置 **ArUco marker**，以其四角均值作为标记中心，再进行单应性变换，获得稳定的 (X, Y, θ)。

- **模块四：目标检测**
  - 尝试 YOLOv4-tiny 后因小物体检测差而弃用，最终采用 **YOLOv11s**，兼顾精度与速度。
  - 检测 10 类物体：monitor、keyboard、book、bottle、scissors、cup、cabinetry、backpack、box、chair。
  - 选锚点：取检测框底边中点（x=(x₁+x₂)/2, y=y₂）作为物体与地面的接触点，再变换到世界坐标。

- **模块五：坐标误差修正（线性回归）**
  - 直接单应性投影误差较大：物体 X 轴 MAE=5.3cm，Y 轴 MAE=17.8cm；NAO 机器人 X/Y 轴 MAE 分别达 17.7cm/28.1cm。
  - 因真实值与估计值呈明显线性关系，采用**线性回归（LR）模型**分别对物体和机器人的 X/Y 轴坐标进行修正：
    - 物体 X 轴：x_cor = 5.352 + 0.905·x_est（R²≈0.994，MAE≈2.8cm）
    - 物体 Y 轴：y_cor = −44.476 + 1.168·y_est（训练 MAE≈8.5cm，测试集降至 2.4cm）
    - 机器人 X 轴：x_r_cor = 17.574 + 0.749·x_r_est（MAE≈1.6cm）
    - 机器人 Y 轴：y_r_cor = 37.930 + 0.912·y_r_est（MAE≈1.6cm）
  - 回归模型显著性极高（p<0.0001），留一法交叉验证显示泛化良好。

- **模块六：本体设计与动态更新**
  - 基于 Protégé 构建本体，共 **35 个类**，两个主要子类为 `physical_entity`（实验室物理对象）和 `abstract_entity`（观测）。
  - 观测记录为 obs = [X, Y, θ, cf, dt]，包含机器人坐标、置信度和时间戳，并以“observes”对象属性连接观测与物理实体，保留完整历史。
  - 为支持当前状态，另设 current_X/current_Y/current_cf/current_dt 数据属性，仅在**位置变化超过约 5cm 阈值**时才更新，以滤除检测抖动。
  - **对象实例生命周期管理**：
    - ≥2 个同类目标时各自建立独立个体；
    - 新目标出现直接添加，连续多帧不出现才移除（容忍单帧漏检）；
    - 采用最近邻匹配将新观测关联到已有对象。
  - **空间语义 "is_near_to"**：对称对象属性，按机器人与物体的欧氏距离计算，**10cm 阈值**内设为“近”，条件消失且连续确认 3 帧才移除，提供持续的近距离推理能力。

- **整体运行流**：帧获取 → 去畸变 → ArUco 定位 → YOLO 检测 → 坐标变换与修正 → 创建本体观察 → 更新本体（增/改/缓删）→ 计算 is_near_to → 保存本体，循环重复。

## 10. 未来工作建议

作者在展望中可进一步开展的方向包括但不限于：

- **向三维扩展**：引入深度相机或双目视差，将 2D 平面坐标升级为 3D 体积占据或物顶高度估计，以表达堆叠、悬空等复杂物理关系，并支撑抓取任务所需的完整位姿信息。
- **多相机协同**：单个外部相机存在固定视角盲区与遮挡瓶颈，多个 PoE 相机跨视角融合可显著增强场景覆盖率，这也将带来时间同步与坐标系统一的新研究点。
- **移动感知互补**：外部固定相机与机器人车载传感器互为补充，在机器人接近目标后利用车载视角做局部精化，缓解远距离俯视对细节识别能力的限制。
- **动态干扰系统的鲁棒性验证**：补充行人穿行、灯光突变、物体被遮挡或短暂移出视野等压力测试，验证延迟删除与观测匹配机制在真实杂乱环境中的生存能力。
- **一体化评估基准**：建立一套含语义标签真值、位置真值和状态变化事件的时间同步数据集，使语义映射流程的召回率、更新延迟以及状态误判率可以被量化比较，摆脱自证式评测。

## 11. 总结评述

总体来看，本文属于**应用驱动的工程集成型研究**：创新点不在于单一算法层面（目标检测、相机标定、本体建模均为成熟技术），而在于将这些组件以“外部固定感知 + 回归修正 + 动态本体”的方式有机结合，为动态场景语义建图提供了一个思路清晰、成本可控的新参照系。论文的语言表述与流程交代较为清晰，公式与逻辑链条完整；但实验规模偏小、外部对比缺失，使结论的置信度更多停留在“可行性论证”层面。

因此，若读者正在寻找可直接拿来对比 SOTA 的语义建图算法，本文并非合适对象；若读者需要一套易复现、易移植到真实实验室环境的模块化工程模板，或希望在决策层引入本体推理能力，本文具有较好的启发性。它适合作为“低成本感知 × 语义知识层”交叉方向的起点型文献来阅读，同时也提醒后续研究者：在数据集构建与系统级评测的规范性方面，该方向仍有大量工作可做。
