## 摘要
自主水下导航通常依赖复杂且昂贵的多模态传感器套件，这些套件旨在优先保证全局同步定位与建图（SLAM）精度。然而，诸如粗略导航和避障等局部反应行为仅需要局部一致性——这种能力本应仅使用前视声纳（FLS）即可实现，但目前仍基本未得到解决，从而在仅FLS的局部SLAM中留下了关键空白。此外，现有声学SLAM框架主要依赖稀疏特征提取方法，这些方法会丢弃本已信息稀疏的声学回波中的很大一部分。为克服这些局限，本文提出一种稠密直接配准方法，将完整的声学强度扫描与递归更新的局部地图对齐。通过最小化计算开销的逆向组合高斯-牛顿优化策略实现实时运行。实验评估表明，与稀疏关键点基线相比，这种稠密方法在平移误差上取得显著改进，并在较大位移间隔下保持稳定的亚米级跟踪精度。此外，该方法提供的里程计性能可与多传感器融合管线（FLS、DVL和IMU）相媲美，在特征丰富环境中绕过了昂贵的载荷依赖。我们通过AUV现场试验验证了实际适用性，并在嵌入式资源受限计算机上机载运行完整的局部SLAM方法。

## Abstract
Autonomous underwater navigation typically relies on complex and expensive multi-modal sensor suites designed to prioritize global Simultaneous Localization and Mapping (SLAM) accuracy. However, local reactive behaviors such as coarse navigation and obstacle avoidance require only local consistency---a capability that should be feasible using only a Forward-Looking Sonar (FLS), yet remains largely unaddressed, leaving a critical gap in FLS-only local SLAM.   Moreover, existing acoustic SLAM frameworks predominantly rely on sparse feature extraction methods that discard substantial portions of the already information-sparse acoustic returns. To overcome these limitations, this work introduces a dense direct registration approach that aligns full acoustic intensity scans to a recursively updated local map. Real-time execution is achieved via an Inverse Compositional Gauss-Newton optimization strategy that minimizes computational overhead.   Experimental evaluations show that this dense method yields significant improvements on translation error compared to sparse keypoint baselines, maintaining stable sub-meter tracking precision over wide displacement gaps. Moreover, this approach delivers odometry performance comparable to multi-sensor fusion pipelines (FLS, DVL, and IMU), bypassing expensive payload dependencies in feature-rich environments. We validate real-world applicability through AUV field trials, running the full local SLAM approach onboard an embedded, resource-constrained computer.

## 2. 方法论

### 2.1 核心思想

- 将完整声学强度扫描**稠密直接配准**到递归更新的局部地图，而非依赖稀疏关键点。
- 把扫描匹配建模为**互相关优化问题**，并采用**逆向组合高斯-牛顿（IC-GN）** 求解，以降低实时计算开销。
- 只维护机器人中心的局部地图与相对 SE(2) 位姿，不进行全局回环与全局位姿图优化。

### 2.2 数据预处理与表示

- FLS 扫描表示为极坐标矩阵 \(P \in [0,1]^{N_r \times N_\phi}\)，其中 \(N_r\) 为距离 bin 数，\(N_\phi\) 为波束数。
- 原始扫描受散斑噪声和相干干扰影响，先在极坐标域进行背景抑制滤波：
  - 若 \(P_{i,j} \ge \mu_P + \beta_{\text{denoise}}\sigma_P\) 则保留，否则置零。
  - \(\mu_P\)、\(\sigma_P\) 为极坐标扫描强度均值和标准差，\(\beta_{\text{denoise}}\) 为经验去噪系数。
- 去噪后的极坐标扫描通过双线性插值映射到笛卡尔空间，得到稠密强度图像 \(I(u)\)。
- 采用反向查表映射避免非均匀采样：\(r=\sqrt{x^2+y^2}\)，\(\phi=\arctan2(y,x)\)。

### 2.3 位姿与配准目标

- 状态向量为 \(x=[t_x,t_y,\theta]^T \in \mathbb{R}^2 \times S^1\)，表示相对局部地图的 SE(2) 位姿。
- 刚性变换函数为：
  - \(W(u;x)=R(\theta)u+t\)。
- 传统 L2 光度损失：
  - \(L_{L2}(x)=\frac12\sum_{u\in\Omega}(I(W(u;x))-M(u))^2\)。
  - 问题：声学阴影导致零强度区域动态变化，L2 会惩罚未声纳照射区域，引入人工局部极小。
- 改用**前向组合互相关损失**：
  - \(L_{FC}(\Delta x)=-\frac{1}{|\Omega|}\sum_{u\in\Omega} I(W(W(u;\Delta x);x))M(u)\)。
  - 零信号阴影区域因 \(M(u)=0\) 或 \(I(\cdot)=0\) 自然从求和中消失，对声学光照变化更鲁棒。
- 但前向组合中，每次迭代需重新计算扫描梯度 \(\nabla I(W(u;x))\)，计算瓶颈严重。

### 2.4 逆向组合高斯-牛顿（IC-GN）

- 通过变量替换：
  - \(u'=W(u;\Delta x) \Rightarrow u=W(u';\Delta x)^{-1}\)。
- 得到逆向组合目标：
  - \(L_{IC}(\Delta x)=-\frac{1}{|\Omega|}\sum_{u\in\Omega} I(W(u;x))M(W(u;\Delta x))\)。
- 将增量扰动从动态扫描 \(I\) 转移到静态地图 \(M\)，线性化后得到：
  - \(M(W(u;\Delta x)) \approx M(u)+\nabla M(u)\frac{\partial W(u;\Delta x)}{\partial \Delta x}\Delta x\)。
- 常值最速下降图像向量：
  - \(J(u)=[M_x(u), M_y(u), -yM_x(u)+xM_y(u)]^T\)。
- 梯度：
  - \(g=-\frac{1}{|\Omega|}\sum_{u\in\Omega} I(W(u;x))J(u)\)。
- 海森矩阵近似：
  - \(H \approx \frac{1}{|\Omega|}\sum_{u\in\Omega} J(u)J(u)^T\)。
- 由于 \(M\) 在单帧配准中保持静态，\(J(u)\) 和 \(H\) 只需每帧预计算一次，显著加速。
- 使用 Levenberg-Marquardt 阻尼：
  - \(H_{LM}=H+\lambda I\)。
  - 每帧预计算并求逆一次。
- 迭代更新：
  - \(x^{(i+1)}=x^{(i)}-\gamma H_{LM}^{-1}g^{(i)}\)。
- 梯度裁剪：
  - 若 \(\|g^{(i)}\|>g_{\max}\)，则按比例缩放，保持方向并防止散斑噪声异常值导致不稳定。
- 终止条件：参数更新量小于容差，或相关损失变化小于阈值。

### 2.5 状态传播与地图维护

- 由相邻扫描间位移计算速度：
  - \(v_x=t_x/\Delta t\)，\(v_y=t_y/\Delta t\)，\(v_\theta=\theta/\Delta t\)。
- 用恒速模型为下一帧提供热启动：
  - \(x^{(0)}_{k+1}=\Delta t [v_x,v_y,v_\theta]^T\)。
- 地图更新采用指数移动平均（EMA）：
  - \(M_k(u)=(1-\alpha)M_{k-1}(u)+\alpha I_k^{\text{aligned}}(u)\)。
- 随后进行统计噪声衰减：
  - 若 \(M_k(u)\ge \mu_M+\beta_{\text{decay}}\sigma_M\) 则保留，否则置零。
  - 用于抑制散斑噪声累积、保留锐利几何边界。
- 最后将参考地图变换到更新后的位姿，并通过高亮声学回波阈值提取障碍物点云。
