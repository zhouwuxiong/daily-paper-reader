## 摘要
我们提出 VGGT-GS SLAM，一种面向未标定视频的单目三维高斯泼溅 SLAM 系统。该系统以前馈式 VGGT 位姿与深度先验为起点，执行子图可微光束法平差，在联合优化相机位姿与三维高斯地图的同时，通过解析标定雅可比优化子图共享的内参与径向-切向畸变。为提升全局一致性，我们引入高斯原生对齐（GNA），用于序列子图之间以相机为锚的尺度细化以及回环候选的验证。在标准室内基准上的大量实验表明，该方法在未标定设定下于定位精度上取得了一致提升，并具备出色的渲染质量，为未标定高斯 SLAM 建立了一个强有力的基线。

## Abstract
We present VGGT-GS SLAM, a monocular 3D Gaussian Splatting SLAM system designed for uncalibrated videos. Starting from feed-forward VGGT pose and depth priors, our system performs submap differentiable bundle adjustment that jointly refines camera poses and a 3D Gaussian map, while optimizing submap-shared intrinsics and radial--tangential distortion through analytic calibration Jacobians. To improve global consistency, we introduce Gaussian-native alignment (GNA) for camera-anchored scale refinement between sequential submaps and verification of loop-closure candidates. Extensive experiments on standard indoor benchmarks show consistent improvements in localization accuracy and strong rendering quality under uncalibrated settings, establishing a strong baseline for uncalibrated Gaussian SLAM.

# VGGT-GS SLAM 论文总结

## 1. 核心问题与研究动机

- **背景**：3D 高斯泼溅（3DGS）支持实时渲染与高保真新视角合成，催生了一批联合估计相机轨迹与场景地图的 Gaussian-SLAM 系统。
- **痛点一**：多数现有方法假设相机已标定，且不少需要 RGB-D 输入来可靠初始化高斯，难以部署在缺少标定元数据与深度传感的普通单目相机上。
- **痛点二**：前馈重建模型（DUSt3R、MASt3R、VGGT）虽能提供位姿与稠密几何先验，但这些预测本质上只是**初始化**：标定误差会被吸收进场景几何，且独立重建的子图之间不共享一致尺度。
- **核心主张**：在未标定单目视频下，应把**标定与几何联合精化**，并显式处理**子图间尺度对齐**；为此保留 VGGT-SLAM 的子图组织方式，但把 VGGT 位姿/深度预测转化为可优化的高斯子图。

## 2. 方法论

### 2.1 总体流程
VGGT 前馈预测 → 高斯子图初始化 → 子图内可微光束法平差（联合优化高斯、位姿、共享内参与畸变）→ 高斯原生对齐（GNA）做顺序子图尺度精修 → 回环候选验证 → 全局 Sim(3) 位姿图优化。

### 2.2 子图与初始化
- **窗口划分**：沿用 VGGT-SLAM，每个映射窗口含 S 个新关键帧 + O 个重叠帧（默认 S=24，O=1）。
- **VGGT 初始化**：对每窗口推理得到外参、内参、深度与置信度图；共享内参 K 取各帧预测平均，畸变系数初始化为 0。
- **高斯初始化**：按 MonoGS 策略反投影有效深度像素（过滤 D<1e-8）到世界坐标，SH 系数取自像素颜色，旋转取单位阵，不透明度 0.5，各向同性对数尺度 ℓ = log(0.1·d_nn)/3（d_nn 为同帧最近邻距离）。

### 2.3 子图内联合 BA
- **参数化**：固定首帧位姿定义局部参考系，其余位姿用左乘 SE(3) 增量更新；内参采用对数焦距 + 加性主点更新；畸变系数用 tanh 有界化（k_j = s_k·tanh(ρ_kj)，p_j = s_p·tanh(ρ_pj)），限制在可控范围。
- **损失**：L_BA = L_rgb + λ_depth·L_depth + λ_iso·L_iso，用 AdamW 以参数相关学习率优化。
- **光度项**：沿用 DSO 的仿射曝光补偿 I′ = exp(a_i)I + b_i，在有效像素上取 L1 与 DSSIM 的加权混合；另提供“曝光稳定”变体（局部 BA 固定 a1=b1=0，后续精化冻结曝光）以缓解曝光—颜色变暗歧义。
- **深度项**：把 VGGT 深度当作**弱几何先验**而非传感器深度，构造带死区容差 τ_depth 的相对残差 r_i(p)，并用中位数归一化、上限裁剪后的置信度加权。
- **各向同性正则**：惩罚高斯三轴尺度偏离均值的程度，抑制极端各向异性。

### 2.4 解析标定雅可比（关键技术创新）
- 在 gsplat 的可微高斯投影中，**解析地**求取投影中心 m_2d 与二维协方差 Σ_2d 对完整 9 维标定向量 θ_cal = (f_x, f_y, c_x, c_y, k1, k2, k3, p1, p2) 的导数。
- 相机模型：归一化坐标 u=x/z, v=y/z，径向因子 d = 1+k1r²+k2r⁴+k3r⁶，再叠加切向项得到畸变坐标 (u_d, v_d)，最后 m_2d = D·m_d + c。
- 中心雅可比：∂m_2d/∂q = (∂D/∂q)m_d + D(∂m_d/∂q) + ∂c/∂q。
- 协方差雅可比：J = D·A·B，Σ_2d = JΣ_3d Jᵀ，对 q 求导时对 J 逐项应用乘积法则。
- CUDA 核返回物理系数梯度，自动微分再施加有界参数链式法则（如 ∂L/∂ρ_kj = (∂L/∂k_j)·s_k(1−tanh²ρ_kj)）。
- 该设计让**渲染损失可以直接驱动内参与畸变**，而不依赖特征对应或几何重投影约束。

### 2.5 高斯原生对齐（GNA）
- **相机锚定初始化**：由相邻子图的共享重叠帧确定旋转 R；恒等像素深度对应确定初始尺度 s0；平移 t0 = c_A − s0·R·c_B；**只优化对数尺度 u = log s**。
- **协方差感知匹配**：源高斯按不透明度、锚视图可见性、空间尺度过滤；变换后的均值与协方差经参考场景尺度归一化后，用对数核 κ_ij = −½(d_ijᵀ S_ij⁻¹ d_ij + λ_det·log|S_ij|) 度量参考高斯与源高斯的匹配程度（S_ij = Σ_A + Σ_{B→A} + (ϵ+τ²)I₃）。
- **双向分数**：对每个源中心取 k 个最近参考中心，按不透明度与观测数加权聚合，得到 B→A 与 A→B 两个方向的匹配分数。
- **目标函数**：L_GNA = −ℓ_{B→A} − ℓ_{A→B} + λ_sp·(u − log(m_A/m_B))²，最后一项是利用两侧中位最近邻间距的密度敏感尺度先验。
- **鲁棒性**：尺度更新被限制在初始化附近，且只有在归一化目标改善时才保留，否则退回 s0。

### 2.6 回环检测与验证
- 用 SALAD 描述子对历史子图检索（距离阈值 τ_r，最多保留最近一对，排除紧邻前驱）。
- 检索帧进入独立的联合 VGGT 回环推理批次，其深度对应初始化子图间 Sim(3) 桥。
- **GNA 仅用于验证而非精化**：接受条件为 L* ≤ τ_L 且 Δs ≤ τ_s，另加旋转一致性检查（与顺序链偏差超过 90° 则拒绝）；接受的回环**保留原始 VGGT 变换**。
- 全局 Sim(3) 位姿图只优化节点变换 G_i，局部高斯、位姿与标定保持不变，子图不合并。

### 2.7 其他实现细节
- 关键帧判据：LK 跟踪点平均像面位移超过 30 像素，或有效轨迹少于 10 条。
- 高斯按累积像面梯度周期性克隆/分裂，并剪枝低不透明度高斯。
- 非关键帧位姿在固定地图与标定下用 SE(3) 优化 90 次迭代，只使用起始关键帧不晚于该帧的局部子图。
