## 摘要
果园构成半结构化环境，其中平行的果树行形成自然的行驶通道，然而狭窄的行间净空和茂密的树冠导致不考虑几何结构的网格规划器偏离行中心，并有接触树干或树冠的风险。我们提出了AGRO-Nav，一种用于果园中基于静态图的全局规划的自动化框架。从SLAM点云中拟合到树干簇的果树行线出发，无需任何手动航点，即可构建包含行内和行间连通性的稀疏拓扑图；随后在该图上通过Dijkstra搜索找到全局路径，通过任意角Theta*段连接到起点和终点，并使用三次B样条进行平滑。在实际果园试验中，AGRO-Nav以约0.08 m的平均误差跟随行中心，远低于A*（0.31 m）和Theta*（0.43 m）最短路径基线，同时规划速度约快四到五倍。在Isaac Sim中，它在A*、Theta*和复现的RANSAC中线基线中取得了最低误差，并且在树木密度降至70%时保持稳定，而RANSAC基线此时性能下降。所生成的轨迹——直行居中的路段由受控转弯连接——适用于差速驱动和四轮转向平台。

## Abstract
Orchards form semi-structured environments in which parallel tree rows create natural driving corridors, yet narrow inter-row clearance and dense foliage lead geometry-agnostic grid planners to drift off the row center and risk trunk or canopy contact. We present AGRO-Nav, an automated framework for static graph-based global planning in orchards. From tree-row lines fitted to trunk clusters in a SLAM point cloud, it builds, without any manual waypoints, a sparse topological graph of intra- and inter-row connectivity; a global route is then found by Dijkstra search on this graph, connected to the start and goal by any-angle Theta* segments, and smoothed with a cubic B-spline. In real-orchard trials, AGRO-Nav follows the row center with a mean error of about 0.08 m, far below the A* (0.31 m) and Theta* (0.43 m) shortest-path baselines, while planning roughly four to five times faster. In Isaac Sim, it attains the lowest error among A*, Theta*, and a reproduced RANSAC midline baseline and remains stable as tree density drops to 70%, where the RANSAC baseline degrades. The resulting trajectories---straight row-centered segments joined by controlled turns---suit differential-drive and four-wheel-steering platforms.

## 1. 论文的核心问题与整体含义

- **研究背景**：果园属于**半结构化环境**——平行的果树行构成了自然的驾驶通道，理论上路径规划应当相对简单；然而实际场景中，行间净空狭窄、树冠枝叶茂密、果树时常缺失或间距不均，使得“应遵循的行几何”只是松散定义的。
- **核心问题**：
  - 传统的**几何无关的网格规划器**（如 A*、Theta*）将果园视为无差别自由空间，优化目标是**行驶距离最短**而非**行中心贴合**，因此在行间过渡处会切角、甚至直接穿越树行，极易与树干或树冠发生碰撞。
  - 结构化的**行拟合方法**（如 RANSAC 中线法）虽能拟合局部行几何，但只基于附近可见的树干推理，在行变得稀疏时（树干不足以恢复连续边界）性能严重退化。
  - 现有果园导航工作存在两方面的空白：一是仅做**局部行跟随**而不上升到全局拓扑表征；二是使用**手工构建或隐式图**（手动航点），缺乏从原始 SLAM 地图到可路由拓扑图的自动化管线。
- **整体含义**：本文提出 **AGRO-Nav**，一个全自动的静态图全局规划框架，能够在**整个果园地块尺度**上将 SLAM 点云转化为**稀疏的可复用拓扑图**，并直接在图上规划与行结构对齐的全局路径，弥合“局部行跟随”与“全局拓扑规划”之间的鸿沟。

## 2. 论文提出的方法论

### 2.1 核心思想

将果园导航分两阶段处理：
1. **离线建图**：从 SLAM 三维点云中自动提取树行结构，生成稀疏拓扑图（无需手动航点）。
2. **在线规划**：每次查询时，在拓扑图上用 Dijkstra 搜索全局行对齐路径，用 Theta* 生成进出路段，用 B 样条平滑输出轨迹。

### 2.2 系统管线与关键模块

| 模块 | 输入 | 输出 |
|------|------|------|
| 树干分割与树行拟合 | SLAM 3D 点云 | 树行线集合 L = {ℓᵢ}（地面系二维端点表示） |
| 拓扑图构建 | 树行线 L、参数 Θ | 拓扑图 G = (V, E) |
| 图级路径规划 | 起点/终点 + 图 G | Dijkstra 行对齐路线 |
| 进出路段规划 | 2D 代价地图 | Theta* 任意角进出路段 |
| 平滑与重采样 | 拼接后的路径 | 三次 B 样条平滑、均匀重采样的最终轨迹 |

### 2.3 拓扑图构建关键技术细节

- **行配对（GroupAdjacentLines）**：两条树行线 ℓᵢ 与 ℓⱼ 组成一个可行驶行的条件：
  - 方向夹角 < 25°；
  - 侧向间距在 3–5 m 范围内（与行间距同量级）。
- **节点生成**：
  - 种子点 sᵢⱼ = 四个端点的几何中心；
  - 以行方向单位向量 uᵢ 为方向，按**行内树间距 d_node = 2.5 m** 双向等距采样节点；
  - 节点须位于许可行驶区域 Ω 内（用户定义或默认为行对端点的包围盒扩展 2 m）。
- **边生成**：
  - **纵向边**：连接同一行内的连续节点；
  - **横向边（跨行/地头连接）**：连接相邻行的节点，须满足两个条件：① 两点连线不穿过任何树行线（视线无遮挡）；② 侧向距离小于阈值 τ_row = 4 m（通过正交投影矩阵 Π⊥ⱼ 计算）。
- **边细分**：所有超过 L_max（约 0.2 m）的边在其中点递归二分，使图分辨率均匀，同时保证状态空间远小于占据栅格。

### 2.4 基于图的全局路径规划

- 起点与终点**吸附**到最近的图节点 v_start、v_goal 上；
- 图级路径通过 **Dijkstra 算法**搜索，边权为欧氏长度；
- 因真实起点/终点通常不在图上，使用 **Theta***（任意角度规划器）在静态 2D 代价图（采用线性距离衰减代价而非 Nav2 默认的指数衰减）上规划**入口段**与**出口段**；
- 三段路径（入口 + 图路径 + 出口）拼接后经**三次 B 样条平滑**，再以固定间隔（约 0.05 m）均匀重采样输出。

### 2.5 关键参数汇总

| 参数 | 含义 | 默认值 |
|------|------|--------|
| d_node | 节点采样间隔 | 2.5 m（行内树间距） |
| τ_row | 跨行边最大侧向距离 | 4 m |
| L_max | 最大边长度（细分阈值） | 0.2 m |
| d_max | 代价图最大影响距离 | 1 m |
| 行配对角度阈值 | — | 25° |
| 行配对侧向距离范围 | — | 3–5 m |

## 7. 优点

1. **全自动拓扑提取（C1）**：从 SLAM 点云到可路由拓扑图无需任何手动航点或人工标记节点，消除了对操作者经验的依赖；
2. **无学习模型依赖**：纯几何构造（PCA 树行拟合 + 图搜索），不依赖带标注训练数据，泛化开销低；
3. **图级规划效率高（C2）**：Dijkstra 仅在稀疏图上搜索（只离散化行中心线和连接段），比栅格搜索快 4–5 倍，适合嵌入式设备实时运行；
4. **可调的分辨率与连通性参数**：节点间距、跨行阈值、边长度上限均可直接调节，便于适应不同果园布局；
5. **轨迹平滑且可执行（C3）**：三次 B 样条平滑后的直行+受控转弯轨迹适配差速驱动与四轮转向两类平台；
6. **对树密度下降的稳健性**：在 70% 树密度下误差几乎零退化，优于 RANSAC 结构基线的表现；
7. **安全裕度均匀性**：行中心贴合的一致性（低标准差）将平台跟踪误差安全地吸收在净空裕度中，减少树干碰撞风险；
8. **消融对照设计合理（C4）**：同时对比“几何
