## 摘要
世界模型让机器人能够想象可能的未来，但利用这一能力进行实时控制却受到表示错位的瓶颈制约：生成模型与规划器在解耦的流形上运行，因此规划器没有可搜索的共享结构，而必须将每个候选解码回高维像素空间进行评估。这一解码步骤是物理硬件上实时控制的主要障碍。本文提出Hydra，一种离散世界动作模型，通过将规划器（包括采样器和评估器）移入模型内部来弥合这一差距。Hydra在视觉状态、物理位姿和控制动作上建立统一的潜在流形，然后通过模态特定的矢量量化瓶颈将该流形压缩为运动动力学意图和视觉状态的离散词汇表。由于候选现在直接来自这个共享流形，采样由模型自身对观察的理解所引导，而非盲目提出，评估也原生地在离散空间内进行：候选根据运动学-感知代价进行排序，无需解码到像素。我们将其称为离散潜在规划（DLP）。由于仅对离散意图进行规划无法提供物理驱动所需的平滑连续命令，Hydra将DLP与条件流匹配相结合，将每个选定的意图映射为执行用的连续轨迹。在两个物理机器人平台上进行的评估表明，Hydra在目标导向规划方面优于最先进的世界模型，同时在闭环执行能力上达到或超越领先的反应式基础策略。

## Abstract
World models let robots imagine possible futures, but exploiting this capability for real-time control is bottlenecked by a representation misalignment: the generative model and the planner operate on decoupled manifolds, so the planner has no shared structure to search over and must instead decode every candidate back into high-dimensional pixel space to evaluate it. This decoding step is a major obstacle to real-time control on physical hardware. In this paper, we present Hydra, a discrete World Action Model that closes this gap by moving the planner, both the sampler and the evaluator, inside the model. Hydra establishes a unified latent manifold over visual states, physical poses, and control actions, then compresses this manifold through modality-specific Vector-Quantized bottlenecks into discrete vocabularies of kinodynamic intents and visual states. Because candidates are now drawn directly from this shared manifold, sampling is informed by the model's own understanding of the observation rather than proposed blind, and evaluation happens natively within the discrete space: candidates are ranked by a Kinematic-Perceptual Cost, without ever decoding to pixels. We term this Discrete Latent Planning (DLP). Because planning over discrete intents alone cannot supply the smooth, continuous commands physical actuation requires, Hydra pairs DLP with conditional Flow Matching, which maps each selected intent to a continuous trajectory for execution. Evaluated on two physical robotic platforms, Hydra outperforms state-of-the-art world models in goal-directed planning, while matching or exceeding the closed-loop execution capabilities of leading reactive foundation policies.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题定位**：现有世界模型（World Models）虽然能让机器人“想象”未来并用于规划，但其生成模型与规划器运行在**解耦的表示流形**上——规划器生成的连续动作候选与生成模型的潜在空间没有共享结构。因此，每条候选轨迹都必须被生成模型解码回高维像素空间，再用 LPIPS 等感知指标与目标图像比较，才能评估其质量。这一“解码再评估”过程计算开销极大，在物理机器人上无法满足实时控制的需求。
- **关键瓶颈**被概括为“表示错位”：  
  - 连续采样空间无穷大，采样器只能盲试，大量计算浪费在不可行轨迹上；
  - 目标评估依赖像素级解码，延迟高且感知指标易受视觉干扰物误导；
  - 规划器无法利用模型内部对“物理可行性”和“拓扑合理性”的先验知识。
- **整体含义**：Hydra 的核心主张是——若要让世界模型真正能驱动物理机器人，必须把规划器（采样器和评估器）**移入模型内部**，在统一的潜在流形上完成最近路径搜索与安全评估，从而绕开逐候选像素解码的瓶颈。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

Hydra 是一种“World Action Model (WAM)”，其整体框架可分为四个部分：

### 2.1 统一早期融合多模态编码
- 输入为视觉图像、位姿和上一时刻动作，通过**早期融合**将视觉潜向量与经过傅里叶特征映射的动作/位姿向量直接相加，形成单一 token 流，再送入 Transformer 编码器。
- 这种设计避免了 Gato/Cosmos 等模型在 Transformer 内部靠长上下文做“in-context alignment”的负担，使自注意力全部用于学习时间动力学，模型参数量因此更小。
- 训练中使用余弦退火的模态掩码课程策略，增强对传感器缺失的鲁棒性并支持无条件探索。

### 2.2 离散瓶颈（Vector-Quantized Bottleneck）
- 编码器输出上下文 token 后，解码器通过交叉注意力预测未来意图 token。
- 未来意图分别经过三个**模态特定 VQ 码本**：视觉码本（2048 项）、位姿码本（64 项）、动作码本（64 项）。
- 采用**非对称词汇量化**：视觉码本容量大以保证生成保真度，运动/位姿码本容量小以保证规划搜索速度。
- 通过“确定性线性锚定”和辅助 MSE commitment loss 稳定码本空间，防止当训练初期码本随机未校准导致下游 Flow Matching 发散。

### 2.3 规划：离散潜在规划（Discrete Latent Planning, DLP）
- **搜索空间**不再是连续动作流形，而是码本中的离散拓扑意图序列。候选意图从专家先验初始化，并在每次迭代中施加时间平滑的高斯噪声和带指数的 Gumbel 噪声扰动，生成多样且物理可行的路径分支。
- 评估候选意图采用**Kinematic-Perceptual Cost (KPC)**，公式为：

  \[
  J_{KPC}(\tau) = C_{geo} 
  + \sum_{t=1}^{T} \gamma^t \left(
  \lambda_{img} C^{(t)}_{img}
  + \lambda_{prior} C^{(t)}_{prior}
  + \lambda_{ent} C^{(t)}_{ent}
  + \lambda_{vq} C^{(t)}_{vq}
  \right)
  \]

  其中：
  - \(C_{geo}\)：几何目标距离（解码一次即可）；
  - \(C_{img}\)：视觉目标 MSE（仅当场景中能看到目标时启用有效）；
  - \(C_{prior}\)：候选对无条件专家先验的负对数似然，隐含人类安全驾驶先验；
  - \(C_{ent}\)：视觉 token 分布的 Shannon 熵，测量对未来视觉状态的预测不确定性；
  - \(C_{vq}\)：连续意图与其最近码本项之间的量化误差（余弦距离），用于在嵌入空间检测“离流形”的碰撞状态。
- 所有评估均在离散潜在空间完成；只有获胜候选轨迹最终通过 Flow Matching 解码为连续位姿/动作，用于执行。

### 2.4 执行：连续 Flow Matching
- 为了在离散意图与物理执行所需的连续信号之间建立桥梁，Hydra 使用三个 Flow Matching 解码器（分别对图像、位姿、动作）回归线性速度场。
- 该 ODE 式生成方法（Rectified Flow）比扩散 SDE 轨迹更直，可在更少的函数评估（NFE）下采样，为实时闭环提供保障。

### 2.5 两种局部路径跟随模式（当有外部全局引导时）
- **分类器自由引导（CFG）**：对无条件先验与目标条件意图做线性外插。速度快，但长时跟踪时可能产生“流形偏离”，导致动态幻觉。
- **子目标采样**：仅从专家先验和有效码本中生成轨迹，再按与子目标的几何偏离挑选最优解。将每个候选都约束在离散流形上，安全性更高，适合长距离跟踪。
- 路径跟随目标函数与全局 DLP 不同：其核心是最小化与外部 waypoint 的偏差，同时受学习到的安全流形约束。

## 6. 主要结论与发现

- **生成质量**：Hydra 的长时 FVD（19.16）显著强于 NWM/B（22.11）与 VertiFormer（81.03），其离散潜在流形即使在量化损失下也能保持长时间动作与时序一致性（而 NWM 约 8 秒后漂移）。
- **规划效率与安全性**：  
  - Hydra DLP 的规划时间约 0.9 秒，相对于 NWM 的 500+ 秒实现 >500× 加速；
  - 无障碍场景成功率 10/10，遮挡场景 8/10，盲角场景 8/10；而 NWM 与 VertiFormer 在所有含障碍场景成功率为 0%。
  - 障碍感知能力来源于码本量化误差与预测熵的联合信号，二者在碰撞逼近时同步上升，验证“无需像素解码”也能检测危险状态。
- **局部路径跟踪**：Hydra 在目标密集图输入频率更低（稀疏 waypoint vs 2Hz 目标图）的前提下，仍匹配或超过 GNM/ViNT/NoMaD 的成功率与干预次数；
  - CFG 适合短走廊，Sampling 适合长距离；VertiFormer 的速度最快但缺乏安全与灵活性。
- **消融**：\(C_{prior}\)、\(C_{vq}\)、\(C_{ent}\) 每一项在移除后都会在两台机器人上造成更多碰撞，证明各代价项互为补充、缺一不可；视觉目标代价 \(C_{img}\) 只在目标可见时有效，否则会误导规划。

## 7. 优点

- **问题洞察清晰**：将“规划器与世界模型不在同一流形”作为核心瓶颈，并直接以此为设计驱动，学术贡献具有一般意义。
- **方法新颖且内在自洽**：通过 VQ 码本把连续路径搜索变成离散词汇搜，模型自带的量化误差与预测熵同时作为碰撞信号，成本函数设计巧妙，实际物理部署验证了其有效性。
- **架构轻量而高效**：143M 参数，早期融合减少了跨模态对齐负担，相比 200M 的 NWM 和动辄上 B 级的通用 WAM，更适合板载和实时搜索。
- **实验逼真度高**：使用两台实际机器人、三类路线场景和 10 次/配置的物理重复，并在线可视化规划分支树，具有较强工程说服力。
- **对失败模式的自我剖析深刻**：公开了“障碍视觉复杂度误报”、行人消失、目标盲种子下错过路口离散、CFG 流形漂移等，使论文透明度高。

## 8. 不足与局限

- **码本可扩展性受限**：视觉码本只有 2048 项，把行人等小物体当作高频噪声丢弃；更大码本能改善泛化但会线性增加检索成本，形成“表达力 vs 延迟”的僵局，论文只在思路上提出自适应分层词汇，没有给出解决。
- **碰撞检测非完美**：复杂高纹理草丛会产生类似障碍的量化误差误报，而与障碍同色的平整墙面可能被漏报，“结构异常”与“纹理复杂度”难以区分。
- **零样本动态目标难**：行人/动态智能体经常被抹除，Hydra 更适合静态世界导航，没有真正解决动态社交环境的规划问题。
- **规划模式的整体成功率不稳定**：长距离路线中规划模式只有 40% 成功率；由于种子先验不含目标方向，3 次迭代搜索不足以避免不可逆转的分叉失误，作者将其归为“延迟预算不匹配”，并非彻底解决。
- **算力披露不充分**：训练所需的 GPU 数量、时长、能耗没有给出；板载实时性更多是逻辑推断，并未真正展示在 Jetson 等边缘设备上的运行结果。
- **实验公平性隐忧**：基线的迭代/样本数固定且未做充分超参搜索，尤其 VertiFormer 的避障失败可能是 MPPI 参数或代价配置欠佳所致；没有统计显著性检验与多随机种子评估。
- **离线 ADE/FDE 上确定性基线仍占优**，Hydra 虽声称策略精度不取舍，但其本质上是通过“更多生成配合几何成本”赢得安全性，并非所有指标上全面领先。

## 总结

Hydra 通过“早期融合统一流形 + 模态特定 VQ 离散瓶颈 + 离散潜在规划 + Flow Matching 连续执行”，成功把世界模型从“供外部挑拣的预测器”变成了“能自主搜索并求值的棋盘”，在物理机器人上实现了近实时的目标导向规划和安全的局部跟随。在生成保真度、规划成功率、碰撞信号可解释性上具有明显优势；但在码本表达力、动态对象建模、搜索多样性与算力预算之间仍存在待解的结构性取舍。
