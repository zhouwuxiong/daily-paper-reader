## 摘要
多模态终身导航要求智能体在自主探索未见环境的同时，顺序完成由物体类别、语言描述或参考图像指定的导航任务。现有方法主要通过构建以状态为中心的语义场景图来完成这些任务。通过将场景图视为语义观测的持久存储库，这些方法难以区分相似实例，难以联合表示语义目标与探索边界，也难以有效利用导航记忆和轨迹经验。为解决这些局限性，我们提出了时空事件图导航（STEGNav），一种无需训练的框架，沿互补的空间与时间轴将传统场景图扩展为时空事件图。空间轴执行查询条件下的实例定位，并联合表示语义目标与具有可达性、路径成本和探索效用的占用感知探索边界。时间轴采用轨迹感知的双窗口记忆，以保留近期决策-轨迹事件和已验证的跨子任务导航结果。基于VLM的导航智能体对生成的时空事件图进行推理，并选择目标实例或探索边界作为其下一个导航目标。STEGNav在GOAT-Bench上达到66.3%的SR和39.7的SPL，在HM3Dv1和HM3Dv2上分别达到64.0%和69.4%的SR。消融研究和错误分析验证了这两个轴的互补效应，表明事件驱动的时空表示提高了导航可靠性和跨子任务经验复用。

## Abstract
Multimodal lifelong navigation requires an agent to autonomously explore unseen environments while sequentially completing navigation tasks specified by object categories, language descriptions, or reference images. Existing methods primarily accomplish these tasks by constructing state-centric semantic scene graphs. By treating scene graphs as persistent repositories of semantic observations, these methods struggle to distinguish similar instances, jointly represent semantic targets and exploration frontiers, and effectively exploit navigation memory and trajectory experience. To address these limitations, we propose Spatio-Temporal Event Graph Navigation (STEGNav), a training-free framework that extends conventional scene graphs into spatio-temporal event graphs along complementary spatial and temporal axes. The spatial axis performs query-conditioned instance grounding and jointly represents semantic targets and occupancy-aware exploration frontiers characterized by reachability, path cost, and exploration utility. The temporal axis employs trajectory-aware dual-window memory to retain recent decision--trajectory events and verified cross-subtask navigation outcomes. A VLM-based navigation agent reasons over the resulting spatio-temporal event graph and selects either a target instance or an exploration frontier as its next navigation goal. STEGNav achieves 66.3% SR and 39.7 SPL on GOAT-Bench, as well as SR scores of 64.0% and 69.4% on HM3Dv1 and HM3Dv2, respectively. Ablation studies and error analyses validate the complementary effects of the two axes, demonstrating that event-driven spatio-temporal representations improve navigation reliability and cross-subtask experience reuse.

### 1. 核心问题与整体含义

- **研究背景**：具身导航要求智能体同时具备目标理解、环境探索与导航到达能力。任务形态已从“单目标搜索”演变为**多模态终身导航**——即在一个场景内，智能体需依次完成由“物体类别”“语言描述”或“参考图像”指定的多个子任务，并在全过程持续复用积累的环境知识。
- **现有方法的缺陷**：现有框架（如 MSGNav、MTU3D 等）普遍将场景图视为**以状态为中心（state-centric）的持久化语义仓库**，存在三大结构性限制：
  1. **实例模糊性**——场景图仅保存物体类别级信息，无法区分同一类别下的不同物理个体；
  2. **语义—空间分离**——语义物体节点与占用地图中导出的探索前沿分裂为两种独立输入，VLM 无法联合推理目标可达性、路径代价和探索效用；
  3. **记忆缺失与重复探索**——场景图只记录即时环境状态，不显式保存导航过程，导致已探索区域被重复访问，且已验证的目标位置无法被跨子任务复用。
- **核心论点**：多模态终身导航本质上是**事件驱动（event-driven）**的——每次导航决策既改变智能体对空间的认知，又为未来的导航决策沉淀经验。论文据此主张将静态的“状态中心场景图”升级为动态的“**时空事件图**”。

### 2. 方法论

论文提出 **STEGNav（Spatio-Temporal Event Graph Navigation）**，这是一个**无需任何训练**的通用导航框架。与传统空间图不同，STEGNav 构建的时空事件图在两条正交轴上同时扩展场景图：

| 坐标轴 | 模块 | 核心功能与机制 |
|--------|------|----------------|
| **空间轴** | 查询条件实例定位（QIG） | VLM 模块 Φ_inst 针对每个候选节点，输出查询—实例相关度 r_t^k(i) 和查询条件化语言描述 d_t^k(i)；只向导航 VLM 暴露 Top-N 最相关实例 |
| **空间轴** | 占用感知前沿定位（OFG） | 将前沿单元格聚类为前沿节点，整合“可达性、路径代价、探索增益、访问状态”；通过“语义—前沿边”和“导航边”构建语义节点与前沿节点的统一图结构 |
| **时间轴** | 短时决策轨迹窗口 | 保存最近 W_st=20 条“高层决策+轨迹段+经过区域+路径长度+执行结果”事件；轨迹被压缩为起点/终点、经过图节点与占用覆盖；不设硬性探索约束，显式暴露重复路径 |
| **时间轴** | 长时任务事件窗口 | 仅存储通过验证（VLM 判定 + 位置容差 δ=0.8m）的前序子任务结果，以“锚点”形式保存（实例 ID、类别、模态、历史查询、终视外观特征、房间标签），容量 W_lt=8；锚点不存固定坐标，需经持久 ID 或 CLIP 外观相似度与当前场景图重新关联 |

- **统一事件图公式**：将查询事件 *u_k*、空间子图 *G*_*t*^spa、短时事件 *M_st* 与长时事件 *M_lt* 合并为整体事件图，节点集为三者并集、边集为三者并集，随后由 VLM 导航策略直接输出“目标物体节点”或“探索前沿节点”。
- **验证与回写机制**：对物体目标执行停止判定，只有满足式 `w_k = 1{ i_term^k = i_k^* ∧ o_k = + ∧ d_k ≤ δ }` 的成功结果（全程**不依赖模拟器真值**）才写入长时记忆，并对环境图和占据图作增量更新。
- **框架流程**：感知（RGB-D）→ 场景图更新/建图 → 图序列化 → VLM 决策（导航 vs 探索）→ 执行轨迹回写 → 验证 → 长时锚点更新，循环推进。

### 3. 实验设计

- **数据集 / Benchmark**：
  1. **GOAT-Bench**（主基准）：Val-Unseen 分割含 36 个场景、每场景 10 个 episode、每个 episode 含 5–10 个顺序子任务，需同时覆盖目标定位、长程探索与跨子任务经验复用三种能力。
  2. **HM3Dv1 / HM3Dv2**（泛化评估）：用于验证框架在类别级（category-level）ObjectNav 上的迁移能力（HM3Dv1 含 20 场景/2000 episodes；HM3Dv2 含 36 场景/1000 episodes，均为 6 类物体目标）。
- **对比方法**：同时覆盖学习型方法与免训练方法——学习型包括 SenseAct-NN、MTU3D、SGM、SPNet 等；免训练包括 Modular GOAT、CoW、VLFM、VLMNav、DyNaVLM、TANGO、3D-Mem、EvoMemNav、MSGNav、SG-Nav、UniGoal 等。
- **评估指标**：成功率先行（SR）与路径加权成功率（SPL），以标准 1.0m 测地距离判成功。

### 4. 资源与算力

- **明确点**：STEGNav 是免训练框架，**无任何网络训练/微调成本**，即不存在 GPU 训练时长或训练算力开销。
- **推理侧配置**：论文仅注明 VLM 主干使用 `gpt-5.4-mini`（温度 0.95、单次采样、每个推理决策最多 4096 个 token，未用多数投票/自洽采样）；感知模块使用 YOLOv8x-World、SAM-L 与 CLIP ViT-H-14。

### 5. 实验数量与充分性

- **主实验数量**：3 个 benchmark（GOAT-Bench Val-Unseen、HM3Dv1、HM3Dv2）+ 1 组组件消融（在固定子集上）+ 1 项失败原因归类分析 + 2 组可视化案例；实验总量约 5–6 组统计实验和 2 个定性案例。

### 6. 主要结论与发现

- 在 **GOAT-Bench Val-Unseen** 上，STEGNav 取得 **66.3% SR / 39.7 SPL**，在 SR 上比最强对照方法高出 3.9 个百分点；
- 在 **HM3Dv1 / HM3Dv2** 上分别取得 **64.0% / 69.4% SR**，均创成功率新高，证明时空事件表示可有效泛化到类别级 ObjectNav；
- **消融结论**：QIG、OFG、DWM 三者互补：OFG 对整体 SR/SPL 带来最大增量（整体 SR 提升 7.5pp），DWM 对图像查询促进作用最显著（SR 从 68.2% 提升至 73.9%），而 QIG 则在语言/图像等实例级查询中作用突出；
- **错误分析**：在 278 个失败样本中，总失败次数下降约 34.1%（从 123→81），“同类别实例混淆”降幅最大（−53.8%），“低效探索”绝对减少最大（−40.0%），而“执行/停止”类失败改善有限（−22.2%）。

### 7. 优点

- **方法层面的显著亮点**：
  1. **“无需训练且即插即用”**——框架只依赖预训练感知模型、CLIP 和通用 VLM 的推理能力，不用训练策略网络，天然支持开放词汇与即时新场景部署；
  2. **“统一的图决策结构”**——把语义实例、探索前沿、可达性、路径代价、历史事件全部表示为同一张图上的节点和边，VLM 不需要在异构输入间做隐式对齐；
  3. **细粒度的实例级定位**——突破了多数场景图方法停留在类别级检索的瓶颈，使“沙发旁的桌子 #2”这类同类别实例查询有了明确的判别通道；
  4. **双窗口记忆设计理性**——短时窗口记录全过程而不加硬性禁止约束、长时窗口只存验证结果且锚点需重新与实时图关联，一定程度上避免了“记忆漂移”和“过期信息直接指导当前决策”两种风险；
  5. **验证不依赖仿真 ground truth**——验证环节只用 VLM 判断与位置容差，更贴近真实部署条件。

- **实验设计亮点**：在 GOAT-Bench 与 HM3D 双基准上同时对齐多模态任务与单模态经典任务，能较稳健地评估空间—时间两轴的普适性和可迁移性。

### 8. 不足与局限

- **语义与空间表示在简化中损耗**：场景图暂存紧凑元信息与代表性 RGB 裁剪块，而稠密 3D 几何、颜色/材质等原始观测被压缩，这可能在复杂开放场景或细粒度语义区分（如“藤椅 vs 摇椅”）中造成信息不足。
- **对 VLM 能力的高度依赖**：实例定位、导航决策、停止判定、历史歧义验证全都押注在单一 VLM（GPT-5.4-mini）上；VLM 幻觉、对长序列图序列化后的上下文丢失、视觉-语言对齐偏差都可能成为错误源，且论文未对不同 VLM 做敏感性分析。
- **路径效率与成功率不匹配**：在 HM3D 上虽然 SR 最高，但 **SPL 反而低于部分基线**（如 VLFM、EvoMemNav），说明当前方法依靠更多探索换取更高的目标发现率，尚未在效率维度上达到最优；这也暴露了高层图推理与低层路径控制之间存在脱节——论文自身也承认执行/停止类错误改进有限。
- **对比公平性与完整性受限**：最主要竞品 MSGNav 在 SPL 上缺失报告，使得“最强基线”之间的对比只落脚于 SR 单项，结论生态稍显残缺。
- **验证机制存在漏报/误报窗口**：长期记忆只保存验证通过的事件，且类别查询产生的锚点不能服务于实例级查询（反之亦然），同时锚点关联依赖 CLIP 相似度阈值，在遮挡重、光照变化大或室内装潢同质化严重的情况下容易发生误关联。
