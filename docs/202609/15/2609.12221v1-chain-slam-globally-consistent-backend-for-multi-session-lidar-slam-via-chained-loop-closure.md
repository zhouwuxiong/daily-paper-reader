## 摘要
在长空间与时间跨度上保持一致性仍是大规模LiDAR SLAM中的一个基本挑战，尤其是在整合跨多个会话采集的地图时。我们提出Chain-SLAM，一种LiDAR SLAM后端，能够在大型规模下实现具有全局一致性的在线多会话地图对齐与复用。我们实现了一种链式回环闭合机制，该机制通过邻接图在跨会话关键帧之间高效传播几何约束，从而能够由可靠的短时域回环闭合触发稳健的长时域一致性。该系统利用GNSS邻近地点识别来初始化跨会话对齐，然后在统一因子图中实时执行回环闭合检测，并对已加载地图与新获取轨迹进行联合优化，在无需动态物体移除的情况下保持会话间和会话内几何一致性，并以最少的超参数调优实现跨平台鲁棒性。实验结果表明，在大规模数据集上轨迹精度得到提升，且多会话整合具有鲁棒性。我们发布源代码，以支持大规模多会话LiDAR SLAM的可复现研究。项目网站：https://ai4ce.github.io/Chain-SLAM/

## Abstract
Maintaining consistency over long spatial and temporal horizons remains a fundamental challenge in large-scale LiDAR SLAM, particularly when integrating maps collected across multiple sessions. We present Chain-SLAM, a LiDAR SLAM backend enabling online multi-session map alignment and reuse with global consistency at large scale. We implement a chained loop closure mechanism that efficiently propagates geometric constraints across inter-session keyframes through an adjacency graph, enabling robust long-horizon consistency triggered by reliable short-horizon loop closures. The system initializes inter-session alignment with GNSS-proximity place recognition, then performs on-the-fly loop closure detections and joint optimization of loaded maps and newly acquired trajectories within a unified factor graph, maintaining both inter- and intra-session geometric consistency without dynamic object removal, and cross-platform robustness with minimal hyperparameter tuning. Experimental results show improved trajectory accuracy and robust multi-session integration on large-scale datasets. We release our source code to support reproducible research in large-scale multi-session LiDAR SLAM. Project site: https://ai4ce.github.io/Chain-SLAM/

## 1. 核心问题与整体含义

- **研究动机**：大规模 LiDAR SLAM 需要在长空间与长时间跨度上保持一致性，但真实环境通常由多次会话（multi-session）分别采集，重访时受动态物体、光照、天气等变化影响，导致轨迹漂移与地图不一致。
- **现有方法的两类不足**：
  - 主流 SLAM 系统（如 FAST-LIO2、LIO-SAM 等）虽通过紧耦合里程计 + 回环 + 因子图获得良好局部精度，但**不支持多会话部署或地图在线复用**。
  - 现有地图合并方法（如 LT-Mapper、LAMM）多把合并当作**后处理**，无法在运行中利用先验会话信息，且随会话与回环约束增多，全局优化难以收敛。
- **额外挑战**：长期环境变化使地点识别退化；现有系统跨平台鲁棒性差，常依赖高保真传感器、高频率测量或大量超参调优。
- **论文定位**：提出 Chain-SLAM——一个可扩展的实时多会话 LiDAR-惯性 SLAM 后端，支持在线地图加载、合并、复用与统一因子图联合优化，并开源代码。

## 2. 方法论

### 2.1 核心思想

- 采用**前端–后端架构**：
  - 前端：紧耦合 LiDAR-惯性里程计，源自 FAST-LIO2，通过直接 scan-to-map 配准估计运动。
  - 后端：扩展 Fast LIO SAM，将链式回环与地图合并纳入统一的 LIO-SAM 风格因子图，使用 iSAM2 增量优化。
- 把已加载的旧地图视为**基准地图**，新会话视为**新子图**；检测到跨会话对应后进行重定位与对齐，再合并进统一位姿图联合优化。

### 2.2 因子图建模

- 位姿节点 \(X=\{x_0,\dots,x_N\}\)，\(x_i \in SE(3)\)。
- 一元先验因子：\(\phi_p(x_i)=\|\log(T_i^{-1}x_i)\|^2_{\Sigma_p}\)，锚定每段轨迹起始位姿。
- 二元因子：\(\phi_b(x_i,x_j)=\|\log(T_{ij}^{-1}x_i^{-1}x_j)\|^2_{\Sigma_{ij}}\)，包含里程计因子与回环因子。
- 目标函数：\(X^*=\arg\min_X \sum \phi_p + \sum \phi_b\)，由 iSAM2 增量求解。

### 2.3 回环检测与配准

- 候选帧：基于 K-D Tree 在关键帧位置做空间邻近搜索，并要求满足最小时间间隔。
- 几何配准：当前关键帧单帧扫描 vs 匹配历史关键帧的子图，使用 ICP 最小化均方误差 \(e_{ij}\)。
- 接受条件：ICP 收敛且 \(e_{ij}\le\tau\)；协方差 \(\Sigma_{ij}=\lambda e_{ij}I_6\)，几何一致者置信度更高。

### 2.4 链式回环闭合（核心创新）

- 维护统一的**邻接图**，每个已接受回环在关键帧节点间建立一条边。
- 当当前帧 \(i\) 与加载地图帧 \(j\) 建立直接跨会话回环后：
  1. 在邻接图上做 **BFS**，找出与 \(j\) 属于同一连通分量的所有加载地图关键帧 \(N(j)\)（无显式深度限制，实际传播范围由回环检测半径隐式约束）。
  2. 对每个 \(k\in N(j)\)（排除 \(j\) 自身）做 scan-to-submap ICP。
  3. 若 \(f_{ik}\le\tau\)，则以 \(\Sigma_{ik}=\lambda f_{ik}I_6\) 添加链式回环因子。
- **关键设计**：链式回环只在当前会话与加载地图之间建立，不在当前会话内部建立，以增强跨会话一致性同时避免对局部里程计施加冗余约束。
- 效果：一次可靠短时域回环可触发多个长时域约束，减少对应搜索成本，避免地点识别假阴性；新旧结构形成双向交叉验证。

### 2.5 地图表示与多会话集成

- 关键帧使用持久索引，保存原始/优化位姿、LiDAR 扫描、回环对及协方差、场景索引范围。
- 保存时序列化上述索引表示；加载时恢复关键帧并追加到全局容器，重建先验、里程计、回环因子，恢复为图中的一个连通分量。
- 新会话关键帧以新索引增量加入，先形成独立分量，再通过跨会话回环连接。

### 2.6 初始化与合并

- 利用 GNSS 邻近搜索做地点识别，K-D Tree 索引 GNSS 位置。
- 候选对用 **FPFH + RANSAC** 估计初始长时域变换 \(T^R_{ij}\)，以 fitness 分数 \(f^R_{ij}=|C_{\text{inlier}}|/|P_t|\) 是否 \(\ge\tau_R\) 作为接受条件。
- 首个被接受的变换用于将当前轨迹对齐到加载地图帧，随后重建因子图（替换当前会话先验、用变换后位姿重新初始化），再沿对齐轨迹用 ICP 重新检测回环。

### 2.7 超参数考量

- 跨平台仅需调整传感器相关参数（LiDAR 线数、IMU 噪声、LiDAR-IMU 外参）和随平台速度变化的回环检测频率与关键帧生成阈值；回环 ICP 误差阈值 \(\tau\)、FPFH/RANSAC 设置在两个数据集上保持一致。
- 回环采用 scan-to-submap，地图合并采用 submap-to-submap；点云先体素降采样。
- 为防止邻接图连通分量过度合并，建议满足 \(v/f_{lc} > r_{lc}\)，即平台在两次检测间行进超过检测半径。

## 3. 实验设计

## 6. 主要结论与发现

- **轨迹精度**：MARS 上相比基线平移误差降低 **5–10 倍**、旋转误差降低 **1.5–3 倍**；NCLT 上取得更低平移 RMSE。链式回环在两个数据集上均进一步降低平移与旋转 RMSE。
- **几何一致性**：点云配准 RANSAC RMSE 比 Fast-LIO2 降低约 **20%**，比 LAMM 降低约 **40%**；链式版本在多数街道取得最低 ICP 精化误差。
- **视角对齐 / 重建**：3DGS 测试 PSNR 与 Loss 均为最优，链式版本最强。
- **实时性**：前端耗时与 Fast-LIO2 相当，后端异步运行；MARS 约 2 Hz、NCLT 约 13 Hz，内存略低于 LAMM。
- **跨平台**：在传感器配置差异极大的 MARS 与 NCLT 上，除传感器相关参数与随速度调整的回环频率外，关键阈值保持一致即可工作。

## 7. 优点

- **方法创新性**：链式回环利用邻接图连通性把可靠短时域回环传播为长时域约束，减少全局地点识别与穷举候选搜索，兼具鲁棒性与效率。
- **在线地图复用**：把旧地图作为连通分量加载进统一因子图，实现运行中增量对齐与联合优化，而非事后合并。
- **鲁棒性设计**：无需显式动态物体去除即可应对环境变化；scan-to-submap / submap-to-submap 配准提升对噪声与跨平台的适应性。
- **工程实用性**：超参少、开源、支持持久索引序列化，具备真实部署潜力。
- **评估维度多元**：除常规 APE 外，引入点云配准与 3DGS 视角对齐，能揭示全局一致性而非仅局部精度。

## 8. 不足与局限

- **GNSS 依赖**：跨会话对应初始化完全依赖 GNSS 邻近搜索，GNSS 拒止或退化环境下难以工作；作者也将其列为未来改进方向（可替换为 Scan Context、STD 等 LiDAR 地点识别）。

- **旋转精度短板**：NCLT 上 Fast-LIO2 的旋转 RMSE 最低，说明方法在强局部可观测性场景下旋转精度未必占优。
- **回环频率约束**：需满足 \(v/f_{lc} > r_{lc}\) 以维持连通分量空间分离，实际部署需针对平台速度调参，BFS 无深度限制带来连通分量过度合并风险。

- **地图合并配准敏感性**：FPFH + RANSAC 对噪声较敏感，论文虽用子图-子图配准缓解，但未给出失败案例分析。
