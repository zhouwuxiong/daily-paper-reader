## 摘要
世界模型使机器人能够想象可能的未来，但利用这一能力进行实时控制受到表示不一致的瓶颈限制：生成模型和规划器在解耦流形上运行，因此规划器没有可搜索的共享结构，而是必须将每个候选解码回高维像素空间进行评估。这一解码步骤是物理硬件上实时控制的主要障碍。在本文中，我们提出了Hydra，一种离散世界动作模型，通过将规划器（包括采样器和评估器）移入模型内部来弥合这一差距。Hydra在视觉状态、物理位姿和控制动作上建立统一的潜在流形，然后通过特定模态的矢量量化瓶颈将该流形压缩为运动动力学意图和视觉状态的离散词汇表。由于候选现在直接来自这个共享流形，采样由模型自身对观察的理解引导，而非盲目提出；评估则原生地在离散空间内进行：候选通过运动学-感知成本进行排序，无需解码到像素。我们称之为离散潜在规划（DLP）。由于仅对离散意图进行规划无法提供物理驱动所需的平滑连续命令，Hydra将DLP与条件流匹配相结合，将每个选定的意图映射为用于执行的连续轨迹。在两个物理机器人平台上的评估表明，Hydra在目标导向规划方面优于最先进的世界模型，同时在闭环执行能力上达到或超过领先的反应式基础策略。

## Abstract
World models let robots imagine possible futures, but exploiting this capability for real-time control is bottlenecked by a representation misalignment: the generative model and the planner operate on decoupled manifolds, so the planner has no shared structure to search over and must instead decode every candidate back into high-dimensional pixel space to evaluate it. This decoding step is a major obstacle to real-time control on physical hardware. In this paper, we present Hydra, a discrete World Action Model that closes this gap by moving the planner, both the sampler and the evaluator, inside the model. Hydra establishes a unified latent manifold over visual states, physical poses, and control actions, then compresses this manifold through modality-specific Vector-Quantized bottlenecks into discrete vocabularies of kinodynamic intents and visual states. Because candidates are now drawn directly from this shared manifold, sampling is informed by the model's own understanding of the observation rather than proposed blind, and evaluation happens natively within the discrete space: candidates are ranked by a Kinematic-Perceptual Cost, without ever decoding to pixels. We term this Discrete Latent Planning (DLP). Because planning over discrete intents alone cannot supply the smooth, continuous commands physical actuation requires, Hydra pairs DLP with conditional Flow Matching, which maps each selected intent to a continuous trajectory for execution. Evaluated on two physical robotic platforms, Hydra outperforms state-of-the-art world models in goal-directed planning, while matching or exceeding the closed-loop execution capabilities of leading reactive foundation policies.

## 1. 论文的核心问题与整体含义

- **研究背景**：世界模型（World Model, WM）为机器人提供了"想象未来"的能力，即通过自回归预测未来视觉状态来评估候选动作。然而，现有导航世界模型（如 NWM）在实际部署中面临一个**关键瓶颈——表示不对齐**：生成模型与外部规划器（如 CEM、MPPI）运行在**解耦的流形**上，规划器没有共享结构可供搜索，只能通过**盲目连续采样**提出候选，并逐一**解码回像素空间**（图像）才能评估该候选与目标的距离。
- **核心问题**：这种"每候选解码到像素"的范式带来极端计算开销，使规划器在物理硬件上**无法满足实时控制约束**（NWM 单次规划超过 500 秒）；同时，连续采样空间随规划时域指数增长，规划器浪费大量算力在不可行的轨迹上。
- **总体含义**：Hydra 提出将**规划器本身（采样器与评估器）内置于世界模型内部**，通过构造统一的联合潜在流形，使搜索和评估发生在与生成模型共享的离散空间内，从而在**保证生成式预见能力**的同时实现**实时边缘部署**，弥合"想象"与"执行"之间的鸿沟。

## 2. 论文提出的方法论

### 2.1 核心思路：从"外部规划器查询世界模型"到"规划器内置于模型中"

- Hydra 将视觉状态、物理位姿和动作三者建模为**联合生成流**，而非把动作仅当输入、图像仅当输出。
- 由于采样直接来自共享潜在流形，候选天然是模型自身理解的物理可行行为，避免了盲目的连续空间探索。

### 2.2 统一多模态编码（早期融合）

- 视觉采用冻结的 Stable Diffusion VAE 提取潜在向量；位姿和动作通过 Fourier Feature Mapping 编码。
- 各模态广播到统一长度后**直接相加**形成单一统一 token 流（受 VertiFormer 启发），而非在 Transformer 中交叉注意力对齐。
- 训练时采用**余弦退火模态掩码课程**（cosine-annealed modality infilling），增强对部分观测的鲁棒性。

### 2.3 离散瓶颈（Vector-Quantized Bottleneck）

- 未来意图 token 分别通过模态特定的 VQ 码本：图像码本 `|V_i| = 2048`，位姿码本 `|V_p| = 64`，动作码本 `|V_a| = 64`（**非对称量化**：视觉保留高容量，运动意图更小以加速检索）。
- 引入**确定性线性锚定**（deterministic linear anchoring）保证码本稳定，防止随机初始化的码本直接输入 ODE 导致发散。

### 2.4 多模态条件流匹配（Conditional Flow Matching）

- 对每个模态，从高斯噪声到目标数据的概率路径通过线性插值构造，模型预测速度场 `v_θ(ψ_s, s, e_c)`，损失为向量场回归。
- 视觉用完整 DiT（50 NFEs），位姿/动作用 Pointwise AdaLN-Zero MLP（10 NFEs），满足高频实时控制要求。

### 2.5 离散潜在规划（DLP）

- **初始化**：以"无偏专家先验"（掩码未来状态）生成种子意图，加入平滑高斯噪声（时间维度 EMA 平滑）产生多样候选。
- **搜索**：迭代细化，每轮用 Top-K Gumbel-Max 离散化（限制在余弦最近的 K 个码内），温度随迭代退火。
- **评估**：候选在离散空间内用 **Kinematic-Perceptual Cost (KPC, Eq. 4)** 排序：

$$J_{KPC}(\tau) = C_{geo} + \sum_{t=1}^{T} \gamma^t \big(\lambda_{img} C_{img}^{(t)} + \lambda_{prior} C_{prior}^{(t)} + \lambda_{ent} C_{ent}^{(t)} + \lambda_{vq} C_{vq}^{(t)}\big)$$

其中：
- `C_geo`：到目标位姿的欧氏距离（唯一需解码的项，O(1) 计算）
- `C_img`：与视觉目标嵌入的 MSE（仅在目标可见时启用）
- `C_prior`：候选的负对数似然（NLL），衡量偏离人类安全示范的程度
- `C_ent`：预测视觉 token 分布的香农熵，度量对模糊/遮挡区域的不确定性
- `C_vq`：量化误差（余弦距离），检测 OOD 状态（如撞墙时的"流形拒绝"）

- 所有成本项除 `C_geo` 外均在潜在空间内计算，无需解码至像素。

### 2.6 执行（Flow-Matching Execution）

- 搜索收敛后，仅将最优轨迹的离散 token 通过 Flow Decoder 解码为连续位姿/动作。
- 使用**Action Chunking with Temporal Ensembling** 实现平滑闭环执行。

### 2.7 局部路径跟随（两种外部指引模式）

- **CFG（Classifier-Free Guidance）**：在潜空间对无条件和有条件的意图做线性外推 `z̃_g = z_∅ + ω(z_g - z_∅)`。快速但对长距离易产生流形偏离。
- **子目标采样（Sub-Goal Sampling）**：从专家先验+码本词汇构建候选集合，评估与全局路径的截断 Chamfer 距离，限制在流形内生成，更鲁棒但更慢。

## 6. 论文的主要结论与发现

1. **离散潜在规划（DLP）有效**：将搜索限制在有限离散流形上，Hydra 在物理平台上实现近实时规划，且成功率远超连续基线（无遮挡 10/10，遮挡 8/10，盲角 8/10，对比 VertiFormer 均为 0/10）。
2. **KPC 能在潜在空间检测碰撞**：C_vq（量化误差）和 C_ent（预测熵）在接近障碍物时同步上升，独立计算的两信号一致指向危险时刻，验证了"流形拒绝"作为免像素安全信号的有效性。
3. **Hydra 在生成质量上不输连续基线**：FVD 指标上超越 NWM/B（19.16 vs 22.11），显明早期融合＋离散瓶颈未牺牲视频预测的时间一致性。
4. **世界模型可兼作反应式策略**：在局部跟随中，Hydra 用稀疏路径点时仍匹配甚至优于用密集目标图像训练的 GNM/ViNT/NoMaD，尤其是室内走廊场景（100% 成功率，最短时间，零干预）。
5. **CFG 与 Sampling 互补**：CFG 短距离快，Sampling 长距离稳健——两种执行策略在算法层面解决了"快速 vs 流形安全"的权衡。

## 7. 优点

- **方法创新性**：将规划器内置于世界模型，从根本上绕过像素解码瓶颈。离散化不限于搜索树结构，而是**离散化表示本身**，所有操作（采样、不确定性、成本评估、修剪）均在离散潜空间完成，和 WorldPlanner（候选中每步仍解码像素）形成关键对比。
- **设计精致**：非对称 VQ 码本（图像 2048 vs 运动 64）兼顾生成保真度与检索延迟；KPC 将多个互补安全信号（专家先验、熵、量化误差）统一为可解释的 MPC 成本。
- **物理可行性**：在两种不同运动学平台（轮式/四足）上验证，且 >500× 效率提升满足边缘实时控制需求。
- **诚实与透明**：对失败模式（行人消失、长距离规划失败、盲目标 C_img 误导、流形偏离）均有专节讨论和定性分析，附录提供 RViz 可视化、码本几何分析等丰富细节。

## 8. 不足与局限

- **"流形拒绝"不可靠**：C_vq 无法区分"真正的物理障碍"与"视觉复杂的可通行纹理"（如树叶、草地产生接近障碍物的量化误差），同质障碍物（如平墙）可能被低估，存在误报与漏报。
- **动态智能体表示缺失**：在 SCAND 社交场景中，行人被量化后从预测帧中消失或平均到背景，使 Hydra 目前仅适用于静态世界导航，无法应对行人等动态参与者。
- **码本容量与延迟的硬权衡**：增大码本可提高泛化，但检索成本线性增长，直接威胁实时性，固定码本无法同时满足表达力和延迟——需要自适应/分层词汇表。
- **目标可见性限制**：C_img 项在目标不可见时严重误导规划（成功率从 80% 骤降至 20%），论文选择直接禁用而非提出更鲁棒的视觉目标跟踪方法，限制了多视角/反射场景下的适用性。
- **长距离规划性能差**：在长距离场景中规划模式仅 40% 成功率，迭代式搜索的延迟使机器人在关键分叉口反应不及时，全局规划能力尚未充分展现。
- **连续基线的天然劣势**：NWM 被限制只能在高算力工作站运行，且其规划需要 500 秒——基线未能在公平条件下展示其理论上限，这使"超越连续基线"的结论带有不对称色彩。
- **训练资源细节缺失**：论文完全未披露训练所需的 GPU 数量/型号/时长，降低了可复现性和算力评估的透明度。
