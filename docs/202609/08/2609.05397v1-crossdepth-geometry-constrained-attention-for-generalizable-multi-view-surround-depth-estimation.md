## 摘要
对周围环境进行可靠的3D理解是自动驾驶的核心要求。多视角环绕摄像头装置提供了广阔的场景覆盖，但空间上相邻的图像通常仅有极小的重叠。因此，大多数像素的深度必须从单目外观线索中推断。这些线索在不同图像中可能表现不同，因此深度估计模型可能对其产生不同的解读。我们针对跨图像不一致性的两个主要来源：相机内参的差异和每幅图像的有限感受野。我们通过将特征基于逐像素的相机感知射线嵌入来调节，从而解决前者，使网络能够考虑单目线索中依赖相机的变化。我们通过将每个像素的上下文扩展到其自身图像之外，利用约束在几何上合理区域的跨图像注意力来解决后者，该区域源自标定后的装置设置。模型以完全自监督的方式基于光度一致性进行训练。在DDAD和nuScenes上的评估显示，在域内和跨域评估中，与最先进的自监督方法相比，整体深度精度和跨图像深度一致性均有提升。代码可在 https://abualhanud.github.io/CrossDepthPage/ 获取。

## Abstract
Reliable 3D understanding of the surrounding environment is a core requirement for autonomous driving. Multi-view surround camera rigs provide broad scene coverage, but the spatially adjacent images typically overlap only minimally. Consequently, the depth of most pixels must be inferred from monocular appearance cues. These cues can appear differently across images and may therefore be interpreted differently by the depth estimation model. We target two main sources of cross-image inconsistency: differences in camera intrinsics and the limited receptive field of each image. We address the former by conditioning the features on per-pixel camera-aware ray embeddings, enabling the network to account for camera-dependent variations in monocular cues. We address the latter by extending each pixel's context beyond its own image through cross-image attention constrained to geometrically plausible regions, derived from the calibrated rig setup. The model is trained in a fully self-supervised manner based on photometric consistency. Evaluations on DDAD and nuScenes show improved overall depth accuracy and cross-image depth consistency over state-of-the-art self-supervised methods under in-domain and cross-domain evaluation. Code is available at https://abualhanud.github.io/CrossDepthPage/.

## 2. 方法论

### 总体框架
- 采用**编码器-解码器**架构：编码器为独立编码每张图像的 **Vision Transformer (ViT)**（基于预训练 DINOv3 ViT-S，权重共享）；解码器为 **DPT（Dense Prediction Transformer）** 结构的 CNN 头部。
- 对于目标帧 `It` 的 N 张图像，编码器提取多层级特征 `Ft,l`；解码器最终对每张图输出相应的度量深度图 `D̂t`。
- 训练完全**自监督**：目标图像由空间（相邻相机）、时间（相邻帧）及时空（不同相机+相邻帧）三种源视图，利用光度一致性损失来监督深度预测，并通过已知标定与相机位姿获得度量尺度。

### 关键技术一：跨图像特征聚合（Cross-Image Feature Aggregation）
- 核心思想是展开每个图像 token 的上下文，使其能利用其他相机图像中的几何与语义相关信息，但只允许在**几何合理区域**内进行注意力聚合，避免无约束注意力的歧义与计算浪费。
- **两次前向推理**：
  - 第一次前向不做跨图像注意力，得到初步（中间）深度估计；
  - 利用该深度将每个 token 反投影到 3D 空间，结合相机内外参确定其在其他图像中**期望对应点**附近的几何合理区域；
  - 第二次前向开启跨图像注意力，并严格限制在区域内。
- **共享圆柱网格（Shared Cylindrical Grid）**：
  - 将来自所有相机的 token 反投影到公共的**竖直圆柱面**上，以角坐标 θ 和高度坐标 h 表示。
  - 相邻相机间的重叠区域由此被映射到圆柱上相近的位置，实现了跨多幅图像的紧凑邻域检索。
  - 将圆柱离散为 `Bθ × Bh` 的二维网格，在此基础上直接通过局部 `KW × KW` 窗口进行候选 token 的检索，替代了原有 CylinderDepth 方法中的穷举逐对距离搜索，提升了效率并支持所有解码器特征尺度上的注意力操作。
- **跨图像注意力（相当于公式 2-3）**：
  - 每个查询 token 只与窗口内最多 M 个候选 token 进行缩放点积相似度计算，做 softmax 后得到加权和；
  - 注意力权重为**可学习**参数（而非固定几何权重）；
  - 查询/键/值来自同一组编码器特征（自注意力形式），但键/值 token 仅限于其他图像的候选，进一步降低计算量。

### 关键技术二：相机感知光线嵌入（Camera-Aware Ray Embedding）
- 针对内参差异问题，为每个像素（token）按其相机内参计算对应的**射线方向**，并利用 NeRF 中的**正弦位置编码**（Ldir = 11 个频带）生成嵌入；
- 在送入解码器的每个阶段，编码器特征与光线嵌入拼接并通过 `CAMFusion`（3×3 卷积）实现特征调制，形如 `F̃t = CAMFusion(Ft ∥ Rt)`；
- 该设计允许解码器学习“外表特征 - 相机内参 - 度量深度”之间**非线性的空间变化关系**（如不同焦距下，同一物体在图像上有不同大小，但预测的度量深度一致）。

### 自监督训练
- 光度误差采用 SSIM + L1 的常规形式（权重 α = 0.85）；
- 综合**空间、时间、时空**三种可视化的光度损失，外加：
  - 边缘感知深度平滑损失 Lsm
  - 稠密深度一致性损失 LDCCL
  - 多视角重建一致性损失 LMVRCL
- 总损失（相当于公式 11）：`L = Lphoto,temp + λsp Lphoto,sp + λspt Lphoto,spt + λsm Lsm + λDCCL LDCCL + λMVRCL LMVRCL`

## 6. 主要结论

- 在所有主要指标上，**CrossDepth 在域内和跨域评估中均优于现有自监督方法**，尤其显著地提升了跨图像深度一致性（Depth Cons）。
- 以 DDAD 域内为例（自述表 1）：Abs Rel 0.185（SOTA-lite方法为 0.201–0.218），Depth Cons 4.60 m（对比最佳为 5.68 m）。
- 相比 CylinderDepth，CrossDepth 的改进体现在：
  - 使用**可学习的注意力权重**并以初步深度做**几何约束**（而非固定权重与穷举搜索）；
  - 将跨图像注意力应用于所有进入解码器的特征层尺度的特征，而不仅仅在一个粗分辨率上；
  - 尽管计算结构更复杂，显存开销仍然保持在可比较水平（训练约 8.1 GB）。
- 消融验证了：
  - 无约束注意力会降低性能，几何约束注意力才能提升性能；
  - 邻域越大（KW 越大）不会带来收益，反而会降低一致性；
  - 光线嵌入方式优于简单的焦距缩放补偿方式；LOoRA 微调能带来小幅度稳定提升（DINO 预训练特征本身已经较强）。
- 局限也明确存在：跨图像注意力只作用于编码器特征而不在解码器中传播时，物体边界处仍可能出现局部深度伪影；论文未验证更大规模训练场景下的可扩展性。

## 7. 优点

- **问题定位明确**：清晰指出了环绕自监督深度估计中两个实质性不一致来源（内参差异与感受野限制），并从方法论上分别应对。
- **几何知识与学习的有效结合**：在投影几何约束的区域内进行**可学习**的跨图像注意力，既减少歧义，又保持模型表达能力，比 CylinderDepth 固定几何权重更合理。
- **效率设计务实**：
  - 将圆柱投影离散为二维网格，通过窗口检索直接获得候选token，完全避免了全局逐对距离计算；
  - 限制注意力只到其他图像，排除冗余的自己图像注意力，显著降计算量——该设计使跨图像注意力可以推广到所有特征层，提升了收益。
- **射线嵌入设计细腻**：以逐像素射线�的正弦位置编码而非一个全局焦距缩放因子来编码相机内参，更具表达能力，可学习非线性的内参-深度关系。
- **自监督策略完整**：有机结合空间、时间与时空三种光度监督，充分利用了环绕装置上有限的重叠视觉和测量刚体几何，无需真值深度标签。
- **评价体系较完整**：同时报告了全图和重叠区域的精度以及跨图深度一致性指标，相较许多工作侧重于单一区域，更贴合该任务的目标。
- 训练/推理显存开销与最优方法相当或更低，且不牺牲结构复杂度。

## 8. 不足与局限

- **解码器注意力缺失**：跨图像注意力未在解码器内应用，使边界区域的深度改进能力受限，作者承认物体边界附近仍可能出现局部深度伪影。
- **扩展性未验证**：未在显著更大的训练规模、更高分辨率或更多数据集上测试，跨数据集与真实场景的可扩展性证据不足。
- **跨域实验仅一对数据集**：仅使用 DDAD↔nuScenes（同为城市/高速公路驾驶配置）验证，针对更不相似领域的泛化性（如换到新大陆域、不同季节/地理环境）无证据；
