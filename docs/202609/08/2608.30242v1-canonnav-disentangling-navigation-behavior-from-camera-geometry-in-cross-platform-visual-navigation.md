## 摘要
尽管通过跨平台示范的模仿学习推动了视觉导航的发展，但充分利用此类数据仍然具有挑战性。首先，直接从图像-轨迹对中学习会将导航行为与平台相关的相机几何纠缠在一起。这迫使策略从视觉观察中隐式推断相机几何，而这是一个本质上不适定的问题，从而阻碍了学习的一致性。其次，从示范轨迹中进行模仿学习捕获了专家选择的运动，但使得该运动背后的中间决策变得隐式。为解决这些问题，我们提出了CanonNav，一种视觉导航框架，它将导航行为与相机几何解耦，并在跨平台示范学习中引入互补的规划监督。CanonNav引入了相机几何规范化，将视觉观察和轨迹转换为相机一致的表征空间。在此表征基础上，我们利用离线可穿越性估计器的伪标签推导出安全性和局部进度监督。安全性监督惩罚不安全的轨迹，而局部进度监督则引导机器人应前进的方向。在多种相机配置和环境中的实验表明，尽管推理时仅使用RGB，CanonNav始终优于基于RGB的基线，甚至在具有挑战性的场景中超越了基于RGB-D的方法。

## Abstract
While visual navigation has advanced through imitation learning from cross-platform demonstrations, fully leveraging such data remains challenging. First, directly learning from image-trajectory pairs entangles navigation behavior with platform-dependent camera geometry. This hinders consistent learning by forcing the policy to implicitly infer camera geometry from visual observations, an inherently ill-posed problem. Second, imitation learning from demonstrated trajectories captures the expert's chosen motion but leaves the intermediate decisions underlying that motion implicit. To address these issues, we propose CanonNav, a visual navigation framework that disentangles navigation behavior from camera geometry and incorporates complementary planning supervision into learning from cross-platform demonstrations. CanonNav introduces camera geometry canonicalization, which transforms visual observations and trajectories into a camera-consistent representation space. Building on this representation, we derive safety and local-progress supervision using pseudo-labels from an offline traversability estimator. Safety supervision penalizes unsafe trajectories, while local-progress supervision guides where the robot should advance. Experiments across diverse camera configurations and environments show that, despite using only RGB at inference, CanonNav consistently outperforms RGB-based baselines and even surpasses RGB-D-based methods in challenging scenarios.

- **核心问题一：导航行为与相机几何的纠缠**：
  - 直接利用来自不同平台的数据进行模仿学习，会将导航行为与平台特有的相机几何（camera geometry）耦合在一起。
  - 策略网络被迫从视觉观测中隐式推断相机的几何属性，但这是一个**本质上的不适定问题（ill-posed problem）**，因为单一RGB图像无法唯一确定其对应的相机参数。这导致跨平台学习时行为不一致，性能下降。
- **核心问题二：中间决策的缺失**：
  - 经典的模仿学习（如行为克隆）只记录了专家的最终运动指令（如线速度、角速度），但并未显式提供该运动背后的**中间决策依据**——例如“前方是否安全？”、“是否应该前进？”、“应该朝哪个方向推进？”等。
  - 这使得策略需要从有限的监督信号中自行推测这些隐式决策，增加了学习的模糊性和样本复杂度。
- **整体含义**：CanonNav旨在解决这两个根本性挑战，提出一种跨平台视觉导航框架，在**不依赖深度传感器**的情况下，通过解耦导航行为与相机几何、并引入互补的规划监督信号，提高多平台模仿学习的泛化性与鲁棒性。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **总体框架**：CanonNav由三个主要模块构成：相机几何规范化（Camera Geometry Canonicalization）、离线可穿越性伪标签生成（Offline Traversability Pseudo-labeling）、以及联合训练范式（Joint Training with Complementary Supervision）。
- **模块一：相机几何规范化（Core Idea: 解耦）**
  - **核心思想**：将不同相机配置下的视觉观测和机器人轨迹统一映射到一个**相机一致的规范空间（camera-consistent canonical space）**中，从而消除平台依赖的几何偏差。
  - **视觉观测规范化**：利用已知的相机内参（在离线数据采集时已知），对原始图像进行重投影或变换，生成视角统一的“规范图像”表征，该表征不依赖于特定相机的FOV或畸变特性。
  - **轨迹规范化**：将专家轨迹从机器人本体坐标系转换到与规范相机坐标系对齐的动作空间或特征空间，确保相同的视觉输入对应的行为预测目标是一致的。
  - **效果**：策略不再需要隐式猜测相机参数，而是在统一空间中学习导航行为，实现“行为与几何解耦”。
- **模块二：互补规划监督（Core Idea: 补充中间决策）**
  - **利用预训练的离线可穿越性估计器（offline traversability estimator）**，仅基于RGB图像或规范表征，生成稠密的可穿越性图（traversability map）。
  - 基于可穿越性图，推导出两类互补监督信号：
    - **安全性监督（Safety Supervision）**：计算轨迹上的点在空间上是否与不可穿越区域重叠，如果当前专家轨迹经过不安全区域则进行惩罚，以约束策略避免碰撞风险。
    - **局部进展监督（Local-progress Supervision）**：根据可穿越性图中指向目标或开阔区域的梯度方向，计算策略应采用的最优前进方向（headings），作为“局部进展标签”，引导机器人朝安全且有进展的方向移动。
  - 这些伪标签在**离线阶段**生成，在训练时作为辅助监督信号，与行为克隆损失联合优化。
- **训练流程**：
  1. 收集跨平台RGB图像和轨迹数据；
  2. 离线阶段：利用已知相机参数进行几何规范化；利用可穿越性模型为每帧生成安全性和局部进展伪标签；
  3. 在线训练：Policy网络接收规范化后的RGB观测，输出导航动作，联合优化行为克隆损失 + 安全性损失 + 局部进展损失；
  4. 推理阶段：仅使用RGB输入，不需要深度传感器或相机参数（即推理时对相机几何具备不变性）。
