## 摘要
具身导航要求智能体在任务、环境和机器人形态之间，将异构目标与视觉观察转化为行动。现代视觉语言模型（VLM）已经编码了用于视觉基础、空间推理和指向的空间先验，但这些能力很少被直接激发用于机器人控制。现有的导航系统反而依赖特定任务或特定形态的组件，将感知、推理和行动割裂开来，同时只能提供有限的泛化能力。在此，我们提出LightNav-0，一种紧凑的通用具身导航模型，它激发预训练VLM的空间智能并将其与导航对齐，且无需任务特定的预测头。LightNav-0通过统一的token接口来表示不同的导航任务：双通道指向表达了与任务、场景和形态无关的空间意图，而残差向量量化动作分词器将该意图映射为精确的、特定形态的轨迹。结合时间感知的视觉历史压缩、ER中间训练、监督微调和强化学习，该公式支持在单一模型中进行指令跟随、开放词汇目标导航和视觉跟踪。该导航训练语料库涵盖2K+场景和4K+小时的具身导航数据。用于初始化LightNav-0的具身推理检查点LightNav-ER在8个具身推理基准上取得了最高的完整集平均值，而LightNav-0在所有10个公共导航模拟设置中取得了最先进的单目成功率。真实世界评估进一步证明了跨机器人形态、多样场景以及静态和动态目标的零样本泛化能力。这些结果确立了紧凑型VLM作为通用具身导航的统一且可迁移的骨干网络。

## Abstract
Embodied navigation requires agents to translate heterogeneous goals and visual observations into actions across tasks, environments, and robot embodiments. Modern vision-language models (VLMs) already encode spatial priors for visual grounding, spatial reasoning, and pointing, but these capabilities are rarely elicited directly for robot control. Existing navigation systems instead rely on task- or embodiment-specific components, fragmenting perception, reasoning, and action while offering limited generalization. Here we present LightNav-0, a compact generalist embodied navigation model that elicits the spatial intelligence of a pretrained VLM and aligns it with navigation, without task-specific prediction heads. LightNav-0 represents diverse navigation tasks through a unified token interface: dual-channel pointing expresses task-, scene-, and embodiment-agnostic spatial intent, while a residual vector-quantized action tokenizer maps this intent to precise, embodiment-specific trajectories. Together with temporally aware visual history compression, ER mid-training, supervised fine-tuning, and reinforcement learning, this formulation supports instruction following, open-vocabulary object navigation, and visual tracking within a single model. The navigation training corpus spans 2K+ scenes and 4K+ hours of embodied navigation data. LightNav-ER, the embodied-reasoning checkpoint used to initialize LightNav-0, attains the highest complete-set average across 8 embodied-reasoning benchmarks, while LightNav-0 achieves state-of-the-art monocular success rates across all 10 public navigation simulation settings. Real-world evaluations further demonstrate zero-shot generalization across robot embodiments, diverse scenes, and static and dynamic targets. These results establish compact VLMs as a unified and transferable backbone for generalist embodied navigation.

## 1. 核心问题与研究动机

- **研究背景**：具身导航要求智能体在多元任务、多样环境与不同机器人形态之间将异构目标与视觉观察映射为动作，即“感知—推理—行动”的闭环。现代 VLM 已具备视觉基础、空间推理与指向等空间先验，但这些先验能力很少被直接用于机器人控制。
- **核心问题**：现有导航系统普遍依赖**任务特定或形态特定的组件**（如专属预测头、SLAM、语义地图、规则策略），导致感知、推理与行动相割裂，泛化能力有限，跨任务、跨场景、跨形态的统一导航难以实现。
- **整体意义与研究目标**：LightNav-0 探索能否用单个紧凑型 VLM 作为通用具身导航的**统一可迁移骨干网络**，通过统一 token 接口将预训练模型的空间智能直接对齐到导航动作，同时支持指令跟随、开放词汇目标导航与视觉追踪，而无需任务特定的预测头。

## 2. 方法论

论文的核心思路是：**不改变 VLM 的空间推理能力，而是通过统一的输入/输出 token 接口将“空间意图”与“具身轨迹”衔接**。主要技术设计包括：

- **双通道指向（Dual-Channel Pointing）**
  - 导航任务的最终目的可以抽象为“指向某类目标/某位置意图”。
  - 双通道指向用来表达“任务无关、场景无关、形态无关”的空间意图，使异构任务能统一为同一种指令格式，然后可转化为 VLM 可理解的 token 序列。

- **残差向量量化动作分词器（Residual Vector-Quantized Action Tokenizer）**
  - 单一用于对齐 VLM 推理与动作输出的“动作语言”。
  - 将粗粒度空间意图映射为精确的**形态特定轨迹**。
  - 采用残差向量量化对动作空间进行离散化，从而绕开任务特定预测头，让模型输出动作 token 而不是加入新解码器组件。

- **时间感知的视觉历史压缩（Temporally Aware Visual History Compression）**
  - 处理导航中的视觉时序问题，把历史观测帧压缩为时间感知的视觉上下文，缓解长时序策略的输入负担。

- **训练管线**（分四阶段完成从通用 VLM 到具身导航模型的演进）：
  1. **具身推理中间训练（ER Mid-training）**：产出 LightNav-ER 检查点，将 VLM 预训练空间智能进一步引向具身空间推理；
  2. **监督微调（SFT）**：对齐统一接口（双通道指向 + 动作分词器）并适配导航动作；
  3. **强化学习（RL）**：对整条轨迹进行奖励优化，提升真实决策质量；
  4. 最终形成 LightNav-0。整个流程强调了“**感知—推理—动作对齐**”，利用统一 token 接口避免原有系统在感知模块、推理模块与动作模块之间的割裂。

- **训练语料**：涵盖 **2K+ 场景、4K+ 小时**的具身导航数据。

- 值得一提的是，该公式不依赖复杂的视觉语言动作（VLA）生成机制，而是先通过指针表达语义意图，再通过分词器解码轨迹，因而具备形态无关的泛化潜力。

## 7. 优点与亮点

- **用统一接口替换任务特定头**：双通道指向 + RVQ 动作分词器的组合很有新意，使任务表示与形态轨迹解耦，统一了异构目标与动作，是“通才导航”设计上的重要一步。
- **“重利用 VLM 空间先验”理念**：不重训视觉基础，而是将 VLM 已有空间智能激发并约束到导航意图传递上，体现了对模型知识的高效利用。
- **四段式训练链条（ER 中间训练→SFT→RL）** 层次分明，RL 阶段让模型在离散轨迹上直接优化导航奖励，和传统分层导航模型相比更连贯。
