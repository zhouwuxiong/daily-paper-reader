## 摘要
自主无人机（UAV）越来越多地在杂乱环境中运行，而RRT*等全局规划器无法直接以控制频率部署。本文通过将动态窗口法扩展到六自由度（6D-DWA），提出了一种用于全向多旋翼（omnicopter）的实时局部规划与避障模块。我们的方法通过以下方式实现实时可行性：(i) 局部地图体素化；(ii) 基于球体的紧凑飞行器几何近似；以及 (iii) 在6D搜索空间中的自适应速度采样。为了提高对未知障碍物的响应能力，我们引入了一种上下文感知的“敏捷模式”，该模式在线调整评分权重，以在规避机动过程中权衡目标进度、安全距离以及航向/朝向约束。我们在仿真中评估了我们的方法，包括计算压力测试、密集航点路径跟踪以及静态/未知障碍物场景。我们的规划器始终在0.2秒控制周期内运行，跟踪航点密集的全局路径，平均横向误差小于0.1米，平均航向误差13度，并在静态环境中避免碰撞。对于未知障碍物规避，敏捷模式对偏心障碍物达到79.3%的成功率，对中心障碍物达到41.4%的成功率，这既突出了自适应加权的有效性，也突显了在高度受限几何形状中仍然存在的局限性。

## Abstract
Autonomous unmanned aerial vehicles (UAVs) increasingly operate in cluttered environments where global planners such as RRT* are not directly deployable at control rates. This paper presents a real-time local planning and obstacle avoidance module for an omnidirectional multirotor (omnicopter) by extending the Dynamic Window Approach to six degrees of freedom (6D-DWA). Our method achieves real-time feasibility through (i) local-map voxelisation, (ii) a compact sphere-based approximation of the vehicle geometry, and (iii) adaptive velocity sampling in the 6D search space. To improve reactivity to unknown obstacles, we introduce a context-aware "Agile Mode" that adjusts scoring weights online to trade-off between goal progress, clearance, and heading/facing constraints during evasive manoeuvres. We evaluate our approach in simulation across computational stress tests, dense-waypoint path tracking, and static/unknown obstacle scenarios. Our planner runs consistently within a 0.2s control loop, tracks waypoint-dense global paths with < 0.1m average cross-track error and 13deg average heading error, and avoids collisions in static environments. For unknown obstacle avoidance, Agile Mode achieves 79.3% success for an off-centre obstacle and 41.4% for a centred obstacle, highlighting both the effectiveness of adaptive weighting and remaining limitations in highly constrained geometries.

## 1. 核心问题与研究背景

- 论文关注的是**自主无人机在杂乱环境中的实时导航问题**。传统全局路径规划器（如 RRT*）虽然能生成无碰撞路径，但其计算复杂度高，无法直接以控制频率运行，因此难以应对控制回路中的突发情况。
- 全向多旋翼（omnicopter）平台具有解耦的 6 自由度平移/旋转控制能力，执行器冗余更多、机动性更强，但其规划决策空间也从平面 3D 扩展到 6D（3D 线速度 + 3D 角速度），搜索空间呈指数级增长，对规划器的实时性构成重大挑战。
- 仅依赖全局路径跟踪而不考虑反应式避障会导致无人机与**未建图障碍物、动态障碍物**甚至**墙壁气动吸力效应**发生碰撞。
- 因此，本文的核心目标是设计一个**实时可行、带碰撞感知的局部规划器**，作为全局路径与底层飞行控制之间的桥梁，兼顾路径跟踪精度、静态避障与未知障碍物下的机动灵活性。

## 2. 方法论：6D-DWA 局部规划框架

### 核心思想

- 在经典动态窗口法（Dynamic Window Approach, DWA）基础上，将速度采样空间从 2D 平面扩展到 6D 全维度（$V_x, V_y, V_z, \omega_x, \omega_y, \omega_z$）。
- 每次规划周期内，仅采样**动态窗口**（即从一个控制步长 Δt 内从当前状态物理可达的速度集合）中的候选指令，并向前仿真短时间轨迹。
- 对候选轨迹进行碰撞检查和加权评分，选择得分最优的速度指令执行。

### 关键技术细节

1. **6D 速度采样与自适应采样策略**
   - 由于均匀采样在 6D 空间中效率极低，将采样分为三部分：
     - **探索采样（Exploration ratio, $e_r$）**：覆盖整个搜索空间，保证无偏搜索；
     - **聚焦搜索（Focused-Search ratio, $f_r$）**：围绕上周期最优速度，以标准差 σ 进行高斯聚焦采样；
     - **边界搜索（Boundary-Search ratio, $b_r$）**：探索动态窗口边界，避免遗漏极限可行速度。
   - 三部分比例满足 $e_r + f_r + b_r = 1.0$，通过调整采样分布大幅提升采样效率。

2. **静态碰撞检测**
   - 飞行器几何用 **10 个球体**近似（覆盖机体主体结构），每个球体半径外加安全膨胀量 $r_{inf}$，以容纳跟踪误差；
   - 静态环境从 STL 网格开始，经过递归细分三角面片 → 生成点云 → **体素化（voxelisation）**，得到占用体素集合 $O_{obs}$；
   - 模拟轨迹由 S 个位置序列构成，对任一时刻任一球心位置 $p_{j,i}$，若到最近障碍体素距离小于 $r_{inf}$，路径即被判定为碰撞无效（公式 1）；
   - 使用 PCL 的 KD-Tree 做近邻查询，保证实时性。

3. **未知障碍物感知**
   - 深度相机点云在感兴趣范围内被体素化，作为“未知障碍集合”$O_u$ 动态加入系统；
   - 用于触发敏捷模式以及计算敏捷模式下的避障代价。

4. **轨迹评分函数**
   - 加权代价函数为：

     $J = w_{goal}C_{goal} + w_{path}C_{path} + w_{head}C_{head} + w_{look}C_{look} + w_{clear}C_{clear} + w_{face}C_{face}$

   - $C_{goal}$：末端位置与局部目标间距（欧氏距离）；
   - $C_{path}$：模拟位置与全局路径最小垂直距离（横向偏差）；
   - $C_{head}$：末端姿态与局部目标姿态四元数的夹角误差；
   - $C_{look}$：机载前视相机方向与路径前视方向的对齐误差；
   - $C_{clear}$：对未知障碍物的距离倒数平方和（势场启发式，低于阈值半径才触发）；
   - $C_{face}$：相机朝向与最近未知障碍方向的对齐误差。

5. **敏捷模式（Agile Mode）**
   - 当局部地图中出现未知障碍物（$|O_u|>0$），控制器由“标准模式”切换为“敏捷模式”，将 $w_{clear}$、$w_{face}$ 从 0 切换到非零值并将路径权重置 0；
   - 目的：在障碍物附近允许**更大的全局路径偏离**，优先保证安全余量；
   - 当障碍物视线消失后恢复标准模式继续路径跟踪。

6. **高速动态障碍物躲避模块**
   - 对 6D-DWA 无法快速响应的威胁，单独构建高速防线：
     - 接收障碍物位置/速度消息；
     - 计算最近接近点时间 $t_{cpa}$ 与最小距离 $d_{miss}$；
     - 当最小距离低于阈值，生成与相对运动平面正交的候选速度方向集合，旋转后逐条做静态碰撞检测；
     - 选择第一条无碰撞候选轨迹执行；躲避完成后切换回 6D-DWA 模式。

## 6. 主要结论与发现

1. **实时性**：6D-DWA 在 CPU 平台上能稳定在 0.2s（5Hz）控制周期内完成一次重规划，满足目标速率；
2. **跟踪精度**：在密集航点路径跟踪中，平均横向误差低于 0.1m，平均航向误差约 13°，平均“前视”误差约 10°；
3. **自适应采样有效性**：相同样本数下显著优于随机采样；配置 $e_r=0.5$ 时能达到接近 5000 随机采样的性能水平，可大幅降低计算量；
4. **静态避障可靠性**：能正确拒绝穿过障碍物的轨迹、绕行并重新汇合路径，还能穿越狭窄但存在姿态错位的间隙；
5. **权重敏感性**：路径跟踪中的 whead（航向权重）过高会限制 90° 窄口的几何可行性，下调后可以成功穿越；说明权重直接决定 6D 空间中的可行几何解集；
6. **敏捷模式（未知障碍）**：
   - 偏心障碍最佳成功率 79.3%（配置 $w_{clear}=1$ + $w_{head}=0$）；
   - 居中障碍最佳成功率仅为 41.4%；
   - 过高 $w_{clear}$ 抑制前进进度引起“人工停顿/超时”，在对称障碍场景下陷入局部最小值；
   - $w_{face}$ 对成功率影响不显著，但过高会延迟回切标准模式；
7. **动态威胁**：快速躲避模块在静态障碍约束下能选出可行方向，完成任务后恢复路径跟踪，状态机优先级正确。

## 7. 优点

- **创新性**：将平面 DWA 创新性地扩展为 6D-DWA，匹配全向飞行器的 6D 决策空间，是该问题域的有价值填补；
- **工程可行性**：

  - **传感器噪声与延迟缺失**：仿真中的深度相机点云与障碍物消息均为理想化输出，而真实视觉测距在光照变化、运动模糊、反光表面等条件下会产生噪点、空洞与时延；这些都会直接扰动 $O_u$ 的触发时机和碰撞检测阈值判定，论文未对此进行鲁棒性测试。
  - **动力学与执行器不确定性**：全向多旋翼的真实推力响应、螺旋桨延迟、伺服过冲等物理因素会对 6D-DWA 的动态窗口可达性假设产生影响；仿真中的“可达速度集”与实际电机响应存在差距，且论文未建立动态窗口与真实加速度限制之间的量化校验。
  - **缺乏风扰与环境气动效应**：前文明确提及墙壁气动吸力是问题动机之一，但实验中始终未模拟气流场或近壁效应，导致这一核心动机没有在验证闭环中被检验。

- **对比实验实质性缺失**：全论文未与任何其他规划方法（如 3D 空间下的标准 DWA、RRT* 局部重规划、MPC 避障或势场法变体）进行横向对照。

  - “优于随机采样”只证明了相对朴素基线的高效性，无法定位该方法在现有局部规划器谱系中的真实坐标；
  - 没有对照实验就无法支撑“6D 全维采样优于降维近似”这一隐式论断——因为 6D 采样即便有自适应策略，在轨迹生成阶段的成本仍线性随样本数增长，读者无从判断其在精度/算力曲线上是否真的胜过先验降维方法。

- **公式与算法机制可复现性不足**：

  - 自适应采样中三部分比例（$e_r$、$f_r$、$b_r$）与标准差 $\sigma$ 的取值虽有实验探索，但缺少理论上的动态调节规律，是否依赖人工调参来决定采样分配尚不明确；
  - 敏捷模式中“未知障碍集合 $O_u$ 非空即触发”的二元切换规则在障碍物位于远处或稀疏时可能过于敏感，论文对阈值空间没有给出消融测试；
  - 轨迹评分中 $C_{goal}$ 与 $C_{path}$ 的归一化方式、各权重的量纲一致性描述不完整，难以被第三方程完成端到端复现。

- **成功率实验统计细节不足**：

  - 敏捷模式实验给出了百分比（如 79.3%、41.4%），但未披露试验次数是否足够、是否覆盖多起点多姿态的初始分布；
  - 没有给出方差/置信区间或随机种子说明，那些相近配置之间的性能差异很可能落在统计噪声范围之内。

- **场景在复杂性与逼真度上偏简单**：

  - 静态场景主要为几何规则墙体与单个障碍物，未知障碍为偏心/居中的单一实体，缺少真实室内常见的杂乱家具堆叠、多障碍密集排列、镜面/玻璃结构等对抗性测试；
  - 动态威胁由人工消息注入而非跟踪模块实时提供，未验证相机跟踪误检/漏检时的状态机稳定性；
  - 全文导航任务为单个局部规划器驱动的路径跟踪，没有多障碍连续出现的整段贯通实验（即全局路径、敏捷模式和动态躲避在同一长任务中叠加考验）。

## 9. 总结评价

整体而言，这篇论文的定位是**工程驱动的方法设计与模块集成**：其贡献重心不在理论推导或新范式提出，而在于把一个经典平面规划思想严谨地推广到 6D 全姿态空间，并以“标准模式 / 敏捷模式 / 快速躲避”三个机制的分层协作解决真实飞行中的典型冲突。章节结构清晰，实验拆解逻辑完整，变量控制意识较强，作为一项面向全向无人机避障的可行性验证工作具有较好的参考价值；但其支撑证据目前停留在**单机、静态、仿真的受控环境**层面，距离支撑论文“实用化”的主张尚有差距。

最关键的后续工作是补足真机实验，尤其是利用全向飞行器独有的**解耦平移与旋转**能力，在窄缝穿越、偏心障碍急转和动态突袭源三个代表性工况下对比仿真结论；其次是对敏捷模式的判定阈值、采样分布参数和权重切换时序做更系统的敏感性分析，并引入 3D-DWA 与 MPC 等基线方法进行同条件对照。若能在这两点上补强，该框架在 6D 运动规划文献中的说服力会有显著提升。
