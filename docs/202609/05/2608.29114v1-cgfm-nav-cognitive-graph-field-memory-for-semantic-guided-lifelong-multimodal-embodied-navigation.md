## 摘要
视觉-语言导航（VLN）要求智能体在持续探索未知区域的同时，对累积的观测进行推理。然而，现有的环境表示往往难以同时支持显式语义记忆和连续探索引导。为应对这一挑战，我们提出了认知图-场记忆（CGFM），一种将显式关系记忆与连续空间直觉耦合的持久化多模态场景表示。CGFM 将物体、空间关系和视觉观测组织成多模态场景图，支持跨导航任务的目标检索和长时程推理。当无法识别到可靠的目标匹配时，基于图的证据会被投射到目标条件下的语义前沿场中，以引导探索朝向语义上有希望的前沿和区域。基于 CGFM，我们引入了 CGFM-Nav，一个用于终身多模态导航的基础模型框架，它将任务相关子图选择、VLM 推理和验证反馈整合到一个闭环决策回路中。在 GOAT-Bench 上的初步实验表明，在相同的 Qwen3-VL-8B 主干下，CGFM-Nav 将整体成功率从 53.2% 提升至 63.0%，SPL 从 30.0% 提升至 39.6%，证明了将显式语义记忆与语义引导探索相结合的有效性。

## Abstract
Vision-and-Language Navigation (VLN) requires agents to reason over accumulated observations while continuously exploring unseen regions. However, existing environment representations often struggle to jointly support explicit semantic memory and continuous exploration guidance. To address this challenge, we propose Cognitive Graph-Field Memory (CGFM), a persistent multimodal scene representation that couples explicit relational memory with continuous spatial intuition. CGFM organizes objects, spatial relations, and visual observations into a multimodal scene graph, enabling target retrieval and long-horizon reasoning across navigation tasks. When no reliable target match is identified, graph-based evidence is projected into a goal-conditioned semantic-frontier field to guide exploration toward semantically promising frontiers and regions. Building upon CGFM, we introduce CGFM-Nav, a foundation-model-based framework for lifelong multimodal navigation that integrates task-relevant subgraph selection, VLM reasoning, and verification feedback into a closed decision loop. Preliminary experiments on GOAT-Bench show that, under the same Qwen3-VL-8B backbone, CGFM-Nav improves the overall success rate from 53.2% to 63.0% and SPL from 30.0% to 39.6%, demonstrating the effectiveness of combining explicit semantic memory with semantic-guided exploration.

## 1. 核心问题与整体含义（研究动机和背景）

- **任务背景**：视觉-语言导航（VLN）要求智能体在持续探索未知环境的基础上，根据多模态目标（如物体类别、自然语言描述、参考图像）进行推理与导航。这类任务在辅助机器人、自主物流、工业巡检和灾害响应等领域有广泛应用。
- **现有方法的两类局限**：
  - **基于2D语义地图/前沿的方法**：高效、易部署，支持在线探索和目标搜索，但缺乏显式对象关系建模与长期记忆。
  - **基于场景图/记忆图的方法**：能组织对象及其关系，支持目标检索和关系推理，但表示离散，无法直接给出连续空间中的探索引导。
  - 因此，现有表示难以同时兼顾**高效探索**、**结构化记忆**和**几何一致性**。
- **核心挑战**：当环境未知且目标可能未被直接观测到时，机器人既需要记住已观测对象的显式位置与关系（显式记忆），又需要对未知区域产生“去哪里找”的语义倾向（隐式空间直觉）。已有工作通常只侧重其中一种。
- **本文提出的整体思路**：受人类导航中“显式记忆”与“隐式直觉”互补机制的启发，提出**CGFM（Cognitive Graph-Field Memory）**，将结构化场景图与连续语义前沿场耦合到同一认知表示中，并据此构建无需策略训练的终身多模态导航框架 **CGFM-Nav**。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想
- 使用**多模态场景图**作为“显式关系记忆”：存储物体的类别、空间位置、视觉-语义特征、观测图像以及物体间的关系。
- 当目标在图中存在可靠匹配时，智能体直接检索并导航至该目标，类似人类的“有意回忆”。
- 当图中没有可靠匹配时，将图证据投影到连续空间中，生成**目标条件语义前沿场**，为探索提供“空间直觉”引导。
- 图与场不是独立模块，而是互为依据：图提供语义知识支撑场推断，场引导探索从而扩展图，形成闭环。

### 2.2 关键技术细节

#### （1）感知与多模态场景图构建
- 使用 YOLOv8-World + SAM 进行开放词汇检测与分割，用 CLIP 提取视觉语义特征。
- 场景图节点存储：类别、3D位置、视觉语义特征、累积观测图像；边编码物体间的空间/语义关系。
- 每个节点增加目标条件验证统计：包括验证计数、对应子任务目标、最终结果、多视角反馈。
- 被拒绝的节点**不删除**，而在当前子任务内抑制其对语义场的贡献，保留视觉证据但防止重复吸引智能体。

#### （2）语义前沿场构建
- 对每个图节点计算目标相关分数 \(s_i(q)\)：基于该节点CLIP特征与目标的相似度，并减去背景基线，确保只有有意义的物体成为语义源。
- 使用“验证掩码”门控：被当前目标最终拒绝的节点贡献置零，不确定节点不抑制。
- 将每个有效节点视为点源，在可通行区域上按测地距离指数衰减扩散，得到每个栅格场值：
  \[
  \mathcal{S}_t(x \mid q) = \sum_{i \in \text{TopK}_{K_s}(x)} s_i(q) w_i(x)
  \]
  其中 \(w_i(x)\) 为随测地距离衰减的权重，聚合局部贡献最大的 \(K_s\) 个物体。
- 语义地图与场景图保持同步，仅在被改变对象附近局部更新，避免全局重算。
- 并行提取前沿候选 \(\mathcal{C}_t=\{f_1,\dots,f_M\}\)，每个前沿得分 \(\mathcal{U}_t(f\mid q)\) 由其邻域内的平均场值减去测地距离惩罚获得；若最大得分低于阈值则回退到最近前沿。

#### （3）CGFM-Nav 闭环框架
- **语义引导的子图选择**：复用字段构造时计算的语义相关分数，保留正相关节点及其一跳邻居作为语义种子集合 \(V_{\text{seed}}\)，其余节点压缩为残差图，再由 VLM 基于常识关系进行补充选择：
  \[
  V_{\text{key}} = V_{\text{seed}} \cup \text{VLMSelect}(\hat{G}_{\text{res}}, q)
  \]
  最后经边剪枝和图像分配形成关键子图。
- **VLM 推理与决策记忆**：关键子图 + 短期决策日志 \(D_t\) 输入给 VLM，输出目标物体节点、目标观测图像、或“继续探索”请求：
  \[
  d_t = \text{VLM}(q, \tilde{G}_t, D_t)
  \]
- **动作选择**：
  - 物体目标：使用节点存储的位置作为目的地；
  - 图像目标：重新检测并定位对应物体；
  - 探索请求：优先选择语义前沿中得分最高的前沿；若无前沿但有语义峰值，则前往语义场响应最高区域的质心；两者皆无则子任务失败。
- **验证与闭环更新**：到达候选目标后，VLM 从多个视角验证，返回 YES / NO-UNCERTAIN / NO-CONFIRMED；结果写入决策记忆和对应图节点，被拒绝对象在后续场构建中被抑制；探索动作不触发验证，只更新图。

## 6. 主要结论与发现

- 在相同 Qwen3-VL-8B 主干下，CGFM-Nav 将整体 SR 从 53.2% 提升到 63.0%，SPL 从 30.0% 提升到 39.6%。
- 在类别目标和语言目标上提升尤为显著，说明图-场耦合表示能更好复用历史观测并引导语义探索。
- CGFM-Nav（Qwen3-VL-8B）在整体、类别及语言目标上甚至超越了 MSGNav（GPT-4o），表明**更强的环境表示可以部分补偿 VLM 骨干的能力差距**，有利于端侧轻量部署。
- 在图像目标上，CGFM-Nav 虽优于同骨干的 MSGNav（SR 46.6%→53.4%，SPL 28.1%→34.8%），但仍低于 MSGNav+GPT-4o（SR 59.1% / SPL 42.6%）。这说明图像目标更依赖细粒度视觉对应，仅改进语义探索仍不够，未来需要更强视觉表示或导航专用 VLM。

## 7. 优点

- **认知启发的统一表示**：将显式结构化记忆与隐式连续探索直觉结合，逻辑清晰且具备神经科学/心理学依据。
- **工程闭环设计成熟**：图、场、决策记忆、验证反馈之间形成完整的“感知–检索–推理–行动–学习”闭环，支持终身持续更新。
- **不依赖训练**：训练-free 架构天然具备开放世界泛化能力，且可适配不同开源 VLM 骨干。
- **局部更新机制**：语义地图随场景图变化局部更新，节省计算成本。
- **对拒绝候选的保留与抑制策略**：不丢失视觉证据，同时避免重复探索，提高了长期记忆利用率。
- **实验结果具有启发性**：在轻量模型上超越重模型的表现，展示了表示学习在弥补推理模型差距中的潜力。

## 8. 不足与局限

- **实验覆盖不充分**：只在一个 benchmark 的部分划分上做 36 个 episodes 的初测，缺少全量 benchmark、多个场景类型和长期任务（如多 episode 连续导航）的分析。

- **图像目标导航仍是短板**：低于 GPT-4o 驱动的 MSGNav，说明方法论对视觉细节匹配任务的支撑不够。
- **资源开销未评估**：训练-free 但仍依赖多个大模型（检测/分割/CLIP/VLM），推理延迟、内存占用、端侧部署可行性均未讨论。

- **缺乏多样性与动态环境**：未涉及时变场景、动态障碍或人类交互，长期记忆的稳定性与更新正确性还没有充分压力测试。
