## 摘要
前馈3D高斯泼溅（3DGS）能够实现高效且可泛化的3D重建，但目前用于场景理解的前馈3DGS方法在很大程度上仍是面向类别的。相比之下，实例感知的3DGS方法通常依赖于逐场景优化，并且常常将重建与实例和语义学习解耦，限制了它们之间的相互交互。我们提出了InstanceSplat，一个统一的前馈3DGS框架，可从无位姿多视图图像进行可泛化的3D重建和实例感知场景理解。在单次前向传播中，InstanceSplat构建一种实例感知的高斯表示，联合编码外观、几何、实例身份和语言对齐的语义。共享的3D高斯跨视图锚定实例身份，生成可渲染且跨视图一致的实例特征。为了使重建和场景理解相互受益，我们进一步设计了一种以实例为中心的学习策略，通过共享的实例结构将重建、实例学习和语义学习连接起来。具体来说，实例线索指导重建，语言对齐的语义增强对混淆的同类实例的判别，实例区域将语义证据聚合成连贯的物体级预测。在不同输入视图设置和未见数据集上的新视图合成、实例分割和开放词汇语义理解实验表明，该方法具有最先进的性能、实际效率和强大的泛化能力。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) enables efficient and generalizable 3D reconstruction, but current feed-forward 3DGS methods for scene understanding remain largely category-oriented. In contrast, instance-aware 3DGS methods typically rely on per-scene optimization and often decouple reconstruction from instance and semantic learning, limiting reciprocal interactions among them. We present InstanceSplat, a unified feed-forward 3DGS framework for generalizable 3D reconstruction and instance-aware scene understanding from pose-free multi-view images. In a single forward pass, InstanceSplat constructs an instance-aware Gaussian representation that jointly encodes appearance, geometry, instance identity, and language-aligned semantics. Shared 3D Gaussians ground instance identities across views, producing renderable and cross-view-consistent instance features. To allow reconstruction and scene understanding to benefit from each other, we further design an instance-centric learning strategy that connects reconstruction, instance learning, and semantic learning through shared instance structure. Specifically, instance cues guide reconstruction, language-aligned semantics strengthen the discrimination of confusing same-category instances, and instance regions aggregate semantic evidence into coherent object-level predictions. Experiments on novel-view synthesis, instance segmentation, and open-vocabulary semantic understanding under varying input-view settings and on an unseen dataset demonstrate state-of-the-art performance, practical efficiency, and strong generalization.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：3D 高斯泼溅（3DGS）以其高保真新视图合成（NVS）和高效渲染能力，已成为 3D 场景表示的重要范式。然而，标准 3DGS 主要面向视觉重建，未显式编码实例结构或语义信息。现有面向场景理解的 3DGS 方法大致分为两条路线：
  - **场景特定方法**（如 Gaussian Grouping、OpenGaussian、InstanceGaussian 等）：通过逐场景优化将语义/实例特征绑定到高斯上，但依赖 SfM 估计位姿、重建与实例学习分阶段进行，效率低、难以跨场景泛化，且各任务间缺乏交互。
  - **前馈 3DGS 方法**（如 AnySplat、Uni3R、C3G 等）：直接从图像重建未见场景，也有方法引入语言对齐特征，但其表示仍然是**类别导向（category-oriented）**，不能区分同类别下的不同物体实例，也难以保留清晰的实例边界。
- **核心问题**：不存在一种统一的前馈 3DGS 框架，能够同时在单次前向传播中完成 3D 重建、实例分割和开放词汇语义理解，并让重建与理解相互促进。
- **本文提案**：InstanceSplat，一个**统一的前馈 3DGS 框架**，从**无位姿（pose-free）多视图图像**出发，单次前向构建实例感知高斯表示，联合编码外观、几何、实例身份和语言对齐语义。通过共享的 3D 高斯结构，实现实例身份跨视图锚定、可渲染的实例特征，并设计了以实例为中心的学习策略，让重建、实例学习与语义学习通过共享实例结构互惠增强。

### 2. 方法论：核心思想、关键技术细节与公式

#### 2.1 整体架构

InstanceSplat 的输入为 N 张无位姿多视图图像 {Ii}，整体网络 F 预测相机参数（内参和外参）、深度图、点图（point map）以及稠密高斯集 G：
```
F : {Ii} → { (ti, Di, Pi) } , G
```

- **骨干网络**：采用 VGGT（24 层 Transformer）作为几何基础模型，包括 DINOv2 骨干和交叉视图注意力；使用 DPT 式解码器预测位姿、深度和点图，并用另一个 DPT 式解码器回归高斯属性与紧凑语义特征。
- **实例编码器**：借鉴 IGGT，从多层级 Transformer 特征预测像素对齐的 8 维实例特征图，并通过滑动窗口交叉注意力注入局部几何线索。
- **高斯构建**：对每个像素生成一个高斯，属性包括位置、旋转、尺度、颜色、不透明度、置信度、实例嵌入、语义特征。随后采用置信度感知的体素化操作（AnySplat）合并冗余原语，得到紧凑且特征融合的高斯集 G′。

#### 2.2 3D 一致实例锚定（3D-Consistent Instance Grounding）

- **可微渲染**：将体素化高斯上的实例嵌入通过 α 合成渲染到监督视图：
  ```
  S̃i = R_ins(G′, ti)
  ```
  不同视图的观测通过共享的 3D 原语耦合，因此图像空间监督可以建立跨视图一致的 3D 实例身份。
- **原型对比学习**：在渲染空间，对每个实例使用 ℓ2 归一化的实例特征计算类原型，并采用 pull-push 式对比损失：
  - **pull 损失**（5）：使每个像素特征靠近其所在实例的原型（margin δ_pull）；
  - **push 损失**（6）：拉开不同实例原型之间的距离（margin δ_push），其中实例对权重 η 在基础模型中为 1；
  - **cross-view 损失**（7）：对齐同一实例在不同视图中的原型（margin δ_cross）。
  - 总损失：L_ins = λ_pull L_pull + λ_push L_push + λ_cross L_cross。

#### 2.3 实例中心耦合（Instance-Centric Coupling）

以锚定后的实例结构为共享接口，实现三条互惠路径：

- **边界感知重建（Boundary-Aware Reconstruction）**：
  - 从像素对齐的实例特征图提取边界分数：计算每个像素与其四邻域的余弦距离最大值，通过局部窗口扩展和 sigmoid 映射得到软边界权重 b_i(p)；
  - 使用边界权重对 Charbonnier 距离加权的 RGB 损失 L_bd-rgb（11），将优化焦点集中在实例边界区域，改善重建在物体边缘的几何精度（无需 GT 边界）。

- **语义引导的实例判别（Semantic-Guided Instance Discrimination）**：
  - 渲染紧凑语义特征并投影到语言对齐教师空间（Student → Language-aligned teacher），通过余弦相似度损失 L_sem 对齐语义；
  - 在实例对之间的 push 项中，根据实例级语义原型相似度动态调整权重 η：
    ```
    η = 1 + (η_max − 1) * [sem_sim clipped]^10
    ```
    即语义上相似（如同为椅子）的实例对获得更大的分离权重，促使实例学习更好地区分同类物体。

- **实例锚定语义聚合（Instance-Grounded Semantic Aggregation）**：
  - 推理时渲染实例与语义特征图，用 HDBSCAN 对归一化实例嵌入聚类得到实例区域；
  - 在预测实例内部聚合语义特征得到实例级语义原型，再与文本嵌入对比，将选取的开放词汇标签传播到整个实例区域，抑制局部语义噪声、保证对象内一致性。

- **训练总损失**：
  ```
  L = L_rgb + L_distill + λ_ins L_ins + λ_sem L_sem + λ_bd L_bd-rgb
  ```

### 6. 主要结论与发现

- InstanceSplat 在所有报告前馈方法的对比中，在多数输入视图设置下取得 **最佳 mIoU**，在重建指标（PSNR、LPIPS）上也达到最优或领先水平，说明重建与实例理解可以协同而非互斥。
- 在未见数据集 LERF 上，InstanceSplat 显著优于逐场景优化方法（OpenGaussian、InstanceGaussian），推理时间从**分钟/小时级降至秒级**，验证了强泛化性与实际效率。
- 共享的 3DGS 表示相比 IGGT 的特征式跟踪，实现了更高的跨视图实例一致性（T-mIoU 64.03 vs 61.99；T-SR 51.04 vs 45.15）；消融表明冻结几何会导致实例边界过度平滑，联合优化 3DGS 可同时提升跟踪一致性和渲染质量。
- 语义引导的硬负样本重加权可有效区分同类不同实例（如相邻椅子）；实例级语义聚合能明显提升 mIoU/mAcc 和对象级预测连贯性；边界感知 RGB 损失对深度精度（RMSE、AbsRel）的提升尤为显著。

### 7. 优点

- **统一的单次前向框架**：同时完成重建、实例分割和开放词汇语义理解，无需逐场景优化，显著提升效率和泛化性。
- **共享 3D 高斯的桥梁作用**：以显式高斯作为实例身份与语义的 3D“载体”，通过可微渲染将二维监督自然锚定到三维，实现跨视图一致性。
- **双向互惠设计**：实例线索改善边界几何，语义线索改善同类实例判别，实例区域聚合语义——重建与理解相互促进而非分离，设计思路清晰且具有示范意义。
- **边界感知损失**：直接利用实例特征而非依赖额外标注，在不改变推理成本的前提下提升边界几何精度。
- **实验设计较全面**：涵盖多种输入视图数、跨数据集泛化、时间一致性、效率对比和消融，提供了多方位的有效性证据。

### 8. 不足与局限

- **聚类成本**：论文自述，随着视图数和高斯数增加，推理时 HDBSCAN 特征聚类的计算开销增大，限制了向大规模场景扩展的能力。
