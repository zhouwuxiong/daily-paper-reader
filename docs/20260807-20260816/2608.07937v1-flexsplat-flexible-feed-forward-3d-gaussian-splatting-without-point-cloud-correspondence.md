## 摘要
我们提出了FlexSplat，一个用于从无标定、以物体为中心的多视图图像集合进行新视角合成（NVS）的前馈框架。最近一系列基于查询的方法通过将3D高斯基元视为变换器查询，并使用多视图可变形注意力进行细化，从而重建紧凑的3D高斯集合；然而，这些方法假设相机位姿已知。FlexSplat移除了这一假设：一个几何变换器与高斯解码器联合训练，以预测每幅图像的相机参数和深度，进而为深度引导的高斯参数化和多视图可变形交叉注意力提供基础，该注意力将所有输入视图的证据聚合为单一、视图一致的原语集合。一个不确定性加权的深度一致性目标使联合训练的几何模块适应重建任务，而解码过程中形成的跨视图共识吸收了估计相机和深度的残余误差。该表示使用紧凑的高斯预算，与输入分辨率解耦——与像素对齐方法不同，原语数量不随图像网格增长——并且不受视图数量支配。在ShapeNet-SRN和Google Scanned Objects（GSO）上，FlexSplat在无需相机位姿或真实深度的前提下，匹配或接近有位姿的最先进重建器，并在GSO上达到所比较方法中最佳的感知（LPIPS）质量。我们的结果表明，联合训练的几何前端足以使基于查询的高斯重建实现免标定操作，同时保持在与有位姿方法0.7 dB PSNR范围内，并匹配其感知质量。

## Abstract
We present FlexSplat, a feed-forward framework for novel view synthesis (NVS) from uncalibrated, object-centric multi-view image collections. A recent line of query-based methods reconstructs a compact set of 3D Gaussians by treating them as transformer queries that are refined with multi-view deformable attention; these methods, however, assume that camera poses are given. FlexSplat removes this assumption: a geometry transformer is trained jointly with the Gaussian decoder to predict per-image camera parameters and depth, which in turn ground a depth-guided Gaussian parameterization and a multi-view deformable cross-attention that aggregates evidence across all input views into a single, view-consistent set of primitives. An uncertainty-weighted depth-consistency objective lets the jointly trained geometry adapt to the reconstruction task, while the cross-view consensus formed during decoding absorbs the residual error of the estimated cameras and depth. The representation uses a compact Gaussian budget that is decoupled from the input resolution - unlike pixel-aligned methods, the primitive count does not grow with the image grid - and is not dictated by the number of views. On ShapeNet-SRN and Google Scanned Objects (GSO), FlexSplat matches or approaches posed state-of-the-art reconstructors while requiring neither camera poses nor ground-truth depth, and matches the best perceptual (LPIPS) quality among the compared methods on GSO. Our results indicate that a jointly trained geometry front-end is sufficient to bring calibration-free operation to query-based Gaussian reconstruction while staying within 0.7 dB PSNR of posed methods and matching their perceptual quality.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **问题背景**：新视角合成（NVS）是计算机视觉的核心任务。基于 NeRF 的方法虽能实现逼真渲染，但需要精确的相机位姿（依赖 SfM 预计算）和逐场景优化（耗时数分钟至数小时）。3D 高斯泼溅（3D-GS）虽然引入实时渲染，但仍存在上述两大限制。
- **已有前馈重建器的不足**：前馈式重建器（如 pixel-aligned 和 point-based 范式）虽然去除逐场景优化，但仍存在两个结构性缺陷：
  - **像素对齐范式**（如 Splatter Image）：每个像素映射为一个高斯，原语数量随图像分辨率和视图数线性增长，导致冗余、过拟合和内存膨胀。
  - **点基范式**：需要复杂多阶段几何管线预测稠密 3D 点或 triplane 特征。
  - **基于查询的范式**（如 LeanGaussian、UniGS）通过将高斯视为 Transformer 查询来打破对应关系，产生紧凑高质量重建，但**仍假设相机位姿（有时还包括深度）已知**。
- **核心研究问题**：能否移除基于查询的高斯重建方法对相机位姿的依赖，实现**免标定（calibration-free）**的物体级前馈重建？
- **论文答案**：可以。FlexSplat 通过联合训练几何 Transformer 与高斯解码器，在无相机位姿、无真实深度的条件下，达到与有位姿 SOTA 方法相当的渲染质量——PSNR 差距在 0.7 dB 以内，LPIPS 达到最优水平。

### 2. 论文提出的方法论

**核心思想**：将几何预测（相机位姿+深度）与高斯重建解码器联合训练，使预测的几何信息直接作为高斯参数化和跨视图注意力的条件，从而在无需显式标定的前提下完成重建。

**关键架构组件**：

- **联合训练的几何 Transformer**：采用 VGGT 作为前端，包含两个头部——深度/几何特征头（基于 DPT 架构）和相机头（回归内参外参）。与传统将 VGGT 作为固定先验的方法不同，FlexSplat 将其与解码器**联合微调**，使几何预测受渲染损失和深度一致性损失共同塑造。
- **双分支特征融合**：UNet 提取像素对齐的外观特征，与 VGGT 的深度特征进行 FPN 式融合（相加+卷积精炼），得到深度感知的多视图特征图 F，作为可变形交叉注意力的键和值。
- **深度引导的均值参数化**：每个高斯基元的中心不直接回归绝对坐标，而是基于预测深度和可学习偏移进行反投影（公式 2）：
  - μₙ,ᵢ = (u¹ᵢ·dᵢ + Δxᵢ, u²ᵢ·dᵢ + Δyᵢ, dᵢ + Δzᵢ)ᵀ
  - 这稳定了训练收敛，同时通过训练深度本身来适应重建任务。
- **几何初始化**：将所有高斯查询放置在估计的场景中心附近（通过相机光轴的最小二乘交点计算），避免随机初始化导致投影点落在图像外、特征消失、梯度消失的问题。
- **多视图可变形交叉注意力（MVDFA）**：每个高斯查询被投影到所有 N 个视图，形成 N 个 2D 参考点；在每个参考点周围采样 Nₚ 个带学习偏移的位置，通过注意力权重聚合特征（公式 3）。归一化在**所有视图和采样点上联合进行**（∑A = 1），使每个高斯形成跨视图共识，而非依赖任何单个（可能含噪声的）投影——这是吸收相机和深度误差的关键机制。
- **迭代解码器**：L=3 层，每层依次执行 MVDFA、自注意力和 FFN（公式 4），并通过 Splat 头输出增量更新，组合到当前估计上（平移/外观用加法，旋转用乘法）。每层渲染并监督，实现渐进式细化。
- **紧凑、分辨率无关的表示**：高斯数量 N_G 是自由超参数，与输入分辨率和视图数无关。4 视图 256×256 输入时，像素对齐方法需约 26 万个高斯，而 FlexSplat 仅用 2 万个（约少一个数量级）。
- **训练目标**（公式 5）：包含三部分：
  - 特征提取器和每个解码器层的 RGB 重建 MSE 损失；
  - **不确定性加权的深度一致性损失**：将渲染深度对齐到 VGGT 预测深度，权重由几何头的逐像素置信度调制；
  - LPIPS 感知损失。
  - 几何 Transformer 在梯度路径中，因此深度一致性项既正则化高斯，又适应几何预测。

### 6. 主要结论与发现

- **免标定可行**：联合训练的几何前端足以使查询式高斯重建实现免标定操作，与有位姿的 UniGS 相比仅损失 0.69 dB PSNR 和 0.012 SSIM，LPIPS 相当（0.041 vs 0.042）。
- **跨视图共识带来鲁棒性**：解码过程中形成的跨视图共识能有效吸收中等程度的相机和深度估计误差。高斯在共享世界空间中聚合所有视图证据，将每视图的姿态误差平均化而不是传播。
- **紧凑表示成立**：高斯预算与输入分辨率解耦、不受视图数支配，在相同输入条件下比像素对齐方法少约一个数量级的高斯数量。
- **视图数量边际收益递减**：1→2 视图 PSNR 提升最大（+5.17dB），2→4 视图再提升 +2.63dB，符合多视图重建的典型规律。

### 7. 优点

- **核心创新点突出**：首次将基于查询的高斯重建扩展到无标定物体级场景，联合训练几何前端是该工作的关键差异化设计（消融显示冻结 VGGT 损失 1.38 dB PSNR）。
- **紧凑且可扩展的表示**：高斯数量为自由超参数，不随分辨率或视图数增长，兼顾内存效率和重建质量。
- **鲁棒性有据可依**：位姿扰动实验量化了跨视图共识对中等姿态误差的容忍度——5° 旋转噪声仅损失 2.09 dB PSNR。
- **推理效率高**：端到端 4 视图约 1 秒，优于大多数传统重建方法，具备实时应用潜力。
- **代码开源**：提供 GitHub 仓库，便于复现和后续研究。
- **消融设计针对性明确**：每个消融组件都能直接对应论文的核心主张（联合训练、深度引导、几何初始化、跨视图一致性）。

### 8. 不足与局限

- **场景范围受限**：仅针对物体级、以物体为中心的采集；扩展到大规模背景丰富场景尚无验证，需要场景级训练数据和基准。
- **原始 PSNR 未超越最强有位姿基线**：FlexSplat 在 PSNR 上仍比 UniGS 低 0.69 dB，论文明确承认其优势在"感知质量和去除标定需求"而非原始数值指标。
- **大几何误差的可传播性**：虽然能容受中等位姿和深度误差，但在视图高度不一致或采集过于密集导致几何估计严重失效时，误差仍可能传播到重建结果。
- **位姿扰动分析不完整**：仅分析旋转噪声，未做平移扰动的敏感性分析（论文明确承认此局限）。
- **训练细节缺失**：未报告训练时长、VGGT 微调的具体策略细节、不同数据集上的训练超参数配置等，可能影响复现性。
- **单视图 GSO 的对比条件为"非原生"**：部分基线（LGM、InstantMesh）需要多视图输入，使用 ImageDream 生成的视图可能不完全等价于原生单视图方法的行为。
